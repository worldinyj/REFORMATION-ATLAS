# 종교개혁 ATLAS — V4.66 인쇄 조판 판별과 학술판 저본 추적

**검토 기준일:** 2026-11-19  
**범위:** 마르부르크 15개 조항, 1529년 취리히 인쇄본 W2118·W2119의 조판/인쇄 사항, 후대 학술판의 사료 저본

**판정 요약:** W2118과 W2119가 서로 다른 서지 판본이라는 사실, 앞선 조사에서 확인한 말미의 콜로폰 차이, 그리고 **『츠빙글리 저작집』 제6권 제2부 제146번의 저본이 서명 필사본 Z가 아니라 실제 인쇄본 W2119라는 공식 기록**을 명시했다. 두 인쇄본의 **동일 조판 여부와 선후·직접 의존관계**는 판정 보류. 이번 실행에서는 **W2119의 제15조·서명면 원본 지면을 다시 확인**, W2118은 웹 접근 실패로 V4.65의 기록을 계승했을 뿐 **새로 전체 지면을 재검증한 것은 아니다**.

## 1. 역사학적·편집학적 핵심 발견: 학술판도 저본이 다르다

[취리히 주립문서보관소 공식 서지·사료 계통 설명](https://suche.staatsarchiv.djiktzh.ch/detail.aspx?ID=618165)은 동일한 마르부르크 15개 조항을 수록한 학술판들의 저본을 다음처럼 명확히 구분한다.

| 학술판 | 공식 기록의 저본 | 직접 뜻하는 바 |
| --- | --- | --- |
| **『츠빙글리 저작집』 6/2권 146번** | **1529 취리히 인쇄본 VD16 W2119** | 이 학술판의 원문을 **서명 필사본 Z의 직접·완전 전사본으로 간주하면 오류** |
| **루터교 고백문서 자료집**(2014), 43–46쪽 | **헤센 서명본 K** | K 기반 텍스트로 표시 |
| **『개혁파 신앙고백집』 1/1권 11번**, 259–267쪽 | **취리히 서명본 Z** | Z 기반 텍스트로 표시 |
| **『멜란히톤 서신집』 본문 3권 825번** | **K에 Z의 이문을 병기** | 기준 본문과 변이를 함께 읽어야 함 |

이 자료는 직접 열람한 아카이브의 공식 서지 설명으로 입증되는 **학술적 편집 저본 매핑**이다. 연구 웹앱에서 '츠빙글리 저작집'이라는 제목만 보고 원본 **취리히 서명본 Z를 그대로 베꼈다고 추론하는 오류**를 원천적으로 예방한다.

**중요한 후속 원칙:** 당시 서명 합의문의 두 원본 K와 Z가 존재한다는 증거와, 어느 후대 교감판이 어느 원본 또는 어떤 **인쇄본**에 의존했는가는 서로 다른 연구 질문이다.

## 2. W2118·W2119 원본 제15조의 '본문 의미'와 '조판 동일성' 구별

서지 명칭:

- W2118: **VD16 W2118, Vischer C162**, ZB Zürich, **Zwingli MvK A 81,8**. 이전 V4.65에서 정확한 e-rara 기록 **291747**과 원본 PDF `https://www.e-rara.ch/zuz/download/pdf/291747`를 열어 제15조(0기준 p6)·서명자 목록(p7)을 판독했다.
- W2119: **VD16 W2119, Vischer C161**, ZB Zürich, **5.174,5**, 원본 PDF `https://www.e-rara.ch/zuz/download/pdf/170052`; **이번 V4.66에서 PDF p6 제15조와 p7 말미 서명면을 다시 직접 확인**.

**이번 환경의 접근 제한:** W2118 원본 PDF·IIIF 주소는 이번 실행에서 열람 도구 오류를 반환했다. W2118의 제15조·콜로폰 판독은 **V4.65의 기존 기록**으로만 이어받았으며, 새 실물 이미지 또는 새 전체 글자 전사와 혼합하지 않는다.

### 제15조의 판독 범위

| 인쇄 위치 | W2119의 이번 직접 확인 | W2118의 기존 연구 기록 | 비교 판정 |
| --- | --- | --- | --- |
| 제목·제15조 시작 | `Vom Sacrament des lybs vnd blüts Christi`; `Zum fünffzehenden` | p6에 제15조가 실림 | **의미상 위치 대응**, 동일 줄바꿈 판정 안 함 |
| 미사와 은총 | `Das auch die Mässe nit ein werck ist` | 미사는 타인을 위한 은총 획득 행위가 아니라는 명제 | **내용 대응**, 완전 철자 대조 보류 |
| 신체적 임재 | `lyplich im brot vnnd wyn` | 제15조의 동일 논점 있음 | **내용 대응**, 문자단위 교감 보류 |
| 상호 사랑·기도 | 제15조 끝부분에 권고 | 전 단계 W2118 판독에서 동일 논점 기록 | **내용 대응**, 인쇄행·교정 사항 보류 |
| 말미 서명자·인쇄자 | p7 명단 아래 취리히 **Christoffel Froschouer 인쇄 표시 있음** | V4.65 기록에서 W2118 p7 명단 아래 **인쇄자 표시 없음** | **서로 다른 말미 인쇄 사항 확인**, 본문 전체 조판 차이 판단 안 함 |

W2119 직접 확인의 원본 출처는 위 PDF의 제6·7쪽이며, 사진에는 인쇄 활자 외에 라틴어 필사 주석이 보인다. 이 주석을 인쇄본의 발행 시점에 존재한 공식 본문으로 처리하지 않는다.

## 3. '콜로폰이 다르므로 완전히 새로 조판했다'는 추론이 성립하지 않는 이유

16세기 소책자는 **본문 활자 조판 유지 여부**, 마지막 지면의 **인쇄자 정보 추가/삭제**, 같은 활자의 **중간 교정(stop-press)**, 별도의 **완전 조판** 등 여러 인쇄 상태를 가질 수 있다.

현재 직접 확인·이전 연구 기록에서 **인쇄자 표시의 유무**라는 차이는 있지만, 다음을 검증하지 않았다.

- 제15조의 모든 인쇄 행 끝 글자가 서로 같은가
- 서로 특이한 잘못 조판된 글자나 파손 활자(broken sorts)가 공유되는가
- 제목·문단·서명자 명단의 활자 배열과 들여쓰기가 같은가
- 접지·절판 구조와 각 장의 서명표가 정확하게 대응하는가
- 어느 인쇄본이 먼저였고 다른 인쇄본이 어느 것을 복사했는가

따라서 현재의 가설은 **'동일 조판에서 말미만 달라진 발행 상태'**, **'본문이 별도 조판된 판본'**, **'부분 조판 교체'** 등으로 병렬 유지한다. **어느 가설도 현재 확증되지 않았다.** 서지번호가 둘이라는 이유로 동일 조판 여부를 자동 결정하지 않는다.
