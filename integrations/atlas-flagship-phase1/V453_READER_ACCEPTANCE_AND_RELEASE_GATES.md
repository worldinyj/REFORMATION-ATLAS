# 종교개혁 ATLAS — V4.53 대표 역사 화면 품질 승인 기준

> 2026-11-18 / 연구 시범 화면만 / Google AI Studio 운영 앱 미변경 / 공개 승인 `can_ship=false`

## 이번 단계에서 확인한 것

- 첫 화면(V4.52)의 실제 GitHub HTML 인라인 스크립트를 V8 모의 DOM에서 재실행했다. 상태 전환, 연도 선택 후 포커스 보존, L0/L1 탭 이동, 문헌 카드, 판본 비교, 리셋, 자료 무변조 등 **21개 점검 모두 PASS**.
- 기존 Node 테스트 파일에 키보드 포커스·탭 회귀 검사를 추가했고, **6개 테스트 함수를 V8 호환 검증기에서 PASS**했다. 이 결과는 `node --test` 실제 실행을 의미하지 않는다.
- Playwright 브라우저 검증 스크립트의 잘못된 기대값을 수정했다. 역사적 **제목 문자열** 대신 화면의 **1531년 날짜 레이블**을 검사한다.

## 출시 전에 완료해야 하는 검증 — 현재 미완료

1. Chromium·WebKit 실제 자동검증을 320·375·768·1440px에서 **실제로 실행**하고 로그와 스크린샷을 저장.
2. 실제 Safari/Chrome에서 키보드 조작·스크린리더·가로 넘침·탭 이동을 **사람이 확인**.
3. 역사학자에게 마르부르크 제15조, 1530 신앙고백 제출 문서, 1531 인쇄·변증서, 1540 Variata 판본 주장을 문장별 검토 의뢰하고 미승인 주장 추적.
4. 소규모 독자에게 위 3개 여정을 시연하고 오해·이탈 지점을 기록한다. 정량 성공 기준은 파일럿 전에 사전 정의한다.
5. 실제 AI Studio 프로젝트의 프레임워크·라우트·인증·비공개 데이터 전달 방식을 확인하고, **그때까지 이식하지 않는다**.

## 자동 실행과 실측을 혼동하지 않기

- GitHub Actions 정의: `.github/workflows/atlas-phase1-browser-qa.yml`
- 브라우저 검사: `integrations/atlas-flagship-phase1/browser-smoke.test.mjs`
- 모의 DOM 회귀 검사: `integrations/atlas-flagship-phase1/preview.test.mjs`
- GitHub 연결 도구의 `fetch_commit_workflow_runs`는 PR 트리거 워크플로만 조회한다. 따라서 이 도구로 결과가 없다는 사실만으로 **push 브라우저 CI가 없었다거나 성공했다고 주장할 수 없다**.
- Public 저장소의 HTML은 공개 자료이며, React 컴포넌트에서 화면을 숨기는 것은 실제 접근 권한 통제가 아니다.
