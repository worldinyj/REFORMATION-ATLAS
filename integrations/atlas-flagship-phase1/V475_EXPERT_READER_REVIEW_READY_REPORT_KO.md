V4.57의 Q09가 **두 개의 사료 카드**를 전제로 한 오래된 질문이어서, V4.75 참가자용 버전에서는 현행 **6종 사료 카드**에 맞는 문구로 수정했다. 기존의 정답·문항 ID·평가 기준은 바꾸지 않는다. 평가 JSON이 공개되어 있어 여전히 실제 블라인드 성능 평가가 보장되지 않는다는 위험을 반드시 공지한다.

## 연구 진행 상태

- 실제 역사학자 승인 **0명**. HIGH 10건 전부 `PENDING`, 2인 독립 검토 필요.
- 실제 독자 참여 **0명**, 수집·채점 **0건**. 기존 V4.57 기준을 유지하고, 현재 어떤 참여자 합격률도 산출하지 않았다.
- 필사본 K/Z 제15조 해당 잎 직접 판독 **0/2**, 1531·1540 라틴어 제10조 직접 교감 **0/2**.
- 기관 이메일 발송 0, 유료 주문 0, 실제 앱 배포 0. 공개 GitHub는 비공개 평가 환경이 아니다.

**출시:** `can_ship=false` / `can_merge_main=false` / `can_import_ai_studio=false`. 실제 사람 검증 없이 진행 가능한 것은 연구 자료의 안전한 재검토와 UI 수정까지만이다.
