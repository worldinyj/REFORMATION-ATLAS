## 2. 실제 React 검증 계획

연구 CI는 `react`, `react-dom`, `esbuild`을 **검사용 CI 작업에 한정해** 설치한다. 브라우저 테스트는 *TypeScript 구문 검사만 하는 것이 아니라 실제 JSX를 esbuild로 번들링해 React DOM을 Chromium과 WebKit에서 구동*한다.

검증: 320·375·768·1440px × 두 엔진 = 8개 실제 반응형 화면, L0/L1 원문 및 6절 표시, 5/2개 사료 카드, 3행 문헌 비교, 전통 판본 비교, 모바일 가로 넘침, 리셋, 네트워크 호출 부재. **접근 미승인과 `readerPack`의 `canShip=true` 변조 상태에서는 실제 본문 렌더링을 차단하는 음성 테스트**를 함께 수행한다.

참고: `privatePreviewGranted`는 UI 가드일 뿐 **서버 인증이 아니다**. 공개 GitHub의 연구자료는 공개 파일이다. 실제 서비스 연동 시 서버 접근제어·라이선스 검토가 별도로 필요하다.
