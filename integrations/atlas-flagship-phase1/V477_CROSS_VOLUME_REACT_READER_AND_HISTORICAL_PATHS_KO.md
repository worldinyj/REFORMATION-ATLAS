## 2. 통합 독자 경로 3건

1. **성찬, 1529 → 1551:** 마르부르크 제15조의 공통 고백/남은 이견과 트리엔트 제13회기의 성찬 교령을 비교. 제13회기를 마르부르크 조항에 직접 첨삭된 문서라고 오해하지 않는다. 근거: 제4권 `[GA][WP]`·제5권 `[TE][TC]`.
2. **칭의, 1530 → 1547:** 아우크스부르크 신앙고백의 제출·판본 역사와 트리엔트 제6회기 제7·8장의 교리 언어를 서로 다른 자료와 목적 아래에서 비교. 원어를 직접 완전 교감했다고 주장하지 않는다. 근거: `[GR][SC]`·`[TG][TC]`.
3. **1540년의 서로 다른 변화:** Variata/비Variata 인쇄본 판차와 예수회 인준이라는 **동년의 서로 다른 사건**을 비교. 같은 연도라는 사실은 직접 인과관계의 증명이 아니다. 근거: `[GR][SC]`·`[TJ][TC]`.

이 탐색 경로는 역사 해석의 **편집 후보**이지 전문가 승인이 아니다. 모든 경로에 출처 ID와 반증·한계를 별도로 표시하고, `research/data/ATLAS_V477_CROSS_VOLUME_READING_LINKS.json`에 기록한다.

## 3. 기술 구조

- 공통 검증·모델 변환: `atlas-cross-volume-research.mjs`가 V4.75 기존 검토 계약을 그대로 재사용하고 사건·출처의 관계, 2개 이상 권, 역사적 연결 근거, 보류된 승인 상태를 검사한다.
- 공통 화면: `AtlasCrossVolumeResearchPanel.jsx`에서 권 선택, 연표, L0/L1, 권별 사료 카드, 권별 문헌 비교, 세 독자 경로, 원상 복귀를 제공한다.
- L1은 두 권의 원고에 들어 있는 **실제 원문을 그대로 렌더링**한다. 제4권과 제5권의 독립형 HTML 및 제4권 React 컴포넌트는 기존 상태로 유지한다.
- 원문 표현에서 출처 ID를 추출하고 공식 외부 링크와 연결한다. 위험한 HTML 주입, 무단 이미지·원전 스캔 재복제, 평가 응답 수집 없음.
- `privatePreviewGranted`는 UI 가드일 뿐 서버 측 인증이 아니다. 공개 GitHub의 연구자료는 누구나 접근 가능하다.

## 4. 회귀검증 / 출시 제한

- Node 계약: 두 권 각각 다른 사건 수·사료 수·장 구조와 L0/L1 원문 불변, 경로 3건의 출처 유효성, 비허가 데이터·조작된 경로의 차단을 확인.
- 실제 Playwright: Chromium/WebKit × 320/375/768/1440px에서 연구 React 화면을 직접 번들링·렌더링하고, 권 간 이동·사료 카드·8절/6절·2개의 3행 비교·접근 거부·변조 차단·가로 넘침과 외부 요청 없는 상태를 시험.
- 실제 CI 결과를 확인하기 전에는 통과라고 보고하지 않는다.
- 역사학자 실제 승인 0건·독자 실증 0건·K/Z 제15조 및 트리엔트 교령의 16세기 원전 직접 교감 미완료.
