- 네 사건(1529·1530·1531·1540), L0/L1 전환, 연도별 사료 카드, 제출·출판·수정판 비교를 보존했다.
- **6종의 사료 카드(GA·GE·WP·ZA·SC·GR)**를 표시하며, 1529 선택 시 5개, 다른 연도 선택 시 Gruber·Schaff 2개를 제시한다. 카드에 출처의 증거 종류와 한계를 적었다.
- **서명 필사본 K/Z / 1529년 W2119 인쇄본 / 후대 GHDI 영어 번역의 3행 대조 표**를 토글로 볼 수 있다. K/Z 실제 필사본 제15조 직접 판독 **0/2**임을 표시한다.
- 각 L0·L1 읽기 아래에 원고에 실제 기재된 근거 ID를 표시한다. 온라인 요청과 응답 수집이 없는 독립형 HTML이며, **공개 GitHub 파일에 접근통제가 있다는 오해를 금지**한다.

## GitHub Actions 실패 원인 (실제 로그 확인)

지난 [실행 #44724441589](https://github.com/worldinyj/REFORMATION-ATLAS/actions/runs/44724441589)에서 계약 테스트는 **82개 중 81개 통과, 1개 실패**였다. V4.59의 W2118 서지 URL이 직접 확인된 공식 e-rara 항목 **291747**로 개선되었는데 테스트가 구 DOI 주소를 `url` 필드에 기대해서 실패했다. **원본 데이터는 유지**하고 테스트가 기관 공식 URL, 별도 `permalink` DOI, 스캔 PDF를 확인하도록 갱신했다.

브라우저 작업 2개는 **Playwright 1.56.1 + GitHub Ubuntu 26.04 러너의 설치 비호환**으로 실제 브라우저 테스트가 시작되지 못했다. 이번 CI에서는 러너를 **Ubuntu 24.04로 고정**했다.

**신규 계약 테스트** `v473-preview-bridge-contract.test.mjs`는 V4.72 본문 완전 일치, 사료 6종·각 증거 수준, 필사본 미확정 표시, 읽기/연도/비교/리셋 및 배포 게이트를 확인한다.

**신규 실제 브라우저 테스트** `browser-v473.test.mjs`는 Chromium·WebKit과 320/375/768/1440px 화면폭의 **8개 조합**에서 L0/L1, 본문 6절, 사료 카드, 두 비교표, 모바일 가로 넘침, 외부 네트워크 요청 차단을 확인하고 화면 캡처를 남기도록 구성한다.

**주의:** 이번 커밋에서 CI 수정이 실행될 예정이므로, 이 문서는 아직 **새 GitHub Actions PASS 보고서가 아니다**. 실제 워크플로 결과를 따로 조회해야 한다.
