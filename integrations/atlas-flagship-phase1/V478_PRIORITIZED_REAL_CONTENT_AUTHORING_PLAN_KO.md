# 종교개혁 ATLAS — V4.78 역사 콘텐츠 실집필 우선 작업지시서

**집필 철학:** 추가 테스트 번호보다 실제 독자가 이해할 한국어 역사 서술, 원전의 증거 수준, 서로 다른 공동체·지역의 목소리를 강화한다. V4.47/V4.50 최신 통합본은 보존하고 새로운 초안은 연구 후보로 관리한다.

## 1단계: 제6권 타밀어 성서·선교·현지 공동체

**기준:** VOL-06 / L448-06-02, 기존 L1 1505자(3장) · 고유 참고 URL 6개.

1. 1706 트랑케바르의 번역 과정에서 유럽 선교사와 타밀어 독자·협력자를 각각 역사적 주체로 서술
2. 1715/1719 신약성경 판본의 실제 확인한 서지와 미확정 인쇄를 별도 증거 카드로 구분
3. 언어·인쇄·수용의 차이와 근거의 종류가 드러나는 L1 심화 본문을 새로 집필

**수용 기준:** 1719년 판본의 실물 인쇄를 확인하지 않았음을 유지하고 G443-03 P0 전문가 검토를 완료했다고 표기하지 않음.

## 2단계: 제2권 635년/781년 경교비와 동방 기독교

**기준:** VOL-02 / L448-02-02, 기존 L1 1405자(3장) · 고유 참고 URL 6개.

1. 635년이라는 사건의 연대와 781년 경교비 제작 연대를 서로 다른 시간에 배치
2. 비문 원문·현존 비석·탁본·전사·후대 해설을 별도 증언으로 비교
3. 비잔틴·서아시아·중세 중국 교회의 서로 다른 정치·언어 맥락을 구체화

**수용 기준:** 635년에 비석을 만들었다거나 비문이 앞선 146년의 모든 사건을 직접 목격했다는 식의 오류를 피함.

## 3단계: 제7권 한국·세계교회의 고위험 주장

**기준:** VOL-07 / L448-07-02, 기존 L1 3330자(3장) · 고유 참고 URL 15개.

1. 1779/1784 한국 천주교 초기 서술의 기록 종류와 신뢰도를 분리
2. 1882·1887·1900·1911년 한국어 성경 간행의 서로 다른 서지 단계 기술
3. 아프리카 독립교회와 MECC/WCC의 기관 주장·역사적 대표성 구분

**수용 기준:** G443-04~07과 G443-11 미제출 상태를 유지하고 기관 출처를 곧 신학적 일치의 증명으로 여기지 않음.

## 4단계: 제8권 여섯 주제의 실제 비교 서사

**기준:** VOL-08 / L448-08-01/02/03, 기존 L1 1604자(3장) · 고유 참고 URL 9개.

1. 여섯 질문별 도입 문장과 다른 권 실제 장 3개 이상의 탐색 경로 구성
2. 성찬·번역·권위·공존을 원전의 종류와 시대별 의미를 밝히는 비교단락으로 집필
3. 권 간 이동 시 직접 인과 관계가 확정되지 않았다는 편집 주석 추가

**수용 기준:** 주제 유사성과 자료 전승·직접 인과를 구분하고 검토 전 임의 출판하지 않음.


## 검토 위험과 원고 밀도를 분리한 네 가지 결정

- **사료 위험 P0:** 제6·7·3·4권의 G443 고위험 판단은 전부 실제 독립 역사전문가 미제출. 그 결과를 기계적 근거 검사의 PASS와 합치지 않는다.
- **서사 밀도 P1:** 제6·2·1·8권은 기존 3장 L1이 약 1,405~1,604자에 머문다. 문헌을 더 링크하는 것보다 사료 비교를 설명하는 실제 한국어 본문을 보강한다.
- **연결성 P2:** 제8권 여섯 질문을 권별 역사 장면과 연결하며, 제4·5권 React 연구 시범의 가능성을 참고한다. 아직 전체 8권 운영 앱으로 확장하지 않는다.
- **출시 보류:** 실제 역사학자 승인·독자 실험·권리검토·서버 접근통제/운영 앱 수용은 별개 사건이고 현재 완료됐다고 주장할 수 없다.
