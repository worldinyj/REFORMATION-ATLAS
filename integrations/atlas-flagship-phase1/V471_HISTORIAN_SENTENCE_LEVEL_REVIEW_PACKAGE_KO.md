## 3. 역사학자에게 전달할 검토 의제

**1차 검토:** 29개 문장 중 사료 관련 주장, 특히 `HIGH` 위험 항목을 종교개혁사·고백문서사 전문 검토자가 출처와 대조한다. 원문 1529 W2119의 인쇄면 6·7쪽, GHDI 편집 번역의 제15조, 공식 기록관의 K/Z 목록, 헤페의 연도별 서지 진술을 **실제 관찰 범위 내에서만** 평가한다.

**독립 2차 검토:** 위험도가 `HIGH`인 문장에 대하여 첫 번째 검토자와 분리된 검토를 요청한다. 필사본 K/Z 직접 이미지가 없어 결론을 내릴 수 없는 문장은 **HOLD**하고, 인쇄본의 대응 문구가 확인되어도 사본 계보는 별도 판단한다.

**필수 검토 질문:** ① 제15조의 공통 진술과 미해결 이견을 정확히 분리했는가? ② W2119에 보이는 미사 구절과 GHDI 번역에서 보이지 않는 구절을 과잉 해석하지 않았는가? ③ 1847/1854년에 관한 샤프의 '제2판' 기술을 실물 직접 판독으로 오인하지 않았는가? ④ 1530–1540년 아우크스부르크 판본과 1529년 마르부르크 논의를 단선적 인과로 묶지 않았는가?

## 4. 일반 독자 평가: 기존 V4.57 도구 재사용

원래의 독자 평가에는 **3과제·9객관식 문항**, 익명 세션 ID, 12분, 최소 6명·권장 8명이 준비되어 있다. 기존 채점 코드 `score-reader-session.mjs`와 사전 기준(9개 중 7개 정답, 핵심 7개 중 6개, 세 과제 완료 / 참여율·오해 기준)을 변경하지 않는다. 이번 V4.71은 **별도 무점수 확인 질문 3개**를 제안하여 V4.70의 새 사료 저본 차이에 대한 독자 오해를 점검한다.

- W2119 인쇄본에는 있는데 GHDI 번역 제15조에 보이지 않는 내용이 있다면, 그것만으로 K와 Z 중 어느 원본에 있던 문장인지 확정할 수 있는가? 왜 그런가?
- ‘1847년 초판, 1854년 제2판’이라는 표현을 접했을 때, 역사학자의 서지 인용과 실제 양 판본 표제지를 직접 확인한 결과를 어떻게 구별할 것인가?
- 제15조를 ‘완전 합의’나 ‘완전 불합의’라고 설명하는 것이 왜 오해를 부를 수 있는가?

**중요 운영상 한계:** 공개 저장소의 V4.57 평가 JSON에는 기존 9문항의 정답이 포함되어 있다. 따라서 단순한 GitHub 링크 공유만으로는 블라인드 평가가 보장되지 않는다. 독자용 안내문에는 정답을 넣지 않되, 별도 평가 화면/운영자는 정답 접근 통제를 해야 한다. 이번 단계에서 참여자를 모집하지 않았고, 아무 점수나 성공률도 산출하지 않았다.
