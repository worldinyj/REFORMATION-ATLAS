# V4.82 — 제8권 제6주제 실제 역사 원고의 편집 판단과 근거 경계

## 실제 집필 범위

대상은 전체 여섯 주제가 아니라 **'번역과 지역 수용'(T6)** 한 주제다. 기존 V4.50 `VOL-08/L448-08-03` 596자의 국가·갈등·공존 주제와 기존 번역 주제까지 포함한 문단을 덮어쓰지 않고, 새 L0 **997자·4문단**, 새 L1 **5836자·10절**을 별도 작성했다.

## 이번 원고의 역사적 성과

- **중국의 경교비는 성경 번역본이 아니다.** 중국어·시리아어 공동체 기록을 635년 사건/781년 석각/20세기 탁본으로 분리했다.
- **남인도의 타밀어 신약은 물리적 판본과 지역 언어 조력이 핵심이다.** 1714 부분인쇄 / WLB 1715 소장본 / BSI 1719 전시 문구 / WLB 1722 별도판의 성격을 분리하고, 1719년 독립 인쇄본 판정은 계속 미해결로 두었다.
- **조선의 1779·1784년은 독서·세례·공동체 형성의 역사**이며 1882 개신교 성서 번역의 직접 서지 계보가 아니다. 1882 복음서 낱권 / 1887 신약 27권 / 1900 신약 / 1906 공인역 / 1911 신구약 합본의 각각 다른 상태를 비교했다.
- **사료 15종**을 제2·6·7권의 기존 확인 기록과 연결하고, **검토 주장 18건**, **보류 9건**, **사건 유형별 시간표 15건**, **비교표 3행**을 구성했다.

## 이 비교가 증명하지 않는 것

- 경교 공동체 → 타밀어 신약 → 한국어 신약으로 이어지는 **직접 문서 계보나 하나의 선교기관/조직 계보**.
- 중국어·시리아어 원석·탁본의 정밀 대조, 1719년 실제 신약 별도판 소장번호, 1882–1911년 본문 이문 전수 비교.
- 출판기록만으로 중국·인도·조선의 특정 지역 주민들이 그 문서를 어떻게 읽었는지 실증했다는 주장.
- 역사전문가 검토, 저작권 승인, 실제 독자 반응·운영 앱 탑재가 있었다는 주장.
