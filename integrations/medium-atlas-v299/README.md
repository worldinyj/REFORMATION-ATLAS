# V2.99 심화 읽기 검토 화면

V2.98 연결 모듈을 실제 화면에 적용한 별도 검토용 UI다. 435편을 검색하고 본문·질문·관련 해설·출처·선택 주장과 확인 범위를 읽을 수 있다. 실제 AI Studio 앱의 최신 소스나 라우트를 사용한 통합은 아니다. 원고·main·실제 앱은 변경하지 않는다.

## 검토 화면 열기

저장소 루트에서 로컬 서버를 실행한다.

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

다음 주소를 연다.

`http://127.0.0.1:8765/integrations/medium-atlas-v299/`

검토가 끝나면 서버를 실행한 터미널에서 Ctrl+C로 종료한다. 이 화면은 저장소의 연구 전달본을 읽으므로 검토 환경에서만 사용한다. 정식 공개나 실서비스 배포를 수행하는 명령이 아니다.

## 구현된 기능

| 기능 | 동작 |
|---|---|
| 검색 | 제목·도입·절 제목·본문 검색, 한국어 띄어쓰기와 영문 정규화 |
| 분야 | 인물·사건·문헌 등 8개 분야 선택 |
| 읽기 경로 | 지역·연대·쟁점별 18개 경로의 순서와 질문·해석 범위 표시 |
| 목록 | 페이지당 12편, 결과 수와 페이지 나눔 |
| 상세 | 도입·본문 세 절·질문·관련 해설·출처 |
| 출처 | 현재 접근 결과와 날짜·확인 한계 표시 |
| 출처 읽기 안내 | 안내 11개, 자료 사용 주의, 선택 주장 22건의 구간·근거 위치·판정 |
| 이동 | URL 해시로 검색 조건과 선택 원고 유지, 새로 고침·브라우저 뒤로 가기 |
| 오류 | 없는 원고·검색 결과 없음·자료 접근 실패·전달본 해시 불일치 상태 처리 |
| 키보드·크기 | 바로 가기 링크, 기본 폼·버튼·접기, 상세 제목으로 초점 이동, 좁은 화면의 단일 열 배치 |

자료는 V2.98 manifest의 SHA256과 맞는 V2.97 전달본만 읽는다. 과거의 여러 JSON을 자동으로 가져오거나 임의의 대체 데이터를 표시하지 않는다. 이 확인은 고정 파일의 동일성 검사이며 역사적 사실 검증과 다르다.

표시 문자열은 DOM의 `textContent`로 넣는다. 원고를 HTML로 해석하지 않는다. 외부 폰트·이미지·분석 스크립트를 화면에서 요청하지 않는다. 출처 링크를 누르면 사용자가 해당 기관으로 이동하며 새 탭 링크에는 `noopener noreferrer`를 지정한다.

## 브라우저 검사 실행

Playwright 1.56.1과 그 버전에 맞는 Chromium이 필요하다. 별도 임시 경로에 준비하면 연구 저장소에 의존성 파일을 추가하지 않아도 된다.

```bash
npm install --prefix /tmp/atlas-ui299 --no-save --ignore-scripts playwright@1.56.1
node /tmp/atlas-ui299/node_modules/playwright/cli.js install chromium --only-shell
ATLAS_PLAYWRIGHT_MODULE=/tmp/atlas-ui299/node_modules/playwright node integrations/medium-atlas-v299/reader.browser.test.mjs
```

검사 스크립트는 임의의 사용 가능한 포트에 loopback 서버를 열고 종료 시 닫는다. 기본 결과 경로는 운영체제 임시 디렉터리의 `atlas-v299-browser-review`다. `ATLAS_UI_ARTIFACT_DIR`로 바꿀 수 있다. 해당 경로에는 결과 JSON과 상세 화면 PNG 3개를 남긴다. 한글 화면 검수에는 OS의 한글 글꼴이 필요하며 CI는 Noto CJK 글꼴을 설치한다. 브라우저가 없으면 검사를 생략하거나 통과로 표시하지 않고 실패한다.

## 확인 결과와 범위

320px·375px·1440px 각 폭에서 다음 14개 항목을 확인한다.

1. 전체 435편과 목록 12개 로드
2. 한국어 띄어쓰기 검색
3. 상세 세 절·질문 및 제목 초점 이동
4. 출처의 접근 실패와 확인 상태 구분
5. Enter 키를 이용한 근거 범위 펼치기
6. 상세 화면의 수평 넘침과 PNG 기록
7. 관련 해설 이동 및 브라우저 뒤로 가기
8. 새로 고침 뒤 검색어·선택 원고 유지
9. 검색 결과 없음
10. 읽기 경로와 분야의 결합 필터
11. 다음 페이지 이동
12. 없는 원고 ID의 안내
13. 페이지 실행 오류 없음

14. 바로 가기 키보드 이동 시 탐색 URL 보존

전달본 404와 해시 불일치 2건을 더해 총 **44개 화면 검사**다. 원고에 관련 해설 연결이 실제로 있는 경우에 그 이동을 검사하며, 연결이 없는 핵심 원고에 임의 관계를 만들어 넣지 않는다.

로컬 Chromium에서 44개 검사가 통과했다. 한글 글꼴을 적용한 화면 PNG도 별도로 검토한다. GitHub의 `Medium Atlas V2.99 Browser QA`에서 같은 검사를 반복하고 결과와 PNG를 CI 아티팩트로 남긴다. V2.98 모듈의 35개 검사와 기존 원고 검사도 별도로 유지한다.

## 실제 앱에 남은 부분

이 검토 화면의 동작을 실제 AI Studio 앱의 완료로 계산하지 않는다. 실앱의 최신 소스·개요 ID·라우트·컴포넌트 구조와 대조하고 화면에 반영한 뒤 다시 검사해야 한다. 이번 검사는 Chromium의 세 화면 폭에 한정되며 실기기·Safari·스크린리더의 전수 접근성 평가가 아니다. 편집 검토본과 출처의 제한을 유지하며 공개 보류 상태다.
