# 시각 자산 폴더
- `diagrams/` 자체 제작 편집 가능한 SVG 관계도·순서도
- `maps/` 검증된 좌표/시대 범위를 바탕으로 만든 SVG 지도(예정)
- `portraits/` 인물별 자체 제작 AI 역사 재현 이미지(예정)
- `scenes/` 역사 장면 자체 제작 AI 일러스트(예정)
- `asset_manifest.json` 제작·권리·검수·설명 대장

현재 `AST-0001`은 자체 제작 SVG 초안이다. 역사적 계보의 세부 사항은 추가 학술 검토 전까지 공개 승인하지 않는다.
**향후 AI 생성 이미지에는 사용자에게 오해를 주지 않도록 'AI 생성 역사 재현' 캡션을 반드시 기재한다.**
