# VOL-03 V0.5 · 웹 연동용 비교·인과 데이터
- `data/vol03_theology_causality.json`: 신학 쟁점 축 7건, 인과관계 연구 사례 5건.
- 독자가 한 사건의 시대·주장·신학·결과를 서로 탐색할 수 있도록 **해설의 분류와 사실 출처**를 분리.
- `axis_id` / `case_id`: 변하지 않는 로컬 고유 ID. `subject_ids`, `event_ids`, `actors`는 기존 기본 및 VOL03 확장 데이터를 참조.
- `causal_factors`: 논증을 위한 요인 태그이며 당대 사료가 직접 진술한 원인이라는 뜻이 아니다.
- `source_ids`: 출처 목록과 연결, `interpretation_status`는 사람 검수 전 모두 DRAFT.
