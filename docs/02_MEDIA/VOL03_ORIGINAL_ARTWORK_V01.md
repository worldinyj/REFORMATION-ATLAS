## 통일 시각 스타일
- 유럽 후기 중세를 연상시키는 **절제된 회화적 역사 재현**: 자연스러운 인체, 토양색 계열의 옷감, 필사본·돌·나무 재질, 연한 빛, 근경 인물과 맥락 배경.
- 현대 디지털 장비, 사진·카메라의 현존 주장, 의도치 않은 가독성 없는 문자, 왕실 문장·국기·교단 심볼의 근거 없는 조합을 피한다.
- 모든 인물화는 **역사적 초상이 아니라 현대적 창작 이미지**다. 인물 얼굴·나이·두상은 다큐멘터리 수준으로 단정할 수 없다.
- 인물화 4종은 원본 2×2 시트의 고유 영역을 손실 없이 분리하여 PNG로 보관하고, 웹용 WebP로 별도 압축.
- 사건 삽화 2종은 하나의 2분할 마스터에서 독립 영역으로 분리.
- 설명 텍스트는 이미지에 소각하지 않고 사이트의 HTML 캡션·대체 텍스트로 표시하도록 한다.

## 역사학 관련 위험 및 판정
**발도:** ‘Peter Waldo’의 'Peter'는 후대 귀속 가능성이 있으며 이름 표기는 Valdes/Valdo를 우선. 당시 리옹의 실재 경관·주택·교회의 모양을 그대로 그렸다고 주장하지 않는다. [V03-S51]
**위클리프:** 학자의 검은 모자와 큰 필사본은 독자가 역할을 이해하도록 한 상징일 뿐 실제 초상이 아니며 '중세 영어 성경을 혼자 번역'했다는 캡션 금지. [V03-S05]
**후스:** 초기·후대 도상에서 얼굴과 수염 표현이 달라지므로, 16세기 후대에 널리 쓰인 학자 모자·수염 모습을 역사적 사진으로 호칭하지 않는다. [V03-S50,V03-S52]
**지슈카:** 체코 과학아카데미는 2024년 제시된 유해 일부를 근거로 한 얼굴복원에 과학적 근거가 부족하다고 비판했다. 한쪽 눈의 정확한 방향도 불확실하므로 붕대는 상징적 소도구로 표기. [V03-S49,V03-S53]
**설교 장면:** 베들레헴 예배당의 당대 내부를 건축 고증한 단일 현장 재구성이 아님.
**협상 장면:** 문서 3개, 현대 비평판 10개, 1436년 선포 등의 문헌 수를 실내 테이블 소품 개수로 표현하지 않는다. 특정 회의장의 정확한 참가자·좌석을 검증한 장면이 아니다. [V03-S34,V03-S35]

## 공개 규칙
페이지에서 자산마다 눈에 띄는 캡션: **“AI 생성 역사 재현 이미지. 실제 초상·사건 현장 사진이 아닙니다.”**
- 인물 실제 얼굴 여부: `historical_likeness_verified=false`.
- 역사적 장소 건축 고증 여부: `historical_setting_verified=false`.
- 사람 검수·학술 검증 전 `DRAFT`, `APPROVED` 금지.
- 원본 PNG 및 마스터 생성 이미지를 후대 다른 작가의 고유 역사화와 혼동하지 않는다. 기존 작품의 화면을 그대로 복제하지 않았고 온라인 자료는 역사 도상 차이를 이해하는 참고로만 사용하였다.

## 설치와 GitHub 정합성
정본이 될 예정인 `assets/illustrations/vol03/*.webp`는 **지금 GitHub에는 실제 파일이 없다**. [단계별 스테이징 메타데이터](../../assets/illustrations/vol03/ILLUSTRATION_STAGE.json)에 다운로드 ZIP·자산별 SHA256이 있다.
로컬 저장소를 동기화한 뒤 별도 대화 ZIP을 확보해 `python scripts/install_vol03_illustrations.py /path/to/REFORMATION_ATLAS_VOL03_ILLUSTRATIONS_V01.zip --install` 실행. 스크립트는 각 자산 해시를 검사한 후 파일을 정해진 폴더에 저장하고 `assets/asset_manifest.json`을 갱신한다.
설치 전에는 디지털 웹사이트가 해당 경로를 사용하지 않도록 `status=PENDING_BINARY_COMMIT` 관리.
