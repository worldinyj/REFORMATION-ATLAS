## 역사 사실 QA
**01** 리옹(1170년대)과 앙그로냐(1532년)는 같은 시기의 이동 경로가 아니라 **서로 다른 시대의 비교 지점**. [V03-S01,S26]
**02** 옥스퍼드→프라하 점선은 Wyclif 저술의 보헤미아 수용 관계; 실제 필사본 개별 운반 노선·여행자의 동선은 확인되지 않음. Ralph Hanna(2023) 참고.
**03** 프라하, 타보르, 쿠트나호라, 리파니, 이흘라바는 후스파 관련 현안 장소를 위한 핀; 중세 국경/국토 경계/군사작전 지도 아님.
**04** 1530~1532년 왈도파와 유럽 개혁자들의 접촉망을 표현. 주어진 화살표가 개별 지도자의 확정 방문 순서나 정확한 출발점이라는 증거는 아님. [V03-S26,S27,S42]

## 화면 인쇄·접근성
- 한글 폰트를 별도 배포하지 않으며 OS의 CJK 지원 글꼴 필요.
- 편집 프로그램에서 `<text>` 태그를 유지하므로 지명과 설명을 개별 수정 가능.
- 각 SVG에는 기본 `role="img"`와 접근성 `aria-label` 제공; 최종 웹은 더 상세한 대체 텍스트와 주석을 연결할 것.

## 검증 실행 주의
GitHub connector로 파일 저장/본문 접근은 확인. 로컬 container와 connector 간 바이너리 전송이 제약되므로 **GitHub SVG와 PNG/ZIP 로컬 산출물의 해시 일치**는 별도 확인이 필요하다. 별도 확인 전 '동일한 SHA'라고 선언하지 않는다.
