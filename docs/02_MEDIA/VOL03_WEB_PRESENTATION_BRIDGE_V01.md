# VOL-03 · 연구 콘텐츠 ↔ 웹사이트 콘텐츠 색인 V0.1
> 2026-10-25 · DRAFT. 본 파일은 5순위 데이터 통합 시범이며, 사이트 UI·PRD·TRD의 승인본은 아닙니다.

## 목표
`data/vol03_presentation_index.json`은 인물 페이지, 사료 해설, 역사 지도, 영상/이미지 자산 간 연결을 기록하는 **라우팅 후보 및 데이터 계약의 초안**이다. 사이트가 아직 만들어지지 않았으므로 URL을 확정하지 않는다. 후속 PRD 및 UX/UI 단계에서 유저 스토리·슬러그를 검토할 수 있다.

| 표시 단위 | 콘텐츠 | 사용 데이터 | 실제 이미지 상태 |
|---|---|---|---|
| 인물 | 발도, 위클리프, 후스, 지슈카 총 4개 | 인물·연구 원고·지도·출처 | 이미지 WebP는 아직 GitHub 미설치 |
| 역사 장면 | 프라하 설교, 콤팍타타 협상 2개 | 사건 해설·출처·AI 생성 스테이징 | 이미지 WebP는 아직 GitHub 미설치 |
| 지리 | 4개 SVG 개념 지도 | 원본 SVG·자산대장·현대 대표 좌표 | 파일 GitHub에 존재(DRAFT) |
| 연구 | 원전 검증, 판본 계보, 신학 7축, 인과사례 5개 | Markdown · 구조화 JSON | 텍스트 자료 GitHub에 존재(DRAFT) |

## 중요한 안전한 렌더링 가드
1. 현재 `media_safe_to_display=false`이다. WebP는 대화 ZIP 파일에 있으며 GitHub에 없으므로 **없는 이미지를 URL로 호출하거나 자동 노출하지 않는다**.
2. 사용자의 로컬 동기화로 이미지가 들어온 뒤에도 `review_status=DRAFT`이면 실서비스 노출은 반드시 별도 승인한다.
3. 지도 SVG 역시 학술적으로 인증된 옛 국경·여정도가 아니므로 화면에 **“현대 도시 중심 좌표 기반 역사 개념도”** 라벨을 보인다.
4. 인물·사건 본문은 원전/비평판/번역본/서평/교단별 관점을 구분한 출처 ID와 함께 표시.
5. 교리 비교와 인과관계의 요인은 논증에 근거한 분석이며 **문헌 자체가 증명한 단일 원인**이라고 렌더링하지 않는다.
