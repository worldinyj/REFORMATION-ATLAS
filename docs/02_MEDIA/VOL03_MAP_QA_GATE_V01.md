## 제작 방식 / 출처
기존 지도·이미지·타일을 복제하지 않고 SVG의 텍스트·선·원·격자·레이아웃을 새로 구성했다. 각 도시·전투터 인근 좌표와 관련된 참고 링크는 지도 데이터에 표시했다. 12~16세기의 국경·도로·산세·건축물 상세 모습은 확정 고증 전까지 **표현하지 않았다**.
