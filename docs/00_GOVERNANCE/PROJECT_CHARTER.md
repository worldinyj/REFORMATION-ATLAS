# REFORMATION ATLAS — 프로젝트 헌장 V0.1
작성일: 2026-10-25 | 상태: DRAFT | 저장소: worldinyj/REFORMATION-ATLAS

## 1. 목적
예수와 사도들의 초기 교회에서 고대·중세의 개혁 운동, 16세기 유럽 종교개혁, 후대의 부흥·선교 및 세계 기독교까지 역사적 관계를 검증 가능한 자료로 탐색하는 한국어 중심의 디지털 역사 아카이브를 구축한다.

## 2. 역사적 범위와 분류 원칙
- **교회사 2,000년**은 상위 시간축이다.
- **16세기 프로테스탄트 종교개혁(Reformation)**은 그 안의 특정한 역사적 운동이며, 초대교회 자체를 '종교개혁'으로 분류하지 않는다.
- 동방정교회, 가톨릭 개혁, 후대의 부흥과 선교를 포함하지만 모두 루터의 '직계 후손'으로 나타내지 않는다.
- 영국 존 위클리프 → 보헤미아 얀 후스의 사상적 영향은 문헌 근거를 표시한다. 후스 → 루터는 직접 사제 관계가 아니라 후스파의 선례, 1519년 논쟁을 통한 후대 수용 관계이다.
- 개혁의 공과, 종교적 박해, 정치적 맥락, 학계의 이견까지 균형 있게 수록한다.

## 3. 사용자·콘텐츠 목표
주 이용자: 한국어로 세계 교회사와 종교개혁을 탐구하려는 일반 독자, 교회 교육자, 학생, 역사 연구 입문자.
핵심 탐색축: **시대 · 장소 · 인물 · 사건 · 사상 · 문헌 · 관계**.
단위 콘텐츠는 독립적으로 읽히면서 출처와 관련 항목으로 이동할 수 있어야 한다.

## 4. 핵심 개발 원칙
1. 콘텐츠 정확성 및 출처 검증 → 이미지 자산과 지도 → 데이터 모델 → 제품 기획 → 구현.
2. Word(DOCX)는 교정·검토 및 배포본. Markdown은 편집 원본, JSON은 응용 데이터, SVG/PNG는 시각 자산.
3. 사람이 승인하지 않은 콘텐츠는 공개 상태가 될 수 없다.
4. 데이터·문서 모두 Git의 변경 이력과 리뷰를 통해 관리한다.
5. 저작권 허용 여부가 불분명한 외부 이미지·책 본문은 공개 저장소에 저장하지 않는다.

## 5. 초기 범위
8권의 편집 구성을 유지하고 시범 범위는 **존 위클리프(PER-0001), 얀 후스(PER-0002), 마르틴 루터(PER-0003)**이다. 각 인물에 대해 개요, 주요 주장, 반론, 문헌, 사건, 사상 관계, 시각 자산, 검증·표현 유의사항을 기록한다.

## 6. 저장소 브랜치 운영
- `main`: 승인된 안정 기준선.
- `docs/foundation-v0-1`: 콘텐츠 구축 체계의 최초 작업 브랜치.
- 작업 브랜치에서 문서·검증·검토 후 Pull Request 생성. 승인되지 않은 자료를 main에 자동 병합하지 않는다.

## 7. 상태 구분
`DRAFT`(작성 중), `REVIEWED`(사실·출처 및 저작권 검토), `APPROVED`(최종 공개 승인), `PUBLISHED`(공개 배포), `RETIRED`(공개 중지/대체). 지식·역사적 사실의 불확실성 등급은 콘텐츠 승인 상태와 별개로 관리한다.

## 8. 첫 출범 완료 조건
콘텐츠 스키마 + 3인 시범 원고 + 관련 사료 카드 + 관계 및 사건 데이터 + 이미지 관리 규칙 + 수정 가능한 정확한 도식 1개 + 검토 목록이 연결되고, 이후 8권 확대가 가능한지 확인하면 Foundation Gate를 통과한다.
