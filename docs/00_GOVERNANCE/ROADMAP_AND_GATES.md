# 로드맵 및 품질 게이트 V0.1

| Gate | 단계 | 산출물 | 통과 기준 |
|---|---|---|---|
| G0 | 범위·편집 기준 | 헌장, 8권 구성, 검증·권리 정책 | 시대 분류와 용어가 모호하지 않음 |
| G1 | 시범 원고 | 3인 프로필, 사건·관계·문헌 카드 | 모든 검증대상 사실에 출처 / 이견 명시 |
| G2 | 매체 제작 | 자체 제작 삽화, SVG 지도, 시각 자산 대장 | 위치·연대 검수, 권리·AI 생성 표시 |
| G3 | 역사 검토 | 교차 검증 기록, 독자/전문가 의견 | 역사적 오류 및 허위 인과 관계 없음 |
| G4 | 데이터화 | 인물·장소·사건·사상 JSON, 원고 MD | ID 유일, 참조 무결성, 출처 필드 충족 |
| G5 | 기획서 | 대상자·가치·IA·MVP 범위 | 콘텐츠 사례로 기능 요구 정당화 |
| G6 | PRD → TRD → UX/UI → TASKLIST | 개별 마크다운 계획서 | 상호 일관성과 검증 가능한 인수 기준 |
| G7 | 구현·검수 | 반응형 웹, 지도·연대표·관계도 | 콘텐츠 추적·접근성·성능·배포 QA 통과 |

### 단계별 순서
G0→G1은 우선 실시. G2를 G1과 병행하되 역사적으로 정밀한 지도는 위치 데이터 검증 후 제작. G3와 G4는 반복할 수 있다. G5~G6는 G3/G4의 시범 데이터 기준을 우선 통과한 뒤 본격화한다.

### 검토 책임
- Researcher: 자료 수집 및 출처 기록
- Historian/Reviewer: 사실·계보·반론·맥락 검토
- Editor: 한국어 표현·접근성·균형 검토
- Asset Editor: 저작권·출처·자체 제작 문서화
- Human Approver: `APPROVED`로 승격하는 최종 의사결정

### 시범 제작 우선 작업
1. 자료군별 워드 목차와 항목 템플릿 작성.
2. PER-0001~3 각각 사건 2~3개와 주요 저술/논쟁 연결.
3. 영국 옥스퍼드→보헤미아 프라하의 영향 관계, 후스 관련 1519년 라이프치히 논쟁을 각기 다른 관계 유형으로 모델링.
4. 관계도 SVG(설명·범례와 역사적 주의문 포함), 후대 인물화 스타일가이드 작성.
5. 사료 교차 검토 후 MVP 기능 초안 작성.

### 승격 규칙
자료가 부족하거나 사실관계가 논쟁적인 내용은 `DRAFT`로 유지. 사이트에 공개하기 위해서는 Human Approver의 승인 기록 필요. 원고 편집과 공개 배포를 동일시하지 않는다.
