# 역사 편집·저작권·AI 매체 정책 V0.1

## 1. 사실관계와 관점
- 모든 핵심 주장에 자료 링크·서지·접근일·인용 대상 문맥 기록.
- 가능한 경우 1차 사료 + 신뢰할 수 있는 2차 연구를 병행한다.
- 확인된 사실 / 합리적인 해석 / 전승 / 학계 이견을 서로 구별한다.
- 당시 인물·운동의 자칭과 후대의 명칭을 구분하고, 개신교·가톨릭·정교회 관점을 무리하게 하나로 합치지 않는다.
- 인용문은 법적·서비스별 조건에 따라 최소한으로 사용한다. 웹사이트 본문은 새로운 한국어 설명으로 작성한다.

## 2. 저작권 및 유료 문헌
- 유료 문헌·학술자료의 전문, 장문의 연속적인 번역/초록 대체물을 그대로 게시하지 않는다.
- 읽고 확인할 수 있는 합법적 자료에 근거해 자체적으로 **맥락 → 핵심 쟁점 → 연구자의 주장 → 관련 증거 → 다른 해석 → 후대 영향 → 참고문헌** 형식으로 해설한다.
- 유료 본문 접근 권한이 없으면 공개 초록/서평/목차/다른 출처로 확인한 범위만 표기하고 미열람 본문 내용을 단정하지 않는다.
- 공개 자료도 출처표시와 저작권을 확인한다. 라이선스가 불분명하면 원본 미수록, 메타데이터와 외부 링크만 기록.
- 오래된 원저작물이 퍼블릭도메인이어도 현대 번역문·사진·주석·편집물은 별도 권리 검토.

## 3. 직접 만드는 시각 자산
- 인물화·역사적 장면: 새로 제작한 일러스트를 기본으로 사용. 항상 'AI 생성 역사 재현 이미지/실제 초상 아님' 등의 표시를 붙인다.
- 이미지가 역사적 사실의 증거처럼 제시되지 않도록 별도의 '당대 원본 사료' 화면과 분리한다.
- 지역 지도: 확인된 현재 지명과 당대 지명, 시점별 경계, 위치, 지도 투영/기준을 명확히 한다. 검증된 지리정보로 SVG를 제작하고 이미지만을 근거로 지리·영역·복장 등을 추론하지 않는다.
- 관계도·타임라인: 직접 SVG 제작. 인물 관계에는 direct_influence / later_reception / parallel_reform / debate / opposition 등 관계 유형을 표기.
- 생성 프롬프트·생성일·모델/도구·검토 상태·파일 해시(가능하면)·대체 텍스트·저작권 설명을 자산별로 기록.
- 외부 실존 인물의 역사 초상은 참고할 수 있으나 원본 이미지 복제 의도가 되지 않도록 주의. 시대적 복장 등 불확실한 재현 요소는 설명한다.

## 4. 자료 등급
`evidence_level`:
- `primary`: 원문·동시대 사료에 직접 근거
- `scholarly`: 전문 연구서·학술 해석에 근거
- `reference`: 신뢰 가능한 개설 자료
- `tradition`: 후대 관습·전승, 사료 논쟁이 있을 수 있음
- `unverified`: 추가 검증 필요

별도 `certainty`: `established`, `debated`, `approximate`, `unknown`. 이 둘과 `publication_status`는 별개 필드.

## 5. 예시 표현
- '1517년 10월 31일 루터가 95개조 논제를 발표/서한 발송'은 확인된 문서와 연혁을 명시하고, **성교회 문에 직접 못을 박았는지 여부는 논쟁적**이라고 설명한다.
- '후스는 루터의 스승'이라고 쓰지 않는다. 후스의 사상 및 상징이 16세기 루터파 논쟁에서 후대 수용된 맥락으로 설명한다.
- 위클리프의 영어 성경 번역은 '위클리프와 관련된 추종자들의 번역 운동'으로 정리하고 독역 여부를 단정하지 않는다.

## 6. 공개 게이트
제3자 권리 불명 자산 공개 금지, AI 재현 표시 누락 공개 금지, 사료로 뒷받침되지 않는 지도 표기 공개 금지, `APPROVED` 없는 콘텐츠 공개 금지.
