# V1.40 종교개혁 ATLAS 탐색 네트워크 확장

**연구 전용 · 2026-10-30**

V1.39의 15노드·13관계를 기반으로 제3권 위클리프·후스, 제5권 이냐시오·테레사를 추가해 25노드·24관계의 탐색망을 작성했다.

## 사료 연결 교정
기존 V1.19 교차권 자료는 `OV-P-009` 위클리프와 `OV-D-005` 『교회론』을 연결했다. 그러나 정본 `data/overview/events_documents_v01.json`의 `OV-D-005`는 1413년 **후스의 De ecclesia**이다. 위클리프의 동명 저술과 혼동해서는 안 되므로 V1.40 그래프는 `OV-P-010` 후스를 저자로 연결하고 과거 관계를 오류 후보로 명시했다. 원본 V1.19 파일은 보존하며 자동 마이그레이션은 금지한다.

프라하 4개조(`OV-D-006`)는 1420년경 후스파 운동의 문헌이므로 1415년에 사망한 후스의 직접 저술이 아니다. 위클리프의 성경 번역 운동과 개인 번역 저작권도 구분했다.

## 제5권 확장
이냐시오의 『영신수련』과 테레사의 『완덕의 길』·『영혼의 성』에 임시 저작 ID를 부여하여 정본 인물 ID와 연결했다. 이 임시 ID는 새로운 정본 저작의 발행 승인을 의미하지 않는다. 트리엔트 공의회 사건과 가톨릭 내부 개혁 주제도 연결했다.

## 다음 사료 검증
위클리프 동명 『교회론』의 저작·판본 식별자를 별도 생성할지 검토하고, 후스 저술과 혼동하는 다른 링크가 있는지 전체 저장소 검색이 필요하다. 가톨릭 영성 저작은 자필본/초판/후대 번역 검증 후 정본 ID 승격을 검토한다.
