# V2.07 · 역사 원고의 문장 분류·고위험 주장 정밀 작업

## 이번 실제 작업

V2.02 역사 원고 10편의 124개 본문 검토 문단에서 V2.06이 추출한 522개 후보 문장을 검토했다. 이 가운데 **마르부르크 문서관 소장기호 `E I 3.1, Nr. 54`에서 마침표가 문장 구분으로 오인된 결함 1건을 수정**하여, 현재는 원고 오프셋을 보존하는 **521개 문장형 검토 단위**가 되었다. 텍스트 수정 없이 레이어를 추가했다.

모든 521개 문장형 단위에 자동 제안 분류를 부여했다. **결과는 전문가가 분류한 최종 판정이 아니다.** V2.04의 30개 최우선 `FOCUS` 모두를 정정된 문장 1개씩에 정확하게 연결하고, 30개 사실 검증이 가능한 **잠정 연구 명제**를 별도로 작성했다. 이 명제들은 30건의 V2.05·V2.06 출처 조사 기록과 이어지지만 특정 원전의 실문·행·쪽을 대조하지 않았으므로 모두 공개 불가다.

| 정량 항목 | 값 |
|---|---:|
| 최신 본문 원고 | 10편 |
| 검토 대상 문단 | 124 |
| V2.06 문장 후보 | 522 |
| 소장기호로 인한 잘못된 경계 복구 | 1 |
| V2.07 문장 검토 단위 | **521** |
| 우선 검증 가능한 잠정 명제 | **30** |
| 이 명제를 V2.05·V2.06 출처 조사에 연결 | **30/30** |
| 전문가 문장 분류·원본 교감·출판 승인 | **0** |

## 문장 자동 분류

사용된 단일 자동 제안 분류는 연구자가 나중에 수정하기 위한 입력일 뿐이다. 한 문장 안에는 역사적 사실과 신학적 설명, 판본 주의사항이 동시에 존재할 수 있다. 분류 우선순위는 질문 → 문헌·판본 → 사건·연대 → 편집상 주의 → 신학 설명 → 일반 역사 맥락의 순서다.

## 검증상 고정되는 원칙

1. **실제 문장 원문/오프셋 대조:** 모든 문장 시작·끝은 Unicode 코드포인트 `[start_char,end_char)`로 원고에 연결된다. V2.02 원문을 수정하면 V2.03부터 참조 오프셋을 재생성해야 한다.
2. **서지 출처 ≠ 원전 문장 증명:** 30건 모두 출처 조사가 있지만 해당 문장에 대한 직접 사료·비평판 본문 대조, 판면, 쪽수, 조항은 여전히 미완료다.
3. **역사적 상충 판단은 중립적으로:** 1517년 문 게시 전승·1521년 명언 전승, 마르부르크 문서 이본, 1530/1531/1540 아우크스부르크 판본을 단일 확정 문장으로 압축하지 않는다.
4. **분석/발행 분리:** 자동 분류가 많아도 `can_ship=false`다. Google AI Studio 웹앱의 공개 색인·지도·인물 이미지에 반영하지 않는다.
