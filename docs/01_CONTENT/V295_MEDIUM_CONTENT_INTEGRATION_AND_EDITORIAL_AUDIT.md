목록에는 제목과 도입을, 상세에는 본문 세 절과 질문을 표시한다. 출처의 scope/access 및 확인 한계를 보존한다. 편집용 provenance·검증 상태는 본문과 분리해 다룬다. `source_basis_status`가 상속 연구인 원고를 출처가 전혀 없거나 감수 완료인 것으로 표시해서는 안 된다. 연대 경로에서 지도 좌표나 정확한 날짜를 자동 추출하지 않는다.

## 검증과 재생성

저장소 루트에서 다음 명령을 사용한다.

```bash
python3 scripts/build_v295_medium_delivery.py --check
```

이 명령은 모든 입력 파일 체크섬, 435편 본문의 원본 일치, 자료별 출처 ID의 유일성, 관련 해설·분야·경로·비교표·FAQ 참조, 상속 연구 연결, 생성 파일의 재현성을 검사한다. `--check`를 생략하면 동일한 두 산출물을 다시 생성한다. 외부 네트워크나 앱에 쓰지 않는다.

기존 검증·빌드 7종 및 git diff --check도 별도로 실행한다. 역사적 사실의 전문 감수, 외부 출처 재조회, 실제 앱의 가져오기·검색·모바일 화면 검증은 이 구조 검사와 다른 작업이다.
