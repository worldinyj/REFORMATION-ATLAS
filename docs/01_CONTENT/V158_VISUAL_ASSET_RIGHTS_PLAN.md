# V1.58 · 종교개혁 역사 시각자료 권리 검토

**2026-10-31 · 연구 전용 초안 / 이미지 반입 보류**

## 범위
V1.56 독서 페이지에 연결할 시각자료 후보 **14건**을 등록했다. 인물화 5건, 역사 장소 4건, 문헌 영인 4건, 역사 지도 1건이다. 현재는 개별 이미지가 확정된 목록이 아니라 **이미지를 찾고 제작하기 위한 조사 레지스트리**다. 실제 이미지 다운로드·게시·원전 이미지 교감은 하지 않았다.

## 권리 확인 순서
1. 실물 작품의 제작자·시기·저작권 상태를 확인한다.
2. 현대 사진이나 고해상도 디지털 복제물은 원작과 구분하여 제작자·소장기관·복제물 권리·약관을 확인한다.
3. Wikimedia Commons를 사용한다면 개별 **파일 설명 페이지**에서 저작자, 라이선스, 크레딧 표기 조건을 확인한다. Wikimedia Commons 전체를 하나의 공통 라이선스로 취급하지 않는다.
4. Europeana에서 발견한 자료라면 각 **디지털 객체의 Rights Statement**를 확인한다. Europeana의 CC0 메타데이터 정책은 **수록 이미지 자체가 모두 CC0라는 뜻이 아니다**.
5. 불명확하면 `NOT_EVALUATED` 및 `approved_to_publish=false`를 유지한다. 출처 URL을 알고 있다는 이유만으로 다운로드 또는 재배포하지 않는다.
6. 공공영역 자료라도 원작·영인 제공처를 표기하고, 학술적 정확성을 위해 작품 제작 연대·인물의 생전 초상 여부를 구분한다.

## 우선 후보
- 인물화: 위클리프, 후스, 루터, 츠빙글리, 칼뱅
- 장소: 비텐베르크, 프라하, 보름스, 마르부르크
- 문헌: 아우크스부르크 신앙고백, 1536·1559년 『기독교강요』, 트리엔트 교령
- 지도: 유럽 종교개혁의 도시·개혁 네트워크

**현재 개별 파일의 저작권을 확인했다고 주장하지 않는다.** 실제 파일 URL과 라이선스 식별자가 없는 상태에서는 자동 반입을 차단한다.

## 웹앱 탑재 조건
각 파일에 원본 이미지의 정확한 식별자, 실제 제공기관, 권리표시 URI, 표기 문구, 이미지 사용 목적 및 최종 검토자의 승인 여부를 채운 후에만 배포 가능성을 검토한다. 이 단계는 연구 브랜치 전용이며 main과 AI Studio 코드에는 영향을 주지 않는다.
