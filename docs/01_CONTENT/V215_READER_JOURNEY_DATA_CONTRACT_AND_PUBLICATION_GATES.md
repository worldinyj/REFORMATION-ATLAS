# V2.15 · 독자 탐색 여정 데이터 계약 및 UI 적용 전 학술 보류

이 산출물은 지도 기술 문서가 아니라 **역사 인물·문헌·장소를 독자가 따라 읽는 순서와 실제 단계별 한국어 해설**을 제안하는 연구 문서다. 웹앱을 직접 생성하거나 수정하지 않는다.

## 자료 모델
- `journeys`는 독서 질문·순서·주제·독서 시간과 6단계 목록을 갖는다.
- `stages`는 문단별 새 해설, V2.11의 실제 문장 ID, V2.12 맥락 해설 ID, V2.14 역사 사건/문헌/장소/인물 ID를 가진다.
- `HOLDING`은 프라하, 프린스턴, 투르 소장처 등으로 사건지도에 표시하지 않는다.
- `COMPARISON`은 교육적 연결이며 인물 간 직접 역사적 인과 관계를 주장하지 않는다.
- `EVENT`의 장소는 V2.14에서 정한 좌표 정밀도를 그대로 상속하며 공개 지도 핀은 허용하지 않는다.

## 공개 전 우선 검토
1. 단계별 새 문장과 그 아래 연결된 V2.11 문장이 동일한 세부 역사 주장을 뒷받침하는지 인문학 전문가 검토.
2. GHDI 및 도서관 서지의 역사적 문언과 원본 필사본·고판본을 구분.
3. 취리히 시의회의 개혁·반대자 탄압, 마르부르크 성만찬 합의의 한계, 가톨릭 공의회의 입장을 균형 있게 제시.
4. V2.13 주제별 읽기(PR #53)의 구조와 나중에 합칠 때 중복·ID 충돌을 수동 검토.
5. 11개 장소 연구지도, 소장도서관, 역사적 건물 좌표, 사진·인쇄본 권리가 확보되기 전에는 웹앱 공개 금지.

**`can_ship=false`. 역사 원문 이미지 직접 교감 0건, 전문가 승인 0건, 웹앱 반영 0건.**
