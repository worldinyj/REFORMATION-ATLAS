# V2.16 · 탐색 단계별 근거 표시 규칙과 출판 차단 정책

하나의 탐색 장면에 포함된 여러 문장 중 단 한 개의 역사 명제만 독립 검토됐더라도 그 **장면 전체를 최종 입증됨으로 표시할 수 없습니다**.

실제 앱에서는 사료 검증의 세 단계를 분리해야 합니다.

1. `SOURCE_NAVIGATION`: 해당 문헌이나 도서관이 존재하고 URL이 열림.
2. `EDITED_SOURCE_ALIGNMENT`: 자료의 번역·비평판 서론·전사에서 좁은 사실을 찾음.
3. `ORIGINAL_WITNESS_AND_SPECIALIST_REVIEW`: 필사본·초기 인쇄본의 관련 원문을 직접 교감하고 연구자 평가 완료.

**현재 3단계 완료는 0건.** GitHub Actions 자동검증은 사료 목록과 원고 연결의 무결성만 확인합니다.

마르부르크 취리히 Z판의 추가 문구, 칼뱅 1541년 최초 프랑스어판/1560년 최종 프랑스어판, 트리엔트 공의회 1547년 칭의/1563년 신학교 규정 등을 특히 주의합니다.

오류 방지: '원전 확인' 버튼이나 초록색 완료 배지를 앱에 출력하지 말며, 원본 확인 전에는 ‘연구 중인 역사 설명’으로 표기합니다. 원본 문헌 이미지의 재사용권은 별도 계약이나 공개 라이선스를 확인해야 합니다.
