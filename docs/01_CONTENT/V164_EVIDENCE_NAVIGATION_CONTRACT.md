# V1.64 근거 중심 탐색 계약

**연구 전용 · Google AI Studio 앱과 main 변경 없음**

V1.63의 증거 카드 8개를 V1.62 조항 비교 매트릭스 및 V1.61의 판본 5개, V1.56의 독서형 페이지와 연결했다. 독자가 한 주장을 선택하면 **주장 → 해당 증거 카드 → 관련 판본 → 해설 페이지**를 차례로 열도록 하는 데이터 계약이다. 실제 UI 구현은 아직 하지 않았다.

## 탐색 절차
1. 비교 매트릭스에서 신학 주제를 선택한다.
2. 해당 증거 카드의 근거 유형과 출처를 표시한다.
3. 판본 ID, 연도, 자료 성격을 보여준다.
4. 역사적 맥락을 읽을 수 있는 독서 페이지로 이동한다.
5. 근거가 편집본·전사본·2차 해설일 경우 **원본 직접 교감 미완료** 표지를 숨기지 않는다.

## 고정 규칙
- 1530년 제출본, 1531년 인쇄본, 1540년 수정판을 단일 실물 원본으로 처리하지 않는다.
- 1536년 『기독교강요』 초판과 1559년 최종판을 동일 텍스트로 표시하지 않는다.
- 인쇄본·이미지의 권리 확인이 없으면 영인 이미지를 표시하지 않는다.
- V1.63 증거의 원문 대조 상태가 false이므로 이 탐색 계층에서 true로 바꿀 수 없다.
- 추가 출처 URL은 원본 증거 카드에서 확인한다. 경로 데이터만으로 새로운 학술적 증거가 생기지 않는다.

## 구현 안내
`data/contracts/atlas_v164_evidence_navigation.json`에서 claims[].matrix_id와 editions[]를 사용한다. 증거 본문과 URL은 `atlas_v163_source_evidence_cards.json`, 조항 비교는 `atlas_v162_edition_article_matrix.json`, 판본 메타데이터는 `atlas_v161_edition_comparison_cards.json`에서 가져온다. historical_reader는 V1.56의 심층 페이지다.

상세 데이터의 내용과 개별 판면은 편집자가 직접 검토해야 하며, 현 단계의 성공적인 참조 검증을 학술 검증으로 표시해서는 안 된다.
