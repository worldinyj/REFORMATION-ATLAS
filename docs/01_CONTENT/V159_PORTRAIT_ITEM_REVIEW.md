## 실물 초상과 후대 그림을 구분하는 이유
‘위클리프의 초상화’라는 이름만으로 당대에 화가가 위클리프를 보고 그렸다고 추정할 수 없다. 위클리프는 1384년에, 후스는 1415년에 사망했으므로 각각 1714년과 1570년경 초상은 **명백히 후대 제작**이다. 그러므로 앱의 설명에는 ‘후대 초상’ 또는 ‘후대에 재현한 모습’으로 기재한다.

## 권리 판단 현황
각 Commons 파일 설명 페이지는 공공영역 또는 PD-Art 복제 관련 권리표시를 제공한다. 다만 **법역별 제한, 원작과 현대 복제 파일의 차이, 소장기관의 이용조건**을 완전히 검토해 앱 반입을 승인한 것은 아니다. 권리 판단 필드와 실제 사용 승인 필드를 구분하고, 다섯 건 모두 자동 게시 보류 상태를 유지한다.

## 화면 구현 기준
인물 카드의 그림 설명에는 작가/제작 시기/동시대 또는 후대 여부를 함께 표시한다. 원본 이미지의 제작 연대를 인물의 생몰연대처럼 착각하지 않도록 한다. 실제 파일 다운로드 및 이미지 최종 배포는 해당 파일의 현재 개별 라이선스 확인과 편집 승인 뒤 진행한다.
