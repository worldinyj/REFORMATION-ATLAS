# V1.52 위클리프 1886년판 대체 접근 조사

**2026-10-31 · 연구 전용**

SIEPM 중세철학 디지털 도서관이 1886년 *Tractatus de ecclesia*를 searchable로 표시함을 다시 확인했다. Google Play Books에도 별도 서지 항목 두 건이 있으며 1886년 Wyclif Society 발행, 600쪽, 무료 전자책으로 표시된다. 그러나 웹 검색에 표시되는 목록만으로 실제 257쪽과 467쪽 또는 Loserth의 서문 원문을 읽었다고 간주할 수 없다.

추가 단서로 CiNii의 1966년 재인쇄본은 **Vienna manuscripts에서 편집한 1886년판 재인쇄**라고 기록한다. 이는 편집에 빈 소재지가 언급된다는 단서일 뿐, 완본 필사본 3개의 상세 서가번호를 입증하지 못한다.

| 대상 | V1.52 판정 |
|---|---|
| 1886년판 실재·서지 | 확인 |
| SIEPM 검색 가능 판본 목록 | 확인 |
| Google Play Books 판본 목록 2종 | 확인 |
| 257쪽 1행 장번호 | 판면 직접 확인 안 됨 |
| 467쪽 29행 장번호 | 판면 직접 확인 안 됨 |
| Loserth 서문 | 직접 읽지 못함 |
| 빈 소재 완본 3종의 개별 서가번호 | 미확인 |

접근 시도에서 로컬 실행 환경은 SIEPM 도메인의 DNS 조회를 수행하지 못했다. 이것은 사용자가 웹브라우저에서 접근할 수 없다는 의미가 아니다.
