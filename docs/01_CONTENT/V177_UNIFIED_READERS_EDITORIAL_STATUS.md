# V1.77 · 심층 10편 통합 및 기준 보정

기존 V1.71 위클리프·후스, V1.72 루터, V1.74 마르부르크, V1.76 나머지 다섯 편을 **원고 중복 작성 없이** 단일 독서용 연구 데이터로 통합했다.

## 분량 판단의 정정
이전의 2,000자 달성 판정은 **공백 포함 본문 수**였다. 이번 통합 대장은 공백을 제외한 본문 길이를 저장한다. 그 결과 열 편 모두 2,000자 미만이다. 이 숫자는 앞선 배치의 글자 수와 기준이 달라 직접 비교할 수 없다.

| 주제 | 공백 제외 문자 수 |
|---|---:|
| 위클리프 | 1,950 |
| 후스 | 1,774 |
| 루터 1517 | 1,650 |
| 루터 1521 | 1,557 |
| 마르부르크 | 1,601 |
| 아우크스부르크 | 1,723 |
| 칼뱅 1536 | 1,604 |
| 칼뱅 1559 | 1,575 |
| 취리히 | 1,628 |
| 트리엔트 | 1,598 |

**핵심 개선:** 기존 분산된 원고들을 같은 출처 ID·본문 필드·글자 수 기준·미승인 게이트로 일원화했다. 원고의 학술적 진위나 사료 직접 교감이 완료되었다는 뜻은 아니다.

## 다음 반복 단계
- 우선 루터 1521·칼뱅 1559·트리엔트 등 낮은 분량 원고에 문헌 논쟁과 연대별 증거 단락을 추가한다.
- 본문 목표는 **공백 제외 2,000자**로 통일한다. 제목·주석·출처 URL은 본문 분량에 포함하지 않는다.
- 이후 주장별 사료와 판본 ID를 연결하고 전문가 감수 게이트를 별도로 유지한다.
