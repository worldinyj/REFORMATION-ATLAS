### 접근 수준 구분
- **OPENED_HTML**: 기관 설명, 편집·번역 역사 문헌, 학술 요약 페이지 등을 열어 확인. 해당 페이지 안에 역사 문서 번역이 있더라도 실물 사료 직접 교감은 아니다.
- **SEARCH_RESULT_EXCERPT_ONLY**: 취리히 문서관 `E I 3.1, Nr.54`는 검색 결과의 자료 목록 설명만 확인했으며 원본 페이지 열람 요청은 시간 초과였다. **그 차이를 데이터에 명시**했다.
- 역사학·교파 연구 자료, 소장기관의 안내, 서지 목록, 비평 번역, 19세기 교회사 문헌을 하나의 '1차 사료 검증'으로 뭉뚱그리지 않았다.
