# V1.28 — 제3·4권 웹앱 반입 전 승인 보류 패키지

**2026-10-30 / 연구 전용 / main 미수정**

제4권 루터 16건, 칼뱅 16건의 역사적 주장과 각 저작 데이터에 선언된 source_id를 전수 조사하였다. 총 32건의 source_id 참조는 원본 데이터 목록에 모두 존재한다. 이 결과는 **구조적 참조 무결성**만 뜻하며, 모든 출처가 실제 주장을 지지한다는 의미가 아니다.

## 의미론적 위험군
- 루터 1517년 교회문 부착은 역사적 전승 논쟁을 표시해야 한다.
- 루터의 농민전쟁 관련 저작과 1543년 반유대주의 저술은 각각 편향된 원전과 현대 학술 해설을 구분하고, 해로운 역사적 사상을 맥락 없이 재현하지 않는다.
- 칼뱅 『기독교강요』의 1536·1541·1559·1560년 판본은 별도 텍스트 객체로 유지한다.
- 1549년 Consensus Tigurinus는 신학적 합의 문서와 2차 해설을 구분한다.
- 1553년 세르베투스 사건은 칼뱅 개인의 역할, 제네바 의회 법적 절차, 카스텔리오의 반론을 확인한 뒤 서술한다.
- 제3권 위클리프파 성경의 Genesis·Exodus·Lamentations 직접 필사본 판독은 여전히 미완료다.

## 승격 절차
1. source_id 및 권/인물 도메인 일치.
2. 출처의 접근 수준(초록/전문/판면) 점검.
3. 역사적 주장과 **관련 근거 문단의 실제 대응** 확인.
4. 판본과 날짜 정밀도 확인.
5. 원문·현대 번역·영상/사진의 권리 확인.
6. 전문가 검토 및 명시적 출판 승인.

현재 V1.28은 1단계를 32건에 대해 실행했다. 2~6단계는 미완료이며 외부 앱에 자동 반영하지 않는다.
