# V2.49 B첩 네 단어의 소장본별 선택 대조

DRAFT · 2026-11-03 · 공개 보류

빈 O90과 뮌헨 O91의 B1r·B3r 사진을 다시 확보하여 네 단어를 대조했다. 두 소장본의 읽기는 모두 일치한다. 사진 네 면은 이전에 본 면의 재검토이며, 처음 확보한 원판 네 면으로 가산하지 않는다. 이번에 추가한 것은 해당 단어의 명시적 대조 기록 여덟 건이다.

## 1. 이번에 직접 확인한 범위

B1r 둘째 줄의 rad, B3r 24행의 hiemit, 27행의 mich, 28행의 ihr를 읽었다. 행 번호는 HAB 목록이 제시한 본문 행을 기준으로 사진의 위치와 맞췄으며 난외문을 별도 본문 행으로 세지 않았다. 뮌헨 사진은 13·17, 빈 사진은 9·13이다. 같은 숫자의 캔버스가 같은 장차를 의미하지 않는다. 이 차이는 빈본 A2·A3의 결락 때문에 생긴 대응 관계와 일치한다.

| 장차·행 | 뮌헨 O91 | 빈 O90 | 판정 |
|---|---|---|---|
| B1r·2 | rad | rad | 일치 |
| B3r·24 | hiemit | hiemit | 일치 |
| B3r·27 | mich | mich | 일치 |
| B3r·28 | ihr | ihr | 일치 |

## 2. HAB 목록과 연결되는 부분

HAB 1221항은 대표 소장본과 일곱째 소장본의 B첩에서 이번 네 읽기를 똑같이 기재한다. 반면 두 책의 A4r 두 단어는 서로 다르다고 설명한다. 따라서 이 네 B첩 단어는 적어도 목록의 두 프로필을 구별하는 지표가 아니다. 이번 직접 관찰한 빈본과 뮌헨본에서도 이 네 지점은 차이를 보이지 않는다. 목록의 보고와 두 원판 사진은 서로 다른 증거 수준으로 유지한다. HAB 두 책의 사진을 확보했다는 뜻은 아니다.

## 3. 표제·A첩·B첩을 나누어 기록하는 이유

V2.47에서 빈본과 뮌헨본의 표제 철자는 달랐지만 A4r의 선택 두 단어는 같았다. 이번 B첩 네 단어도 일치한다. 이에 비해 HAB 목록의 대표 O91과 일곱째 O91은 A4r이 다르고 선택 B첩은 같다. 표제의 교정 여부만으로 전 본문의 상태를 예측하는 방식은 이 자료를 제대로 표현하지 못한다. 데이터는 소장본, 장차, 지점, 증거 종류를 함께 저장한다. 몇 지점의 일치를 완전한 인쇄 상태 동일성으로 바꾸지 않는다.

## 4. 활자 조판과 인쇄 순서는 별도 문제다

단어 네 개와 주변 행의 유사성만으로 두 책이 동일 조판, 같은 인쇄 시점, 같은 교정 순서를 갖는다고 확정할 수 없다. 종이·워터마크·활자 손상·인쇄 압력·제본 이력은 이번에 분석하지 않았다. WA 15의 Aa/Ab 불일치도 여전히 보류한다. 부분 읽기가 맞는다는 사실은 편집 기호 전체를 해결한 성과와 구분한다. 독립적인 사건 증언이 새로 추가된 것도 아니다.

## 5. 확인하지 못한 것

HAB의 두 청구기호를 대상으로 공식 디지털 자료 경로를 검색했으나 식별 가능한 원판 사진 링크는 확보하지 못했다. 검색 결과가 없다는 사정으로 미디지털화 상태를 확정하지 않는다. 관련 없는 필사본 자료는 대상 인쇄본으로 채택하지 않았다. 소피아 편지 숫자의 최종 판독과 1526년 청원 원판의 신규 판독도 없다. 빈본 결락 A3r의 문장부호는 계속 미확인이다.

## 6. 재현과 권리

이미지 URL 네 개와 다운로드 크기·SHA256을 JSON에 남겼다. 이번 이미지는 작업 공간 정리 후 재확보한 자료다. 뮌헨은 PDM, 빈은 NoC-NC 및 기존 목록의 상업적 재이용 제한 종료 정보를 유지한다. 접근 가능성을 상업 이용 허가로 바꾸지 않는다. 이미지 바이너리는 GitHub에 추가하지 않는다. 자동 검사는 소장본별 위치·관찰값·수량·보류 조건을 검증하며 사람의 원판 판독을 대신하지 않는다.
