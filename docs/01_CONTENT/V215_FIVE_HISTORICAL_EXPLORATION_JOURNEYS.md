### 4단계 · 1563년 제23회기: 신학교 규정의 목적

공의회의 신학교 규정은 성직자 후보자의 교육과 훈련, 주교의 감독 책임을 제도화하려는 조치였다. 의롭다 함에 관한 교리적 설명과는 다르게 실행 기관과 재정·교육의 문제가 이어진다. 공의회 결의 날짜와 각 교구가 실제로 학교를 세운 날짜가 같다고 가정하면 안 된다.

- 자료 연결: V2.11 **TRENT** / 문장 SNT-V211-TRENT-0010 / V2.12 RDR-V212-10
- 사건: EVENT-GEO-V214-19
- 역사 장소: 트렌토 / 소장기관: 해당 없음
- 실제 읽을 문장: “1563년 7월 15일 제23회기의 신학교 규정은 성직 후보자 선발, 교육과 훈련, 주교의 감독 책임을 구체적으로 다룬다.”
- **사료 주의:** 공의회 결정은 현장 시행의 증거가 아니며 교구별 사례 미조사

### 5단계 · 1523년 취리히: 도시의 권력이 한 개혁

취리히 시의회는 도시 안에서 예배와 질서에 관한 결정을 집행한 주체였다. 이는 전 가톨릭 세계를 대상으로 규정을 제시한 트리엔트 공의회나 여러 제후가 모인 제국의회와 법적 위상이 다르다. 개혁의 제도화라는 공통 질문으로 비교하되 기관을 동일시하지 않는다.

- 자료 연결: V2.11 **ZWINGLI** / 문장 SNT-V211-ZWINGLI-0001 / V2.12 RDR-V212-05
- 사건: EVENT-GEO-V214-06
- 역사 장소: 취리히 / 소장기관: 해당 없음
- 실제 읽을 문장: “취리히의 개혁은 지도자 한 사람의 성경 해석이 예배당 내부에만 영향을 준 사건이 아니다.”
- **사료 주의:** 서로 다른 정치기관과 종교적 권한을 동일한 거버넌스로 표현하지 않음

### 6단계 · 결정과 시행 사이: 아직 비어 있는 지도

제국 칙령이나 공의회 교령의 발행 연도를 알아도 모든 지역에서 실제 적용한 장소와 날짜는 아직 알 수 없다. 지역별 제후·시의회·교구 기록은 다음 원전 조사 과제다. 현재 자료로는 이 미확인 구간을 임의의 지도 핀으로 채우지 않고 ‘추가 사료 필요’로 남기는 것이 정확하다.

- **사료 주의:** 미조사된 지역 시행을 공의회의 의결 장소로 자동 귀속 금지
