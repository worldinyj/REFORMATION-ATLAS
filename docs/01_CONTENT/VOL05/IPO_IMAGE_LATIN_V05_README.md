## 이번 단계에서 할 수 있었던 검증

오스트리아 기록 2594303의 링크 목록에서 이미지 요청 주소가 실제 존재하는지 확인했다. \`getimage.aspx?deid=0&klid=9&sqnznr=1&veid=2594303&width=200\` 형식의 링크가 제공된다. 그러나 이미지 1·31·66번 모두 브라우저 응답에서 **캐시 오류**가 발생해 원본 사진은 읽지 못했다. 사본 2594304의 이미지도 직접 열어 문자 판독한 상태가 아니다.

APW 디지털 포털은 접근 제한 응답(Anubis), 보충판 서비스는 시간초과로 읽지 못했다. Google Books는 Oschmann 1998년 책의 서지와 디지털화 기록만 제공했으며 실제 121·129쪽의 라틴어 판면은 확인하지 못했다. **APW 121·129쪽은 여전히 2차 학술 인용에서 찾은 후보 위치**로서 본문 인증이나 완전한 교감이 아니다.

대신 https://la.wikisource.org/wiki/Instrumenta_pacis_Westphalicae 에서 IPO V §§1·2·34·35·36·37, VII §§1·2, VIII §2의 라틴어 온라인 전사 위치를 실제로 읽고 의미를 해석했다. 단지 온라인 volunteer 전사의 본문을 읽었다는 사실은 1648년 원문 물리 사본 또는 Oschmann 학술 비평판을 직접 대조했다는 주장으로 격상하지 않는다.

## 유기적인 다음 연구

1. **원본 이미지 확보/열람**: Austrian State Archive 2594303·2594304의 촬영자료를 실제로 열어 각 조항의 프레임과 물리적 엽번호를 연결한다.
2. **학술판 교감**: Oschmann III B 1/1 1998 pp.121·129 등 직접 판독 후 V §§34–37, VII §§1–2의 철자·이문·주석을 원본 전사와 비교한다.
3. **사회사 연결**: V §35의 길드·상속·병원·매장 규칙이 특정 도시·영방의 법원이나 종교 분쟁에 실제 어떻게 적용되었는지 지역사 자료로 검증한다.
4. **기존 원고의 정식 반영**: 학술적 감수와 권리 확인 후에만 기존 정본의 원문 대응을 승인하고 별도 공개용 데이터를 만든다. Google AI Studio 웹앱은 병렬 개발 상태 유지.

자동검증의 성공은 연구의 **데이터 구조와 미검증 상태**의 일관성만 보증하며 1648년 원본 문서 사진을 판독하거나 비평판의 라틴어를 교감했다는 뜻이 아니다.
