# V1.32 제5권 트리엔트·베스트팔렌 연구 교차 감사

2026-10-30 · DRAFT_RESEARCH_NOT_PUBLIC

## 실재 데이터 집계
트리엔트 연구 자료에는 출처 11건과 선정 회기 8건, 별도의 라틴어 증인 대조 자료에는 출처 10건과 절·표제 앵커 4건, 30년전쟁·베스트팔렌 자료에는 출처 11건과 조약 문서 3건이 존재한다. 동일 출처가 반복될 수 있으므로 이를 서로 다른 32개 고유 출처라고 해석하지 않는다.

## 역사학적 해석 규칙
트리엔트 공의회는 세 시기(1545–1547, 1551–1552, 1562–1563)에 걸쳐 진행되었다. 1564년 인쇄된 교령·규정집은 16세기 문헌 증인이지만 각 회기 당시의 개별 초고·필기 원본과 동일하지 않다. 사본의 보존처를 찾은 것만으로 라틴어 판면 교감이 완료된 것은 아니다.

1648년 베스트팔렌 평화에는 뮌스터에서 체결된 황제–프랑스 사이의 평화문서와 오스나브뤼크에서 체결된 황제–스웨덴 사이의 평화문서 등 여러 법적 문서가 있다. 각 조약의 체결 날짜, 비준 및 발효 관련 절차를 하나의 단일 문서로 합치지 말아야 한다. 1555년 아우크스부르크 종교화의와의 관계도 배경/법제 비교로 연결하되 동일 문헌으로 처리하지 않는다.

이냐시오 데 로욜라와 아빌라의 테레사는 제5권 정본 인물 ID OV-P-021과 OV-P-022를 유지한다. 예수회 조직의 발전과 개혁 가르멜회의 역사는 동일한 조직의 활동이 아니므로 별도 서술한다. 가톨릭 내부 개혁의 다양성을 하나의 일괄적인 '반동'으로 단순화하지 않는다.

## 현재 공개 판정
출처·회기·조약 앵커와 제5권 기존 자산의 연결을 확인했지만, 해당 라틴어 문단을 원본 인쇄물에 직접 대조하거나 개별 이미지 이용권을 승인한 것은 아니다. 기존 기록은 수정하지 않고 독립 감사 파일만 추가하였다. 공개 불허 및 AI Studio 반입 보류.

## 후속 검증 우선순위
1. 트리엔트 8개 회기의 source_keys가 실제 출처 등록부에 모두 존재하는지 점검하고 원문/번역본 문장대조를 준비한다.
2. 라틴어 앵커 4건의 session_number와 1564년 인쇄본 해당 판면의 대응 관계를 확인한다.
3. 베스트팔렌 조약문 3건의 문서명, 체결 장소, 서명일과 source_keys를 점검한다.
4. 이냐시오·테레사의 1차 저작을 인물 ID에 연결하되 후대 번역과 저술을 엄격히 구분한다.
