## 이번 조사에서 확인한 실제 소장·문헌 근거

1. **1521 보름스**: 인쇄본 `VD16 L 3653`(Stadtbibliothek Worms 소장 근거)과 `Mag-LB 88`(다른 인쇄물), 칙령 `VD16 D 924` 및 BSB `Res/4 H. ref. 287`은 서로 다른 증인. '여기 내가 서 있다' 후대 추가 문제.
2. **1527 만츠**: 취리히 국가기록보관소 원판결 등록 `B VI 251, fol. 40r–41v`와 초안 `E I 7.1, Nr. 87`, 별개의 `OV-E-017`은 슐라이트하임 7개 조항.
3. **영국**: 영국 의회의 1534 수장령·1549 예배 법령·1559 통일령 구분. 의회 기록 `HL/PO/PU/1/1558/1Eliz1n2`; 체섬스 도서관의 1549/1552 공동기도서 실물. 1559 판본도 별개 개정판.
4. **1555 종교화**: GHDI에 §17 타 종파 배제, §18 교회재산 유보, §24 이주권, §27 제국도시 내 양 종교 공존에 대한 번역. `cuius regio, eius religio`는 후대의 요약 표현으로 표시.

## 연구 원칙

- **역사 서술과 원본 교감의 구분**: 기관 자료/디지털 번역과 소장 기록을 토대로 한국어로 해설했으나 원어 사료 전체를 페이지별 교감했다고 표시하지 않는다.
- **한 사건의 행위·전승 구분**: 보름스 4월 17/18일 청문과 5월 칙령, 취리히 신자세례와 만츠 판결 및 슐라이트하임 7개 조항, 1534 왕권 법률과 1549/1552/1559 전례 변화, 1530 신앙고백 제출과 1555 법률은 각각 따로 관리한다.
- **정치·종교 권한의 구분**: 루터의 양심, 취리히 시의회의 형사 판결, 헨리 8세의 국왕 수장권, 제국 제후들의 법적 권한은 동의어가 아니다.
- **저작권과 이미지 검증**: 역사적 물건 자체가 오래되었더라도 현대 도서관 디지털 촬영·메타데이터·번역의 사용 조건을 검증하지 않고 이미지 파일을 공개 앱에 넣지 않는다.
- **새 정본 ID 0건**: 기존 `OV-P`, `OV-E`, `OV-D`만 참조하며 출판 승인을 받지 않은 사건은 경로를 만들지 않는다.
- **웹앱과 독립성 유지**: Google AI Studio 개발과 `main` 파일 변경 없이 연구 브랜치에서만 저장한다.
