## 역사적 기록 원칙

기존 OV-E-024, OV-D-015는 바꾸지 않는다. **IPO-AK LWL que2599**와 **황제를 위한 정본 que2595**는 LWL의 서로 다른 서지 항목이지만 두 항목이 동일 또는 별개의 실물인지 **원본 식별·대조 전에는 결론을 보류**한다. 오스트리아 HHStA의 구체 소장번호도 현재는 미확정으로 남긴다.

Antje Oschmann 편집의 *APW III B 1/1 (1998)* **95–170쪽**은 **후대 학술 편집본의 수록 페이지**이지 1648년 라틴어 실물의 엽번호가 아니다. LWL의 약 42쪽 PDF는 후대 역사 출판물의 스캔으로, 서명된 1648년 원본의 전면 촬영본이라고 표시해서는 안 된다. APW 전자 보충판은 자료 제공 범위가 확인됐지만 원문 서비스 열람이 완료되지 않았다.

증거 단계: **소장목록 확인 → 서지 판본 확인 → 비평판 직접 읽기 → 실물 서명/면·행 대조 → 역사·권리·사람 검수 → 공개 승인**. 현재 앞의 두 단계에 관한 자료를 확보했으며 문구/인쇄 증인 수준의 전체 교감은 미완료다.

기존 제5권 역사 원고의 IPO 제5조 §§34·36·37 관련 **사적 신앙 보호와 조건부 이주 공존**이라는 정정은 유지한다. 이번 작업은 그 조항의 원라틴어 문구를 인증했다는 뜻이 아니다.

## 이후 우선순위

오스트리아의 개별 IPO-AK 정확 소장부호 및 온라인 원본 이미지를 식별한 뒤, APW의 실제 비평판 텍스트에서 IPO V §§1,2,34,36,37, VII §§1–2, VIII §2의 정확한 조항별 페이지와 이문을 직접 확인한다. 당대 인쇄본은 별도의 인쇄자·출판년·사본 서지로 추가한다. 현대 번역문과 기관 이미지는 권리 승인 없이는 웹앱에 배포하지 않는다.
