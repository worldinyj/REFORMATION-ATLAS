## 사료 신뢰도와 보류

- **공의회 본문**: 현대 번역문, Waterworth 1848의 판본, GHDI 발췌는 16세기 라틴어 공식 교령의 물리 원본과 동일하지 않다.
- **칭의**: 제6회기(1547년 1월 13일)와 루터·멜란히톤의 작성 시기/문헌 장르가 서로 다르다. 가톨릭을 '오직 인간의 공적', 개신교를 '행위 없는 방종'으로 묘사하지 않는다.
- **성찬**: 제13회기(1551년 실체적 현존)와 제22회기(1562년 미사 제사)는 **서로 다른 문서**다. 개혁가들의 성찬 설명도 내부 차이를 보존한다.
- **신학교**: 제23회기 1563년 **개혁 교령 제18장**은 법·규범; 지역 교구별 설립일은 개별 역사 기록이 필요하다.
- **최종 회기**: 1563년 12월 **3~4일**과 교황의 1564년 **1월 26일 확인**을 구분한다.
- **교회개혁**: 예수회와 가르멜 개혁을 트리엔트의 단순 하급기관처럼 기술하지 않는다. 여성 개혁가 테레사의 실천과 문헌·기관 운영을 독립된 역사로 다룬다.
- **이미지/권리**: 루브르의 1563년 공의회 그림 등 전시·소장 기록은 참고 링크일 뿐, 배포권 확인 없이 이미지 파일을 연구 저장소나 웹앱에 복제하지 않는다.
