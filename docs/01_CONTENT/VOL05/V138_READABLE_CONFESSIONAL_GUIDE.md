# V1.38 — 독자 중심의 신앙고백 비교 심화 콘텐츠

**DRAFT / 웹앱 자동 반입 금지**

## 1. 의화·칭의 — 같은 질문, 다른 설명
‘사람은 어떻게 하나님 앞에 의롭다고 인정받는가?’라는 공통 질문에서 출발한다. 아우크스부르크 신앙고백 제4조는 인간의 힘·공로·행위가 아니라 그리스도로 말미암아 믿음으로 의롭게 된다는 설명을 제시한다. 트리엔트 제6회기는 은총에 근거한 의화가 죄의 용서와 인간의 내적 갱신을 포괄한다고 해설한다. 칼뱅 『기독교강요』 제3권은 의의 전가와 성화의 관계를 세밀하게 논한다.

**어려운 용어:** *justificatio* (의화·칭의), *imputatio* (전가), *sanctificatio* (성화). 관찰할 점은 세 전통 모두 은총과 그리스도를 말하지만 개념을 서로 다른 체계 속에서 정의한다는 것이다.

## 2. 성찬 — 현존·참여·제사
트리엔트는 성체성사에서 그리스도의 현존과 미사의 제사성을 설명한다. 아우크스부르크 제10조는 성찬에서 몸과 피의 참된 현존을 강조하고 제22·24조는 양형 영성체와 미사 관행에 관한 주장을 담는다. 칼뱅 『기독교강요』 제4권 17장은 성령을 통한 참여를 강조하면서 18장에서는 미사 성제에 비판적이다. '루터파=기념설'은 틀린 요약이다.

## 3. 성인 공경과 성화상 — 기억·호소·이미지
아우크스부르크 제21조는 성인의 신앙과 행위를 본받는 것을 긍정하면서 성인에게 도움을 청하는 의식을 성경적 의무로 인정하지 않는다. 반면 트리엔트 제25회기는 성인 공경·유해·이미지를 규정하면서도 남용을 제한한다. 칼뱅의 『기독교강요』 I.11은 예배 이미지에 더 강한 비판을 제시한다. 세 문서의 장르가 각각 신앙고백·공의회 교령·신학서인 점을 분명히 표시한다.

## 웹앱 사용자 경험
이 심화 자료는 각 주제에 대해 **200자 요약 → 용어 3개 → 세 문헌의 입장 → 공통점/차이 → 출처·판본·검증상태** 순서로 보여주는 것을 권장한다. 날짜와 저작 ID를 연결하되, 1530년 원문·1559년 라틴어 판본·1564년 트리엔트 인쇄본을 나중 영어 번역과 동일시하지 않는다.
