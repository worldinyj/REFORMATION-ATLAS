# V1.17 — 제3·4권 인물·문헌·판본 연결 및 무손실 규칙

**DRAFT_RESEARCH_NOT_PUBLIC** · 2026-10-30

## 실제 저장소 대조
기존 `OV-P-016`은 장 칼뱅 인물의 전역 개요 ID이고 제4권 심화 자료에서 같은 ID를 사용한다. `CLM-V04-CA-002`는 1536년 초판의 6장 구조와 1559년 라틴어 최종판의 4권 80장 구조를 구분한다. `CLM-V04-CA-003`은 1541년 첫 프랑스어판과 1560년 후대 프랑스어판의 구별을 요구한다.

이번 V1.17에서 부여한 WRK-/EDN-V04-CALVIN-... ID는 **임시 연결 ID**로, 기존 전역 ID 레지스트리에 영구 채번하지 않는다. 저작과 개별 판본은 서로 다른 객체다. 현대 연구의 서술을 16세기 판면 원본 직접 판독이라고 주장하지 않는다.

제3권 자료 `data/vol03_document_witnesses.json`에 이미 원문 객체, 1844/1937 편집판, 온라인 전사 및 비평판 등 8개 문헌 객체가 구분돼 있다. 특히 `DOC-V03-001`과 `EDN-V03-001`을 같은 물건으로 합치지 않는다. 온라인 전사(`TRN-V03-001`)는 1937 편집판을 참조하며 역사적 원본 문서의 대체물은 아니다.

## 구현
- `data/contracts/atlas_person_work_edition_crosswalk_v117.json`: 칼뱅 인물·저작·4개 판본과 제3권 문헌 객체 8개 연결 초안.
- `scripts/validate_atlas_editions_v117.py`: ID 충돌·원본 기반 관계·판본 독립성·비공개 상태 검사.

## 검증 경계
학술 해석과 원전·교감본의 출처 수준은 다른 축이다. 판본마다 저작 연도·언어·판본 구조·실제 판면 접근 여부를 따로 기록한다. 기존 정본 파일 변경, 앱 배포, 이미지 재사용은 수행하지 않는다.
