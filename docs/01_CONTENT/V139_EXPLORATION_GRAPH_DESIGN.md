# V1.39 — 종교개혁 ATLAS 탐색형 연결 구조

연구자 전용 초안 / 2026-10-30

## 사용자 관점
루터 → 1517 논제 → 교회 개혁 논쟁, 칼뱅 → 『기독교강요』 → 1536/1559 판본 → 칭의·성찬·성화상 비교, 트리엔트 → 공의회 문헌 → 같은 비교 주제로 이동하는 구조다. 동일한 주제를 다양한 전통의 자료로 확인하되, 비교가 곧 동등한 문헌 권위나 동일한 시기의 사건을 뜻하지 않는다.

## 연구 데이터 구성
기존 인물·사건·문헌 정본 ID를 보존하고, 이미 사용 중인 칼뱅 판본 ID를 연결한다. 세 비교 주제에는 임시 토픽 ID를 사용한다. 이냐시오와 테레사는 제5권 인물로 등록했지만 본 탐색 그래프에 출처가 확증되지 않은 저작의 저자 연결을 만들어내지 않는다.

## 웹앱 사전 점검
- 화면: 인물 → 사건/문헌 → 판본 → 비교 주제 → 근거 링크
- 필수 표시: 원전/후대 편집본/현대 번역 구분, 논쟁적 전승, 문헌 검증 수준
- 주의: 이 그래프는 초안 수준이며 자동 퍼블리싱 불허
- 검토: source_id가 실제로 존재하는 것과 해당 주장에 적합한 것을 구분

## 향후 확대
제3권 위클리프·후스 사본을 연결하고, 제5권 이냐시오 『영신수련』과 테레사 『완덕의 길』/『영혼의 성』에 대해 별도 문헌·판본 레코드를 검증한 뒤 저자·저작 관계를 확장한다.
