# V2.03 · 최신 역사 원고 10편과 엔터티·근거 탐색 브리지

## 결과
V2.02 실제 개정본(공백 제외 25,404자)을 **변경하지 않고** 기존 연구 ID와 결합했다. 이전 10편에 대한 V1.79 대표 주장 10건을 다시 연결하고, 최신 본문에서 독서용 절 경계를 자동 추출했다. 연구용 JSON만 생성하며 앱 검색·웹 공개·main 병합은 하지 않는다.

| 구조 | 수량 | 해석 |
|---|---:|---|
| 최신 독서 원고 | 10편 | 원본 V2.02 유지 |
| 절 단위 탐색 앵커 | 70개 | V2.02 본문 유니코드 코드포인트 오프셋, 수정 시 재생성 필요 |
| 대표 주장과 기존 근거 대장 | 10건 | **각 원고 대표 주장 1개**; 전체 역사 명제 검증 아님 |
| 도시 맥락 | 11건 | 도시 중심점 수준; 역사 장소·여정 경로 아님 |
| 시각자료 후보 | 14건 | **이미지 권리 승인·바이너리 공개 없음** |

## 핵심 연결 결정

- **위클리프와 후스의 동명 저작 분리**: 위클리프는 잠정 `WRK-V03-WYCLIFFE-DE-ECCLESIA`, 후스는 기존 정식 개요 문헌 `OV-D-005`. 제목이 같다는 이유만으로 같은 문헌으로 취급하지 않는다.
- **루터**: 1517 논제와 1521 보름스는 `OV-E-015`/`OV-E-016`으로 분리하며, 1521 심문 기록의 정식 문헌 ID를 임의 생성하지 않는다.
- **마르부르크와 바젤**: 지도 후보는 `marburg`와 `basel`이지만 개요 장소 `OV-L-*` 식별자가 존재하지 않으므로 `overview_place_id=null`로 둔다.
- **아우크스부르크**: `EDN-V161-AC-1530` 제출본, `EDN-V161-AC-1531` 인쇄본, `EDN-V161-AC-1540` Variata를 분리한다. 관련 문헌 작업 ID는 계속 **잠정**이다.
- **칼뱅**: `EDN-V161-INST-1536`과 `EDN-V161-INST-1559`를 엄격히 분리하고, 1559년 항목에 1536년 개요 사건 `OV-E-020`을 오용하지 않는다.
- **츠빙글리**: 1523년 취리히 논쟁의 독립 개요 사건이 없으므로 1529년 마르부르크 사건을 동일 사건으로 지정하지 않는다.
- **트리엔트**: 개인 한 사람의 업적으로 오인하지 않도록 관련 인물 ID를 억지로 지정하지 않고 `OV-E-021` 및 `OV-D-014`에 연결한다.

## 주장·사료 출처의 한계

`claims[*].source_references`는 V1.79에 **이미 기록된 URL과 출처 종류**를 구조화한 것으로, 이번 작업에서 원문을 새로 열어 확인했거나 개별 문장과 대조했다는 의미가 아니다. 각 원고 대표 주장 1건만 추적하고 있으며, **70개 절의 모든 사실 명제를 별도로 검증했다는 뜻이 아니다**. 출처 대장에 동일 URL이 존재하는 경우에만 기존 `SRC-O-*` ID를 연결했다. 학술 감수 `PENDING`, 원본 직접 교감 `false`, 공개 `false`를 강제한다.

## 독서 UI 사용 계약 (연구자 내부 미리보기 전용)

1. 제목·본문은 `data/deep/atlas_v202_unified_ten_revised_readers.json`에서 `key`로 조회한다. 브리지에는 본문 중복 저장을 하지 않는다.
2. 독서 목차는 `section_anchors`를 이용하고, 본문 문자열은 유니코드 코드포인트 오프셋 `[start_char,end_char)`로 자른다. 앵커는 **V2.02 전용**이며 내용 수정 시 다시 생성한다.
3. 엔터티 연결은 `person_ids`, `primary_event_ids`, `canonical_document_ids`, `map_contexts`로 탐색하되, 위치나 문헌 연계를 해당 문장에 대한 사료 입증으로 승격하지 않는다.
4. 검증 패널에는 `representative_claim_id`로 연결하고, 출처 종류·미검증 설명·원본 미교감·인간 검토 대기를 **그대로** 표시한다.
5. `visual_candidate_ids`는 에셋 등록부를 가리키는 권리검토 대기 식별자일 뿐이다. 이미지를 자동 로드하거나 외부 이미지 링크를 웹에 노출하지 않는다.
6. `publication_gate.can_ship=false`인 데이터는 AI Studio 공개 앱·외부 검색색인·배포 번들에 삽입 금지. 이번 브리지는 **웹앱 수정 또는 연동 완료가 아니다**.

## 자동검증

```bash
python3 scripts/validate_atlas_v202.py
python3 scripts/validate_atlas_v203.py
```

## 다음 우선순위

2. 개인·문헌·도시의 미해결 ID를 근거 수준을 보존하면서 정리. 바젤·마르부르크를 자동으로 정식 장소로 승격하지 않음.
3. 원고별 중복 문단과 모바일 독서용 소제목을 교정하되, 원본 변경이 발생하면 절 오프셋 재생성·회귀검증.
4. 지도·인물화·문헌 이미지 후보의 개별 권리와 파일 존재를 사람이 확인. 웹앱 반영은 **별도 승인된 단계**에서 수행.
