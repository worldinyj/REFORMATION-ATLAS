# V1.73 · 남은 6개 주제의 역사·문헌 심화 원고 — 연구 배치

기존 V1.72 계획 대비 보고서에서 가장 시급한 항목으로 선정한 6개 주제에 대해 시대와 문헌, 신학, 수용을 연결한 **신규 4절 해설 원고**를 작성했다.

| 장 | 시대 | 강조 사항 |
|---|---|---|
| 아우크스부르크 신앙고백 | 1530–1540 | 정치적 제출 문서, 제4조·제10조, 1531 인쇄·1540 Variata |
| 취리히 츠빙글리 | 1523–1525 | 1523년 두 논쟁, 도시의회, 예배·성상·공공질서 |
| 마르부르크 | 1529 | 공동 서명된 15개 조항, 제15조 성만찬 미합의, 양측 기록의 편향 |
| 칼뱅 초판 | 1536 | 프랑스 박해와 헌사, 여섯 장, 1539년 이후 수정 |
| 칼뱅 최종 라틴어판 | 1559 | 4권 80장, 권별 주제 구조, 1560년 프랑스어판 구별 |
| 트리엔트 | 1545–1563 | 회기별 교령, 가톨릭 내부 개혁, 후대 출판본 구별 |

### 실무적으로 중요한 주의사항
- 여섯 원고는 연구 초안이다. 편당 2,000~3,000자 목표의 최종 장문 원고와 동일하지 않다.
- 동시대 1차 자료의 원판 판면을 직접 읽고 교감했다는 주장도 하지 않는다.
- 문헌 단위 ID와 기존 V1.56의 `source` ID를 연결했다.
- 위클리프·후스·루터 1517·1521 시범 원고는 V1.71~V1.72에 따로 있다.
- 결과적으로 **10개 주제에 모두 추가 원고 초안이 생겼다**는 의미이며, **10편 완성·감수 승인**의 의미는 아니다.
