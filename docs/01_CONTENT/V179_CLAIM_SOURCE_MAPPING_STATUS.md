# V1.79 · 심층 10편 근거 연결 1차 등록

V1.78에서 10개 역사 주제의 본문 분량을 공백 제외 2,000자 이상으로 확장한 뒤, **각 장을 대표하는 검토 대상 주장 1개**를 소장처·편집 사료·2차 연구의 자료 유형과 연결했다. 주장당 최소 1개 URL, 실제 확인이 남은 내용, 원본 판면 직접 교감 여부를 구조화했다.

이 배치는 **문장 단위 전체 사실검증이 아니라 검증할 주장과 출처 후보의 1차 연결표**다. 출처 URL 형식은 검사하지만 외부 URL 응답 상태, 사료의 해당 절, 논문의 해당 쪽을 직접 대조한 것은 아니다. 정확한 출처 구절과 판본 증거가 부재한 경우 서지 수준의 안내임을 유지한다.

핵심 10개 주제: 위클리프·후스·루터(1517/1521)·마르부르크·아우크스부르크·칼뱅(1536/1559)·취리히·트리엔트.

## 후속 작업 기준
1. 1편에 1주장이 아닌 **여러 주요 주장**을 실제 문단별로 분해한다.
2. 마르부르크 조항은 제15조의 해당 문장, 아우크스부르크는 제4조·제10조의 판본별 위치, 칼뱅은 권·장·절을 기록한다.
3. 출처의 직접 열람/편집 전사/소장 기록/2차 연구를 명시적으로 구분한다.
4. 실제 판면·논문 쪽수 대조 없이는 `original_folio_checked=false`를 유지한다.
5. 공개는 학술·권리·사용자 승인 후에만 한다.
