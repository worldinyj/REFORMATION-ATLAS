# 제1~5권 V1.18 — 위클리프·후스·루터·칼뱅 연결 교차표

**DRAFT_RESEARCH_NOT_PUBLIC** · 2026-10-30

기존 저장소의 개요 인물 ID를 직접 확인했다. 존 위클리프 `OV-P-009`, 얀 후스 `OV-P-010`, 마르틴 루터 `OV-P-013`, 장 칼뱅 `OV-P-016`을 정본으로 유지한다. 제4권 심화 데이터의 루터와 칼뱅 인물 ID도 이에 일치한다.

개요 사건 ID 중 위클리프의 영어 성경 번역 운동 `OV-E-011`, 후스 처형 `OV-E-012`, 루터 95개조 `OV-E-015`, 보름스 회의 `OV-E-016`, 마르부르크 회담 `OV-E-018`, 칼뱅 1536년 『기독교강요』 초판 `OV-E-020`을 연결한다.

사건 연계는 역사적 영향의 직접 계보나 사제관계를 증명하지 않는다. 위클리프와 영어 성경운동은 개인 단독 번역으로 단정하지 않고, 위클리프→후스의 영향은 사상·문헌의 수용 경로를 원전 근거와 함께 별도로 연구해야 한다. 1536년 칼뱅 저작 사건과 1559년판은 다른 판본 객체로 유지한다.

검증 스크립트는 연결 ID의 실재와 각 인물의 권 구분, 비공개 게이트를 검사한다. 단, 개별 역사 해석의 신빙성을 이 구조 검증으로 입증할 수 없다. `main`, Google AI Studio, 기존 정본 수정 없음.
