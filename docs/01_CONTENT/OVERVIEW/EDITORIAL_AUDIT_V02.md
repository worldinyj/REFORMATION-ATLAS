## 3. 직접 수행한 자료 점검과 증거 범위
- 원본 데이터 전 항목에 대한 **식별자 중복·고아 관계·출처 참조 검사**: 일차 구조 점검에서 누락 0건.
- 본 회차에 실물 페이지를 열어 제목·범위를 확인한 일부 자료만 `review_status=WEB_CHECKED`로 기록. 나머지는 `REFERENCE_ONLY_NOT_RECHECKED`.
- SRC-O-004 국가도서관 자료의 웹주소가 변경되어 정식 주소로 수정했으며 이전 주소도 `original_url`에 남김.
- SRC-O-019는 학술서 출판정보·요약이지 전문을 읽은 것이 아니다. SRC-O-016은 후스의 **1915 영어 번역**이지 라틴 원저본을 직접 본 것이 아니다.
- SRC-O-021, SRC-O-022와 SRC-O-001은 동일 URL에 대한 주제별 별칭이므로 **서로 다른 독립 출처 3건**으로 세지 않는다.
- 확인된 기초 사실: WCC 공식 자료의 1948-08-23 창립, 한국천주교 1784 공동체와 1885 이후 개신교 선교의 구분, 루터 면벌부 논쟁, 웨슬리 신학 개관.

## 4. 데이터 계약 보강
- [기존 VOL-03 인물과의 3건 ID 대응표](../../data/overview/legacy_person_crosswalk_v01.json): 발도·위클리프·후스 개요 `OV-P`와 통합 그래프 `PER`를 구분하여 매핑.
- `OV-P`는 **현재 개요 검토용 임시 ID**, 정식 서비스 모델의 영구 인물 ID가 아님. 자료를 마이그레이션할 때 고유 ID와 연결을 보존할 규칙 필요.
- 지명은 문자열 기준, 중세 실제 장소나 좌표가 고증된 지도가 아니다.
- 날짜 정밀도는 `day`, `year`, `range`, `period`, `approximate_year`, `approximate_period`를 그대로 보존. 기계적 정렬이 사실상 정확한 날을 의미하지 않는다.

## 5. 설계 단계 준비 판정
- **READY_FOR_PROJECT_PLAN_DRAFT**: 탐색·검색·권/인물/사건/문헌/장소/주제 스키마와 최소 샘플 데이터가 준비됨.
- **NOT_APPROVED_FOR_PUBLICATION**: 고증 안 된 이미지, 근대 편집 사료 전문, 외부 학술 승인과 출처 재검증은 미완료.
- **PRD/TRD 작성 전** 제품 범위, 사용자 여정과 화면 카드 정보 계약은 계획서에서 고정해야 한다. 이번 검수는 제품 요구사항을 승인하지 않는다.
