## 3. 중요한 발견 — 역사적 사건 날짜와 출판물 날짜를 같은 필드에 넣으면 오류가 발생한다

### 사례 A — 1882년과 1887년의 한국어 성경

대한성서공회의 한글 성경 번역사에 따르면, 1882년에 『예수셩교누가복음젼셔』 등 **개별 복음서**가 발행됐고, 로스·매킨타이어와 한국인 번역·필사 협력자들의 작업으로 1887년에 『예수셩교젼셔』 **전체 신약전서**가 간행됐다.

한국민족문화대백과의 『예수성교전서』 항목은 본문·정의에서 **1887년**이라 하면서 메타정보의 '간행 시기'를 **1882년**이라고 표시한다. 내부적 불일치가 있으므로 한 줄 메타데이터만 가져와 『예수셩교젼셔』 자체의 발행연도를 1882년으로 바꾸는 것은 오류다.

**정리 규칙:**

- \`1882 / PARTIAL_GOSPEL_EDITION\` = 누가복음·요한복음 등 초기 낱권.
- \`1887 / COMPLETE_NEW_TESTAMENT_EDITION\` = 『예수셩교젼셔』.
- 번역자·인쇄자·유통자·신앙 공동체 형성자를 각각 구분하고, 한국인의 역할을 빠뜨리지 않는다.
- 원자료에 서로 모순되는 연도가 있으면 \`metadata_conflict\`와 교차 확인 출처를 남긴다.

근거: 대한성서공회 https://www.bskorea.or.kr/bbs/content.php?co_id=subpage2_3_3_1_1 ; 한국민족문화대백과 https://encykorea.aks.ac.kr/Article/E0037972 .

### 사례 B — 635년/781년, 1421년/1433년/1436년, 1530년/1531년/1540년

**당나라:** 781년 비문이 **635년의 선교 관련 도착을 회고**한 것이므로, 사건의 주장 연대(\`event_year\`)와 그것을 전하는 증거의 물적 제작 연대(\`witness_year\`)를 분리한다. 635년 자체를 후대 비문과 별개로 직접 확인된 물적 증거라고 오기하지 않는다.

**후스파:** 프라하 4개조의 강령화·공포(1420~1421년), 바젤 공의회 협상(1433년), 이흘라바의 공적 공포(1436년)는 문서의 정치·법적 지위가 다른 세 단계다. 마사리크대학교 2024년 학술서 장 소개 역시 1421년 공포·1433년 협상·1436년 이흘라바 공포를 구분한다.

**아우크스부르크:** 1530년 제국회의 제출, 1531년 라틴어 인쇄본, 1540년 Variata 수정판을 각각 **공적 제출 / 인쇄·정본 전승 / 후대 수정판**으로 구별한다. 해당 원문의 조항별 판독은 별도의 L2 작업이다.

**칼뱅:** 『기독교강요』 1536년 최초 라틴어 판과 1559년 최종 라틴어 판, 1560년 최종 프랑스어 판은 발행 연대·언어·구성이 다르다. 1559년 4권 80장 체계가 1536년 첫 출판 때 존재했던 것처럼 보이지 않게 한다.

자료 예: Masaryk University https://www.muni.cz/en/research/publications/2437517 ; Oxford Academic https://academic.oup.com/book/50318/chapter-abstract/422710493 ; Schaff 역사적 판본 소개 https://www.uecf.net/books/collected-works/chapter1319.html .
