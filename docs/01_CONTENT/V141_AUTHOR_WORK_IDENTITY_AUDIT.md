# V1.41 저자·저작·판본 식별자 감사

**연구 브랜치 전용, 기존 데이터 미수정.**

이번에 실제로 읽고 교차 확인한 것은 제3~5권 연결용 3개 파일이다. 전체 저장소를 전수검사한 것으로 표현하지 않는다.

### 오류 후보 F01 (높음)
V1.19 교차 연결의 `OV-P-009`(위클리프) → `OV-D-005` 관계는 정본 개요의 `OV-D-005`가 **후스의 1413년 『교회론』(De ecclesia)**인 점과 충돌한다. 위클리프의 별도 동명 저작과 구분할 고유 작품 ID를 먼저 확보하고, 편집자 검토 후 잘못된 관계를 대체해야 한다.

### 주의 사항 F02
`OV-D-006`은 1420년경 후스파 운동의 「프라하 4개조」이다. 후스의 개인 저작으로 연결하지 않고 `later_movement_document` 유형을 유지해야 한다.

### 주의 사항 F03
V1.40 그래프에 임시 `WORK-*`, `TOPIC-*` 식별자와 정본 `OV-*` 식별자가 공존한다. 웹앱 반입 시 임시 ID를 정본으로 승격하는 자동 변환을 금지한다.

## 권장 개선
저자·원어 제목·연대·문헌 종류를 복합 키로 비교하고, `authored` 관계는 검토한 저자 표시와 일치할 때만 승인한다. 인물 생몰과 저작 작성연대가 어긋날 때는 우선 검토 대상으로 보내며 사후 운동 문헌은 자동으로 저자 귀속을 금지한다.

이번 검토는 **정본·교차 연결·V1.40 그래프 세 파일의 표적 감사**이며, 미검토 파일에 오류가 없다는 주장이 아니다. 원전 직접 교감, 병합, AI Studio 공개 없음.
