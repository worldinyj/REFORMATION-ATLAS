# V1.15 제1~5권 공통 콘텐츠 규격 호환 설계

**DRAFT_RESEARCH_NOT_PUBLIC** · 2026-10-30

## 기존 규격 재활용
`data/contracts/atlas_contract_v01.json`은 이미 모든 권에 대한 안정적 ID 정책과 읽기 전용 투영을 정의한다. V1.15는 이를 대체하지 않고 호환 레이어를 추가한다. 기존 Markdown·JSON을 정본으로 유지하고 일괄 마이그레이션은 진행하지 않는다.

## 구분해야 할 레코드
- **인물**: Wycliffe, Hus, Luther, Calvin 등의 전역 ID와 권별 심화 원고의 연결.
- **문헌/판본**: 동일 저작의 연도별 판본(예: 1536/1559 Calvin)을 독립 엔트리로 관리. 저작 = 판본이라는 등식 금지.
- **사건/날짜**: `date_precision`을 보존하여 1652년 허가와 1658년 실제 이동을 하나로 합치지 않음. 레거시 `period`는 기존 데이터에서 허용하되 변환 시 명시적 처리.
- **장소/지도**: 현대 도시 중심점과 역사 건물 위치, 추상 이동선과 실제 여정 구분.
- **증거/권리/승인**: 역사적 확실성, 원문 접근 단계, 편집 검토, 출판 권한의 네 축을 독립적으로 기록.

## 레거시 매핑 시험 대상
1. `data/overview/events_documents_v01.json` — 제1~5권을 포함하는 개요 사건.
2. `data/deep/vol04_luther_v01.json` — 제4권 인물별 심층 콘텐츠.
3. `data/deep/vol05_education_map_timeline_v114.json` — 제5권 기관·교육·지리 네트워크.

모두 정본 ID와 원본 필드를 수정하지 않는다. 변환 대상에 본래 존재하지 않는 source, 연월일, 건물 좌표 또는 공개 승인을 만들어 넣지 않는다.

## 품질 게이트
- 소스 ID 누락/중복, 날짜 정밀도 저하, 판본 혼동, 미확인 이미지 공개를 차단.
- 비공개 연구 자료는 앱에 반영될 수 있는 파일 형식이라도 **공개 승인으로 취급하지 않는다**.
- `main`, Google AI Studio 프로젝트, 기존 원고와 JSON은 변경하지 않음.
