# V1.42 저장소 연계 식별자 감사

2026-10-30 · 연구 전용

저장소 트리 518항목을 조회했고 `data/contracts`, `data/deep`, `data/overview` 아래 JSON 94개를 목록화했다. 그 가운데 인물·저작 식별자 관련 대표 파일 **6개를 실제 열어 검사**했다. 94개 파일의 본문 전수조사를 완료했다고 주장하지 않는다.

## 확인 항목

1. **확인된 충돌:** V1.19의 위클리프 `OV-P-009` → `OV-D-005` 연결은 개요 정본에서 후스의 1413년 『교회론』을 가리키므로 정정이 필요하다. 두 인물의 동명 저작을 합치지 않는다.
2. **보존해야 할 주의:** 프라하 4개조는 후스 사후 운동 문헌이므로 `later_movement_document` 관계를 유지한다.
3. **임시 ID:** V1.17의 칼뱅 작품 ID가 `provisional_id`로 표시되어 있다. 기존 `OV-D-012`와 판본 ID에 대한 관계는 유지하되 임시 작품 ID를 정본으로 승격하지 않는다.
4. **제5권 탐색 ID:** V1.40에서 추가된 영신수련·완덕의 길·영혼의 성 작품 ID는 탐색 그래프 전용이다.

## 실행 제한
원본 데이터나 Google AI Studio 앱을 직접 수정하지 않았다. 수정을 위한 별도 편집자 승인 및 자동 테스트를 구축한 다음 관계를 변경해야 한다. 검사 범위 확대를 위해 94개 JSON의 전체 인물·문헌 ID 참조를 순회하는 CI 검증이 후속 과제다.
