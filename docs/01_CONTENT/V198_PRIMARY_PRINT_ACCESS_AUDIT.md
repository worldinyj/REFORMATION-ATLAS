# V1.98 원본 인쇄본 접근성 및 원문 대조 실행 대장

## 실질적인 발견
1539년 칼뱅 『기독교강요』 뉴베리 도서관 소장 기록은 공개되어 있지만, 상세 페이지는 원본 이미지를 볼 권한이 없다는 메시지를 보여준다. 이 사실을 문서 열람과 구별한다. 소장번호 VAULT folio Case 6A 224.

1559년 제네바 Robert Estienne 인쇄 『기독교강요』 원판의 디지털 이미지가 Princeton/Internet Archive 기반으로 Wikimedia Commons에 게시되어 있다. 576쪽 PDF이며, 자료 설명은 **이 개체에 인쇄쪽 545–546이 결락**되었다고 경고한다. 제3권 8장 7절의 원본 판면과 비평 주석을 실제 대조하기 전에 해당 절의 원판 인쇄쪽 위치를 검증해야 한다.

마르부르크 취리히본 영인본은 1883년 Usteri의 `Theologische Studien und Kritiken` 제56권 409–413쪽이라는 서지 출처를 서로 독립적인 문서관 목록과 종교개혁 문헌 연구 자료에서 확인할 수 있다. **실제 영인 이미지 파일을 확보한 것은 아니다.**

## 증거의 구별
- 1539년판: 소장 기록 확인, 직접 판독 미완료
- 1559년판: 실물 판본의 공개 스캔 존재 확인, 특정 원문 판면 판독 미완료
- Barth–Niesel 비평판: 온라인 텍스트 및 편집 주석과 원판 스캔은 서로 다른 증거
- 1883년 마르부르크: 팩시밀리 서지 위치 확인, 독일어 이문 전사 미완료
