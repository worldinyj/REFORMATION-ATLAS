# V1.75 · 판본 중심 심층 원고 3편

이번 배치는 이전 V1.74 마르부르크 장과 같은 **역사적 배경 → 문헌·판본 → 쟁점 → 후대 해석 → 독서 질문**의 편집 구조를 반복한다.

- 아우크스부르크 신앙고백: **1,998자 본문**, 1530 제출 / 1531 인쇄 / 1540 수정판 구분
- 칼뱅 1536: **1,749자 본문**, 6장 초판과 박해·헌사, 중간 판본 확대
- 칼뱅 1559: **1,705자 본문**, 4권 80장, 권별 독서 안내와 번역·판본 차이

총 신규 본문 **5,452자**, 21개 절. 분량 계산은 JSON의 절별 `text`만을 기준으로 했다. **3편 모두 2,000~3,000자 목표에 아직 미달**한다. 반올림 또는 표제·데이터 메타 정보를 합쳐 완성됐다고 표시하지 않는다. 차기에는 각 원고의 1차 사료 위치와 반론·신학사적 맥락을 보강해 개별 2,000자 이상으로 높인다.

## 자료 성격
- Augsburg: 현대 편집본과 1531년 실물 소장 안내, 1540 Variata 설명을 참고했다.
- Calvin: Bridwell Library의 판본 전시와 후대 역사 개설, Anthony N. S. Lane의 편찬사 설명을 참고했다.
- 본문은 독립적으로 작성한 한국어 해설이다. PDF·인쇄본의 전문을 복제하지 않았다.
- 개별 원판의 문장·쪽수 직접 교감, 학술 감수, 이미지 권리·최종 공개 승인은 아직 수행하지 않았다.
