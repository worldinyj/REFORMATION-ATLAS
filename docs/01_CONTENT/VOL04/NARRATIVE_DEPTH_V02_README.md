### 왜 DRAFT인가?
1. 일부 근거는 원전 비평판이 아니라 기관 전시·번역·초록 등이다.
2. 제네바 교회규정 1541년 승인 날짜(아카이브 설명 페이지 간 **11/20 vs 11/30**), 취리히 1523년 67개 조항/논쟁 날짜, 멜란히톤 취임일 등은 추가 검토가 필요하다.
3. 루터 1525년 문헌, 마르부르크 취리히/헤센 조항, 멜란히톤 `Loci`, 칼뱅 교회규정/세르베투스 사건은 원전 단락·판본별 대응 대조 전이다.
4. 문헌 원문 인용 및 초상·판화의 이미지 사용 허가가 확보되지 않았다.
