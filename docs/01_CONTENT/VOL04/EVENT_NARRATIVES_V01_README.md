## 각 콘텐츠의 서술 규칙

- 독자가 이해할 수 있는 **장면/배경 → 인물과 집단의 선택 → 문헌·논쟁 → 갈등의 결과 → 남은 역사 질문**을 기본 구조로 한다.
- 신학·정치 권력이 일치했다거나 특정 인물이 도시 모든 판결을 직접 내렸다는 과장을 피한다.
- 인쇄본, 필사본, 목격자 서신, 후대 전사·번역·학술 해설을 구분한다.
- 날짜를 정확한 일자로 만들 근거가 없으면 기간으로 남긴다. **제네바 1541년 11월 20일과 30일 차이를 임의 해소하지 않는다.**
- 1525 농민 요구와 루터의 진압 논리를 서로 다른 문서로 다룬다.
- 마르부르크 취리히 서명본 `E I 3.1, Nr. 54`와 헤센본(K)의 차이는 실물 원문 대조 전까지 미결.
- 세르베투스 사건은 비엔 종교재판과 제네바 시의회 재판, 세르베투스·칼뱅·카스텔리오의 목소리를 구분한다.
- 독자용 사례 문구는 직접 인용을 최소화하고 1차 자료 전체 교감을 완료했다고 표시하지 않는다.
