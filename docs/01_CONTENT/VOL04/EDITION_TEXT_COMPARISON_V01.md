## 연구 근거와 검토 수준
- 칼뱅 판본 구조: Richard A. Muller, *Establishing the Ordo docendi* (2000), https://academic.oup.com/book/50318/chapter-abstract/422710493 ; Anthony N. S. Lane, https://www.crossway.org/articles/an-important-chapter-that-calvin-added-to-the-second-edition-of-his-institutes/
- 루터 도상: Bridwell 소장기관의 1522년 12월판 설명 https://bridwell.omeka.net/exhibits/show/luther/lutherbibles/dezembertestament
- 아우크스부르크 제10조 비교: https://www.augsburg1540.com/1530-1540-comparison-text.html (참고용 대조 사이트이며 16세기 실물 원문 직접 대조는 아님). 개혁파와 루터파 해석 이견을 남긴다.

## 웹앱 데이터 경계
- `case_id`는 연구용 비교 식별자이며 정식 문헌 ID가 아니다.
- `work_family`는 기존 저작 정체성을 유지한다.
- `observation_ko`는 확인 가능한 구조·도상·문구 관찰, `interpretation_ko`는 해석이다.
- `evidence_level`과 `source_text_collated=false`를 명시한다.
- PUBLIC 자료는 검토·권리·사람 승인 이후 별도 스냅샷으로만 발행. 현재 웹앱은 미변경.
