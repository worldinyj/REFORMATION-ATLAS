## 검증 및 게이트

- 전체 상위 후보 **17건 유지**, 분리 필요 부모 **5건**, 연구용 하위 구분 **10건**.
- 하위 항목의 `split_key`는 UI 표시에 쓰는 임시 연구 키이며 `EDN-V04` 등 정식 식별자가 아니다.
- 각 항목에 언어·연도·물적/문서 종류를 기재하되, 확인되지 않은 소장번호는 반드시 `null`을 유지한다.
- 기존 `OV-D-011`(아우크스부르크 신앙고백), `OV-D-012`(『기독교강요』)의 저작 ID는 변경하지 않는다.
- 후속 2차 연구에서 마르부르크 취리히본/헤센본의 **개별 실물 증인**도 따로 분리·대조한다. 현재의 5건 분리 집계와 구분한다.
- 원전 대조, 사본 서지 검증, 저작권, 편집자 승인, 출판 승인을 각각 통과하기 전에는 정본 ID와 공개 스냅샷 생성 불가.
