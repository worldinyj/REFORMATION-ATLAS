# V1.57 — 종교개혁 역사 지도의 도시·연표 연결 패키지

**연구 전용 / main·Google AI Studio 변경 없음**

V1.56 심층 페이지 10편과 도시 수준의 역사 지도 기준점 11곳을 연결한다. 좌표는 도시 중심을 나타내는 **대략적인 지도 기준점**이며 14~16세기 사건 발생 건물의 정밀 위치가 아니다. 연표에서 사건을 선택하면 관련 인물·문헌·도시를 탐색하도록 설계하되, 실제 여행 동선이나 방문 시간은 생성하지 않는다.

## 증거 및 권리 구분

도시 기준점은 독자의 공간적 이해를 위한 **대표 좌표**다. 사건 당시 장소의 현존 여부나 건물 내부 지점을 뜻하지 않는다. 프라하 베들레헴 예배당 관련 정보는 체코공과대학교의 안내를 참고하며, 도시 선택의 기본 배경은 역사 개설에서 교차 검토한다.

초상화는 단지 오래된 그림이라는 이유로 자유 이용 이미지라고 단정할 수 없다. 작가·촬영자·소장기관·원본 이미지 권리를 별도로 확인한다. 지도의 타일 제공업체 라이선스와 필사본 영인 재게시 허가도 독립적으로 확인한다. 이번 패키지에는 **외부 이미지 파일을 삽입하지 않았다.**

## 개발자 반입 계약

- `atlas_v157_historical_city_map.json`: 11개 지도 기준점, 좌표 정밀도, 관련 읽기 페이지 ID, 미디어 권리 게이트
- `atlas_v157_spatiotemporal_links.json`: 페이지→도시→연도→관계 연결 11건
- 페이지 ID는 V1.56의 기존 값을 사용하며 새로운 정본 인물·저작 ID를 임의로 생성하지 않는다.
- `publication_gate.can_ship=false`. 학술·시각 편집자의 승인 후 AI Studio 쪽에서 별도로 적용해야 한다.
