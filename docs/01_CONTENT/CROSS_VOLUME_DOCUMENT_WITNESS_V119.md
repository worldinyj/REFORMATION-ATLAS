# V1.19 — 제3·4권 인물·문헌·판본 교차 연결

**DRAFT_RESEARCH_NOT_PUBLIC** · 2026-10-30

## 개요 데이터 실측
기존 개요에 `OV-D-005` 『교회론』, `OV-D-006` 프라하 4개조, `OV-D-008` 95개조, `OV-D-009` 『그리스도인의 자유』, `OV-D-012` 『기독교강요』가 있음. 각 문서에 기존 개요 출처 ID가 연결돼 있다. 제3권의 원문·편집본·온라인 전사 ID는 `data/vol03_document_witnesses.json`에서 확인했다. 루터·칼뱅의 주장은 각각 심화 데이터의 기존 claim ID를 재사용한다.

## 중요한 역사적 구분
1. 위클리프의 『교회론』과 후대 위클리프파 영어 성경 번역운동은 별개의 연구 대상으로 연결한다. 위클리프 개인이 성경 전체를 직접 번역했다고 표시하지 않는다.
2. 후스는 1415년 처형되었으며 프라하 4개조의 1420년경 문안을 후스의 생전 직접 저작으로 분류해서는 안 된다. 문서는 후대 후스파 운동의 맥락으로 연결한다.
3. 95개 논제는 루터의 1517년 대학 논쟁을 위한 논제 문서다. 전승된 부착 일화와 인쇄 확산은 분리 검증한다.
4. 『그리스도인의 자유』는 1520년 별도 저작이며 95개 논제와 합치지 않는다.
5. 『기독교강요』는 동일한 저작이지만 1536 라틴어 초판, 1541 프랑스어판, 1559 라틴어 최종판, 1560 프랑스어판을 개별 객체로 구분한다.
