# V2.04 — 10편 본문 124개 문단 검토 단위와 핵심 사료 검증 30건

## 목적과 실제 범위
V2.02 원고 10편과 V2.03 절 경계 70개를 변경하지 않고 **124개 본문 검토 단위**에 원문 위치를 지정했다. 각 편의 중요한 역사 주장·판본·사료 전승 주제 **3건씩 총 30건**을 사람이 검증할 작업으로 선택했다. 서로 다른 중점 문단은 27개다.

문단 검토 단위는 **원자적 사실 주장 1개**가 아니다. 하나의 줄/문단에 역사적 사실, 해석, 편집 지침, 유의점이 섞일 수 있으므로 추후 사람의 문장별 분해·판정이 필요하다. 124개 본문과 30개 연구 초점 모두 현재 **입증된 역사 명제 0건**으로 취급한다.

## 신뢰성 게이트
- `passages`의 본문 경계는 UTF-8 바이트가 아니라 Unicode 코드포인트 기반 `[start_char,end_char)`이고, **V2.02 원문에만 유효**하다. 본문 수정 시 V2.05 등 신규 버전과 오프셋을 다시 생성한다.
- `focus_tasks[*].exact_source_excerpt`는 원고 내 **유일하게 나타나는 실제 문자열**이다. 후대 사료의 직접 인용으로 오인하지 않는다.
- 기존 V1.79 출처 링크와 증거카드는 `existing_*_not_proof` 필드의 **주제별 탐색 단서**다. 해당 구절을 사료 판면으로 직접 확인한 기록이 아니다.
- `witness_identifier`, `folio_page_or_clause`는 공란이다. 그 필드를 편집자가 실제 확인한 근거로 채운 다음 별도 검증과 승인 과정이 필요하다.
- 학술 감수·원본 직접 교감·매체 권리 승인·공개 승인 모두 미완료. Google AI Studio 앱, 공개 검색 또는 번들에 이 데이터 연결 금지.
