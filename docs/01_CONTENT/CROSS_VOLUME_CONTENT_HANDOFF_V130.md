# V1.30 — 제3~5권 통합 연구 콘텐츠 인계

2026-10-30 · 연구 전용 · 자동 게시 금지

## 이번 배치
V1.29에서 별도 검토한 제4권 주장 12건을 제외한 **나머지 20건**을 루터 10건·칼뱅 10건으로 정확히 식별하고 소속 출처 ID 연결을 재점검하였다. 20건에서 빠진 출처 ID는 없었다. 단, 이는 **출처 목록 및 범위 메타데이터 대조**로서 실제 출처 본문의 의미론적 전수 검증을 완료했다는 뜻은 아니다.

제3권은 여전히 위클리프파 성경의 직접 필사본 교감 및 후스 공의회 판결 라틴어 대조가 필요하다. 제5권은 이번 배치에서 자료 목록 확인과 검증을 수행하지 않았으므로 임의로 정본이라 표시하지 않는다.

## 앱 연동 계약
권 ID 및 파일 경로를 저장하는 JSON은 연구자 내부 연결용이다. 실물 영인본을 복제·삽입하지 않고 원전 미검증 항목을 역사 사실로 표시하지 않는다. main 병합, AI Studio 자동 동기화, 공개 승인 모두 차단했다.

## 검토 순서
1. 루터 잔여 주장: 하이델베르크 논쟁, 라이프치히, 1520년 저술, 보름스, 마르부르크 성찬 논의, 제국의회·교회 및 세속 권위.
2. 칼뱅 잔여 주장: 회심 시점의 불확실성, 제네바에서의 추방과 복귀, 교회규정, 장로회·시의회 역할, 판본 구조, 세르베투스 논쟁, 1559년 아카데미, 멜란히톤 교류.
3. 각각 원문 문단 또는 학술판으로 판정 강도를 추가 확인하고, 출처의 원문/초록/목록 접근 수준을 구분한다.
4. 제5권의 실재 파일·인물·사건·저작 구조를 다음 배치에서 처음부터 검증한다.
