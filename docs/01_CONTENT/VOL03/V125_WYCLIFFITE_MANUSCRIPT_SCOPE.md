# V1.25 위클리프파 성경 실물 증인 범위

Egerton 617: 잠언~마카베오기, Egerton 618: 마태복음~요한계시록. 각각의 사본이 직접 포함하지 않는 창세기·출애굽기를 해당 사본의 영인본에서 확인했다고 표현해서는 안 된다. BL 목록은 앞부분이 소실된 원래의 세 부분 구성이라는 점도 명시한다.

Manchester English MS 89는 EV/LV 혼합의 사례다. 판본 분류는 책 단위나 사본 구성 단위로 내려가야 한다. 최초 번역자를 단일 인물로 확정하지 않는다.
