## 새로운 교차권 오류 발견
제3권 V1.25의 `V125-C19`는 칼뱅 1536년판과 1559년판 구분이라는 제4권의 타당한 주장에 **AHISTO(후스/Palacký 서지)**를 근거 ID로 연결했다. 출처 식별자 자체는 존재하므로 단순 ID 검증에서는 통과할 수 있지만, 해당 주장을 뒷받침하는 문헌이 아니라는 점에서 의미론적 오류다. 현존 V1.25 자료는 보존하고 V1.26에서 이 연결을 `HOLD_WRONG_SOURCE_DOMAIN`으로 교정 제안한다. 정확한 연결은 제4권 `CLM-V04-CA-002`에 묶인 학술 문헌으로 재검증해야 한다.

## 30개 오류 검증 설계의 실제 실행화
V1.25의 N01–N30을 실제 검증 가능한 *명시적 실패 조건*에 매핑한다. 검증 대상은 자료 표면에 선언된 상태와 참조 관계이며 인공지능이 역사 해석 전체를 자동 판결한다고 주장하지 않는다. 별도 스크립트에서 각 규칙의 올바른 차단과 정상 통과 사례를 함께 검사한다.
