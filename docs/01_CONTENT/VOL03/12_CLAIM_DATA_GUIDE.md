# VOL-03 원전 검증 주장 카드 구조
- `vol03_primary_claims.json`은 주장을 `CLM-V03-xxx`로 식별하고 인물·사건 ID를 연결합니다.
- `textual_basis`는 정확한 **검증 가능한 에디션과 장·절**을 기록합니다. 불확실한 페이지는 강제로 만들지 않습니다.
- `evidence_tier`는 출처에 어떻게 접근했는가, `certainty`는 주장 확인 정도, `review_status`는 사람의 승인 상태입니다.
- 서지·초록·서평은 해당 출판물의 실증적 내용을 읽은 것과 동등한 수준이 아닙니다.
- **핵심 수정**: 1433년 핵심 합의 문안 3개 / 학술 비평판 수록 공식 문서 10개 구별. [V03-S33,S34]
- GitHub에 원문 전문·유료 저술의 대량 번역을 저장하지 않고 자체 해설과 서지 링크만 보관합니다.
