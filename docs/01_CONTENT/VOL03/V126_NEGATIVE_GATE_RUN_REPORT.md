## 실제 시행 결과
GitHub 브랜치에서 `atlas_v126_negative_fixtures.json`와 `atlas_v126_cross_volume_semantic_audit.json`를 다시 읽고 동일한 JavaScript 거부 규칙을 실행하였다.

- 30개 오류 시나리오 모두 해당 규칙 ID가 거부 응답에 포함됨: **30/30 PASS**.
- 정상적인 연구 전용 기본 레코드는 `PASS_RESEARCH_ONLY` 반환.
- 유일한 위험 신호(flag)는 27종이며 N01–03과 N05–06은 동일한 검사 항목을 공유함. 따라서 개별 입력을 삽입할 때 여러 규칙이 동시에 발생하는 것은 정상이다.
- V1.25 `V125-C19`의 출처 AHISTO(후스/Palacký)가 칼뱅 판본 구분을 뒷받침하지 못하는 의미론적 오류를 별도 기록: `HOLD_WRONG_SOURCE_DOMAIN`.
- 자료 전문/필사본 판면의 원본 대조와 이미지·번역물 공개 승인은 **진행되지 않음**.

## 중요한 범위 제한
30건은 각각 위험 신호가 입력되었을 때 거부되는지 점검한 **합성 부정 사례**다. 사용자가 입력하지 않은 문장에 대해 위험 신호를 자동으로 검출하거나, 역사적 사실의 정확성을 증명하는 자연언어 사실검증기는 아니다. 저장된 Node 스크립트의 GitHub Actions 실행은 별도로 확인하지 않았다.
