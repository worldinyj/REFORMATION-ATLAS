## 1. 목적
V0.9-P1 원전 조사와 V0.9-P2 매체 검토가 끝난 부분을 **개별 독자용 해설(캡션·대체텍스트·확정/미확정 구분)**으로 연결한다. 출처 없는 단정이나 AI 인물화를 역사 사진처럼 잘못 전시하는 위험을 낮춘다. 이 문서는 **출판 승인이나 웹 서비스 구현을 의미하지 않는다**.

## 2. 생성한 데이터
- [독자 화면 안전 오버레이](../../../data/vol03_editorial_overlay_v09_p4.json): 미디어 **10점**(인물화 4·사건 삽화 2·SVG 지도 4)에 대해 제목, 고증 위험도, 한국어 캡션, 접근성 대체 텍스트, 수정 지시, 원전/학술 출처 ID 및 인물/장소 참조를 연결.
- 같은 오버레이에 기존 **14개 역사 주장 카드**를 ID로 연동. 기존 주장 텍스트는 재복제하지 않으며 `data/vol03_primary_claims.json`이 정본.
- 검토 대상 자산 ID: PRT-V03-01, PRT-V03-02, PRT-V03-03, PRT-V03-04, ILL-V03-01, ILL-V03-02, MAP-V03-01, MAP-V03-02, MAP-V03-03, MAP-V03-04.
- 모든 공개 제어 필드 `show_in_public=false`, `approved=false`, `can_ship=false`.

## 4. 이미지 검토 결과에서 반드시 되돌릴 수정
- 발도·위클리프 시각물의 대형 고딕 건축을 실제 12/14세기 배경이라고 소개하면 안 된다. 두 자산은 배경 재작업 우선.
- 지슈카 눈의 붕대가 정확한 역사 고증을 의미한다고 오인시켜서는 안 된다.
- 후스 프라하 설교 장면은 특정 예배당 인테리어 복원이 아니다.
- 바젤 협상 그림은 1433 핵심 문안 3개와 1436 공표·1437 후속 교령을 하나의 장면으로 합친 역사 사실이 아니다.
- `MAP-V03-02`와 `MAP-V03-04`의 점선은 사상/문헌 교류를 뜻하며 개인의 직접 여정은 아니다.

## 5. 게시 게이트 및 접근성
1. 최종 학술 심사 전 `show_in_public=false`; SVG 파일 존재가 사용 승인과 같지 않음.
2. `data/vol03_presentation_index.json`의 `media_safe_to_display=false`를 건드리지 않음.
3. 한글 캡션과 대체텍스트를 모두 포함하고 그래프의 REL 관계를 '직접 사제 계보'로 자동 변환 금지.
4. 이미지의 원본 PNG/WebP는 GitHub에 아직 없음. 기존 스테이징 ZIP을 해시 검증하여 설치하는 작업은 사용자 로컬 동기화 때 별도 수행.
5. 역사 고증과 권리 확인은 사람 승인 후 차례로 처리. `main` 병합 및 퍼블릭 라우팅은 보류.

## 6. 이번 작업의 자동 교차 검증
- GitHub에서 읽은 원본 그래프 출처 노드와 모든 미디어 `source_ids` 참조 비교: **누락 0건**.
- `linked_entity_ids`가 통합 그래프의 정식 노드인지 검사: **누락 0건**(출처와 개체 전체 합산).
- 카드: 미디어 10/10, 역사 주장 14/14.
- 매체 고증 상태의 기록 완료 ≠ 학술 사실관계 승인 완료.
