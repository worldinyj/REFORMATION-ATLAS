# 원전 판독 요청·후속 확보 계획

1. 창세기 1:3을 실제 포함하는 EV 필사본과 LV 필사본 각각의 shelfmark와 folio를 확인한다.
2. 출애굽기 7:25에 대해 동일 작업을 수행한다.
3. 애가 2:19의 EV/LV 전사와 원판을 독립적으로 확인한다.
4. 팔라츠키 1869 235/237/286/324 인쇄면과 전사 일치 여부를 확인한다.
5. 공의회 1415년 7월 6일 제15회기 공식 문헌의 라틴어 판본 출처를 확정한다.
6. Relatio에서 같은 사건을 기술하는 문단을 특정하여 문헌 간 행위자/시간을 비교한다.
7. 도서관 이미지 라이선스와 공개 가능한 범위를 확인한다.

이 문서는 요청 초안이며 기관에 실제 요청을 전송한 것이 아니다.
