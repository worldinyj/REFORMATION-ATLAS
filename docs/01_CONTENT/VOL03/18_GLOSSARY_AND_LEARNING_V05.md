# VOL-03 · 학습용 용어집과 독자 질문 (V0.5)
> 2026-10-25 · DRAFT · 16세기 교단 교리를 12~15세기에 기계적으로 소급하지 않는다.

| 용어/개념 | 한국어 교육 설명 | 사용시 주의 |
|---|---|---|
| Ecclesia (교회) | 예배 장소, 신앙 공동체, 성직자 집단, 보편교회 등을 가리킬 수 있는 라틴어 | 문맥·인물마다 의미 다름 |
| Dominium (지배권) | 재산 소유, 통치권과 정당성의 관계를 다룬 중세 정치신학 용어 | 오늘날 단순 토지개혁으로 번역 금지 |
| Apostolic poverty (사도적 청빈) | 사도들의 생활을 본받는 자발적 가난의 신앙 실천 | 수도원 청빈·평신도 설교 구분 |
| Licence to preach (설교 인가) | 성직 또는 공적 권한을 통해 가르침을 허가하고 감독하는 중세 교회 제도 | 청빈 자체의 허가와 혼동 금지 |
| Wycliffite Bible (위클리프 관련 성경) | 위클리프 관련 중세 영어 성경의 필사·개정 전통 | 단독 완역 기정사실화 금지 |
| Lollards (롤라드파) | 잉글랜드에서 위클리프의 사상 일부를 수용한 여러 집단에 붙인 명칭 | 통일된 단일 교파로 묘사하지 않음 |
| Predestination (예정) | 참 교회와 구원의 대상에 대한 중세 신학의 논의 | 후대 칼빈주의 예정론과 자동 동일시 금지 |
| Transubstantiation (실체변화) | 성찬에서 그리스도 현존을 설명하는 서방 신학 교리 | 과학적 성분 변화로 오해 금지 |
| Real presence (실재적 현존) | 성찬에서 그리스도가 실재적으로 함께하신다는 여러 신학 표현 | 여러 교파의 이해가 같지 않음 |
| Concomitance (동반성) | 한 성찬 형태 아래에도 온전한 그리스도가 주어질 수 있다는 교리 | 양형성찬 논쟁의 배경 |
| Sub utraque specie (양형) | 빵과 포도주 두 형태 아래 성찬을 받음 | '실체변화 반대'와 동의어 아님 |
| Utraquists (양형성찬파) | 특히 평신도에게 잔을 나누는 성찬을 강조한 보헤미아 개혁 계열 | 15세기 모든 후스파를 대표하지 않음 |
| Taborites (타보르파) | 타보르를 거점으로 한 후스파의 급진적 경향들 | 내부 단일·고정된 입장 가정 금지 |
| Four Articles of Prague (프라하 4개조) | 말씀 선포·양형성찬·성직자 세속 지배·공개 죄 규율 등 공통 요구 | 1420년 원본과 후대 편집본 구분 |
| Compactata (콤팍타타) | 바젤 공의회·보헤미아 대표들 사이의 복잡한 협상·타협 문서군 | 1433 핵심 3문안 / 2019 비평판 10문서 구별 |
| Unitas Fratrum (형제단) | 15세기 중엽 보헤미아에서 형성된 개혁 공동체 | 현대 모라비아 교회를 1457년 상태와 동일시 금지 |
| Safe-conduct (안전통행 보장) | 이동을 허용·보호하기 위한 중세적 법률적 약속 | 후스 사건에서 세부 법적 효력은 쟁점 |
| Confessionalization (교파화) | 초기 근대에 교단·국가·사회질서가 분화·강화되는 과정에 대한 역사학 개념 | 12세기에 완성된 제도라고 쓰지 않음 |
| Historical edition (역사 문헌 편집본) | 원문을 전사·대조하여 출판한 특정 시기의 문헌 | 저자 당대의 자필 원본이 아님 |
| Later reception (후대 수용) | 후대의 다른 인물·집단이 이전 사상과 인물을 다시 읽는 일 | 직접 만남이나 사제 계승이 아님 |

## 학생용 10개 질문
1. 초기 왈도파에서 핵심 갈등은 청빈 자체인가, 설교의 정당한 권한인가?
2. 위클리프의 성찬론을 단순한 '기념설'로 요약하기 어려운 이유는?
3. 후스가 위클리프에게 영향을 받았으면서도 성찬론에서 달랐던 점은?
4. '양형성찬'의 정의와 '실체변화'의 정의는 왜 같은 질문이 아닌가?
5. 프라하 4개조 첫째와 넷째 조항에는 왜 담당 주체가 중요하게 등장하는가?
6. 후스의 처형 뒤 후스파가 일관된 하나의 운동으로 남지 못한 이유는?
7. 1434년 리파니 전투의 승패와 1436년 종교·정치 협약은 어떻게 다른가?
8. 1433 핵심 합의 문안 3개와 학술판 관련 문서 10개의 차이는 무엇인가?
9. 1532년 왈도파-개혁파 교류와 1847년 '찬포랑 종교회의' 이름의 탄생을 구분해야 하는 이유는?
10. 역사상 종교적 박해를 설명할 때 당대 제도적 논리와 오늘날의 평가를 어떻게 구별할 수 있는가?

## 독자용 3단계 구성
- 입문: 인물 하나와 사건 하나를 이어 읽고 주요 용어 해설 확인.
- 중급: 두 입장을 나란히 놓고 원인·결과와 사건의 직접적 근거 비교.
- 심화: 원전 전사·편집판·학술 연구 초록의 차이를 확인하고 해당 주장 카드의 검증 한계를 읽음.
