## 검증 증거
- GitHub 연결로 관련 파일 **12개**를 직접 재조회하여 인물·사건·원전 주장·문헌 판본·출처 등의 ID 참조 검사.
- 이번 검사에서 누락 ID/연결 오류 **0건**.
- 실제 로컬 Git clone·전체 Python 검증 실행·GitHub Actions 실행 결과를 나타내지 않는다. 현재 실행 환경의 `github.com` 네트워크 DNS 확인 실패.
- 연구 해설은 합법적으로 열람 가능한 서지·판본·번역·서평과 제한된 원문 대조 범위를 명시한다.
