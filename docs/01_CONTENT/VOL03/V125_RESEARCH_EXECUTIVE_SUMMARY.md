# V1.25 대형 연구배치 총괄

## 목표
기존 V1.24보다 연구의 면적을 크게 확대하면서 **사료의 실제 접근 단계와 역사적 주장 강도를 분리**했다. V1.25는 14건 출처, 20건 검토 주장, 필사본/편집본 4종, 대조 본문 후보 5곳, 후스 재판 기록 3층, 서지 충돌 4건, 편집 통제 6건 및 후속 연구 20건을 각각 독립 데이터로 제공한다.

## 주요 성과
1. 영국국립도서관 Egerton 617/618은 창세기·출애굽기의 직접 증인이 아님을 재검증했다.
2. 초기판·후기판의 번역상 특징을 학술연구 수준에서 구분하고, 두 집단 사이의 지속적 수정이라는 대안을 인정했다.
3. 후스 관련 Palacký 1869 원고의 디지털 텍스트 252,254,286,300쪽을 독립 관찰 지점으로 등록했다.
4. 공의회의 심문·최종 판단·후스 측 기록의 문헌 장르 차이를 명시했다.
5. 미승인 인용, 이미지 무단 전재, 원전 판독 완료 허위 표시를 차단하도록 데이터 공개 게이트를 닫았다.

## 중요한 한계
이 작업은 원전 판면 자체를 직접 교감했다는 뜻이 아니다. 문헌 목록·연구 해설·1869 전사본의 확인 단계까지만 인증한다. 본문 5곳은 현재 '연구 후보'로 남아 있으며 역사 서술과 편집용 비교 인터페이스는 공개 미승인이다.
