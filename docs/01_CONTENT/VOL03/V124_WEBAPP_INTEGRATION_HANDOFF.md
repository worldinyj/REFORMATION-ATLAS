# AI Studio 웹앱 연결을 위한 V1.24 인계 메모

이 문서는 **배포 지시서가 아니라 비공개 데이터 계약 안내**다. `data/contracts/vol03_critical_readonly_ui_v124.json`의 세 모듈은 모두 RESEARCH_ONLY. 현재 출력 가능한 것은 연구자 검토 카드의 항목명, 증거 접근 수준, 출처 URL 및 보류 사유이며 현대 학술자료의 긴 본문이나 사본 스캔 이미지 공개는 불허한다.

### UI 구성 제안
- 문헌 계보: EV/LV 구별, Egerton 617/618의 실제 수록 범위, Manchester MS 89 혼합 전승을 각각 별개 카드로 표시.
- EV/LV 비교: Genesis/Exodus/Lamentations의 구절 후보에는 '실물 판면 미확인'을 명시하며 실제 판본 확정 비교 화면으로 승격 금지.
- 후스 재판: 심문(1415-06), 선고(1415-07-06), 후대 편집본(1869)을 연대기 축에서 분리.
- 증거 열람: 카탈로그/학술연구/편집 전사/원본 판면 접근 상태를 구분. 원본 직접 판독 여부를 숨기지 않음.

### 인계 차단 조건
human_approval=false, can_ship=false를 모두 유지. 원문 이미지 사용권/중세 문장 현대 번역의 권리를 별도로 판단. 기존 Google AI Studio/Builder 앱은 이 브랜치에서 자동 갱신하지 않는다.
