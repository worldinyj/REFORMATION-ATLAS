# 제3권 V1.0-P1E · 1435년 브르노 협의 문안의 역사 편집본 추가 검토
> 2026-10-25 · DRAFT, 미공개. 기존 182노드·365관계 및 역사 주장 14건은 그대로 유지한다.

## 1. 이번에 새로 실제 열람한 자료
**František Palacký(ed.), 『Archiv český』 제3권(1844), 421~425쪽**의 공개 온라인 OCR/전사에서 브르노에서 작성된 *Námluwy kompaktat* 협의 문안을 확인했다.
- 421쪽 제목: 바젤 공의회 특사와 보헤미아 왕국 사이의 협의 문서, **라틴어와 체코어 병기**.
- 제목에 붙은 날짜 **1435년 7월**은 본문이 처음부터 '원문에는 날짜 없음'(bez datum)이라고 밝힌 후 **편집자가 추정한 시기**다. 이를 정확한 역사적 일자로 DB에 입력하지 않는다.
- 자료 원문: https://www.rbmonline.cz/portal/book/794?lpage=421
- 해당 권 책의 출판정보: https://www.rbmonline.cz/portal/book/794

## 2. 직접 접근한 인쇄 편집본 텍스트의 내용
| 인쇄 쪽 | 확인된 핵심 | 검증 상태 |
|---|---|---|
| 421 | 브르노 협의 문안의 제목, 라틴·체코어 병기, 원문 무날짜와 편집자 추정 날짜 | 1844 인쇄본 OCR 직접 확인 |
| 422 | 바젤 공의회 대표들의 화해·평화·기존 제재의 처리 | 1844 OCR 직접 확인; 라틴 활자 대조 대기 |
| 423 | 양형성찬을 둘러싼 허용 조건과 추가 협의가 언급됨 | 1844 OCR 직접 확인; 법적 효력 판정 보류 |
| 424–425 | 성찬의 두 형태, 그리스도의 온전한 현존, 성직자의 집전 의무에 관한 논점 | 1844 OCR 직접 확인; 원문 교감 전 정확한 정본 인용 보류 |

**중요한 문서 구별:** 이 텍스트가 협상·합의 형성 과정의 어느 문서인지 밝혀야 한다. 이를 1433년 11월 30일 프라하 **3개 핵심 문안**, 1436년 7월 이흘라바 **공적 선포**, 1437년 **후속 교령** 중 어느 하나와 자동으로 동일시할 수 없다.

## 3. 새로운 출처의 상호 검증
- [Herder-Institut 원전 해설](https://dbs.herder-institut.de/digitale-angebote/dokumente-und-materialien/themenmodule/quelle/3255/details/4733.html)은 1436년 7월 6일 이흘라바에서 읽힌 고체코어 번역 전승을 논하고, **특정 중세 필사본의 옛 체코어 텍스트가 팔라츠키 편집본과 다르다**고 지적한다. 따라서 1844 인쇄본을 유일한 체코어 원문 정본으로 간주해서는 안 된다.
- [Šmahel 2019 비평판 기관 소개](https://cms.flu.cas.cz/en/publications/monographs/die-basler-kompaktaten-mit-den-hussiten-1436-2.html): 공식 관련 문서 **10건** 편집. 이번 조사에서 그 유료 비평판 **원문 전문을 읽지 않았다**.
- [Fudge 2020 전문 서평](https://scholarworks.iu.edu/journals/index.php/tmr/article/view/31313): 1433년 프라하에서 확인한 3개 핵심 문안 및 24개 필사본 대조를 설명.
- 1844 판본은 **직접 접근한 후대 인쇄사료**이고 Šmahel의 2019년 비평판과 1:1로 매칭됐다고 주장할 근거는 아직 없다.

## 4. 보충 구조화 데이터
[보충 원전·편집본 색인](../../../data/vol03_supplemental_witnesses_v10.json)에 출처 정보 4건, 브르노 문안 1건(임시 WIT ID), 판본 접근/추정 날짜/본문 대조 한계/기존 5개 주장·3개 사건 참조를 기록했다.
- `SUP-V03-` 출처 ID는 **이번 연구 보충 색인에 한해 사용**한다. 기존 63개 출처 그래프에 편입한 것으로 표시하지 않는다.
- `WIT-V03-SUP01`은 **새 정식 1435 역사 문헌 ID가 아닌 보충 임시 문서 식별자**다.
- 원문의 긴 라틴어·체코어 텍스트나 사진을 GitHub에 복제하지 않는다. 인용 근거와 자체 해설만 기록한다.
