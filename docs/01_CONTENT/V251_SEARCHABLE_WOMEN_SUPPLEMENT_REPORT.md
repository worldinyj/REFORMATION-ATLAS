# V2.51 여성사 보충 해설의 검색·원고 연결

DRAFT · 2026-11-03 · 공개 HOLD

V2.50의 본문을 그대로 유지하면서 8절·16문단을 검색 가능한 문장으로 구조화했다. 기존 핵심 543문장과는 별도 ID 공간을 사용한다. 문장 위치는 보충 문단 내 Unicode 코드포인트이며 기존 핵심 원고의 좌표를 변경하지 않는다.

## 기존 원고와 연결한 읽기 경로

| SEC-V251-R02 | SNT-V219-LUTHER1517-0002 | 루터의 수도회 배경에서 여성 수도자의 별도 경험으로 읽기를 확장한다. |

기존 원고에는 농민전쟁을 독립적으로 다루는 장이 없으므로 새 농민전쟁 장이 이미 존재한다고 연결하지 않았다. 네 기존 원고(루터1517·1521, 츠빙글리, 아우크스부르크)에서 실제 존재하는 문장을 선택했다. 주제상 탐색 연결은 인과관계나 문장 내용의 상호 입증이 아니다.

## 근거를 읽는 방법

보충 절의 6개 근거 장부를 유지하며 각 문장은 해당 절의 근거 묶음을 물려받는다. 이 연결은 문장별 원전 입증 완료 표시가 아니다. 검색 결과에는 근거 층위·미해결 조건·공개 보류를 함께 출력한다. 소피아의 인쇄 숫자가 검색되어도 자필 승인값으로 바뀌지 않는다. 황제 접수나 게스의 독립 증언도 검색어 일치만으로 확정하지 않는다.

## 검색 사용

저장소 루트에서 실행한다. 네트워크와 웹앱 배포 없이 로컬 JSON을 읽는다. 검색은 Unicode 정규화 후 제목·주제어·문장의 부분 문자열로 작동하며 형태소 분석이나 역사적 의미 추론을 하지 않는다. 여러 검색어는 모두 포함되어야 한다.

```bash
python scripts/query_atlas_v251.py --query "소피아" --limit 3
python scripts/query_atlas_v251.py --query "숫자" --limit 3
python scripts/query_atlas_v251.py --section R07 --limit 2
```

결과에는 보충 문장 ID와 원문, 근거 ID·층위, 관련 핵심 원고 문장과 비교 이유, HOLD 상태가 포함된다. 이 출력은 연구자 검토용이며 사용자에게 공개된 앱 화면은 아니다.

## 보존과 미완료 범위

기존 핵심 10편·543문장 및 V2.50 데이터의 SHA256을 보존한다. 신규 원판 판독은 0면이다. 신규 역사 해설을 다시 썼다고 세지 않으며 V2.50의 16문단을 그대로 구조화한 성과다. 검색·연결 기능은 준비했지만 Google AI Studio 앱에 탑재하거나 main에 병합하지 않는다.

구조화 결과: 보충 59문장, 비교 연결8건. 기존543문장과 합쳐 핵심 원고가 늘었다고 집계하지 않는다.

## 검증 결과

연구 검사 V2.19–V2.51 33개와 Draft 검사 7개가 통과했다. 원문 오프셋·문장 누락·중복 구조·끊어진 연결을 검사했다. 오프셋 오류, 없는 핵심 문장, 비교의 인과관계 승격, 근거의 확정 판독 승격, 공개 게이트 변경의 오류 변형 5개를 거부했다. CLI의 숫자 검색·절 필터·무결과와 잘못된 입력 거부를 실제 실행으로 확인했다.
