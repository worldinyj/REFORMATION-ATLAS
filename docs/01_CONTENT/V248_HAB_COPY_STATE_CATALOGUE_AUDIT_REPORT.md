# V2.48 HAB 소장본 목록과 인쇄 상태의 구분

상태: DRAFT · 2026-11-03 · 공개 보류

볼펜뷔텔 HAB의 공식 루터 인쇄본 목록 1220·1221항에서 O90 3점과 O91 8점의 청구기호를 확인했다. 이 가운데 본문 읽기를 명시한 세 프로필을 추출했다. 신규 원판 이미지 판독은 0면이다.

## 1. 같은 O91 안의 차이

1221항의 대표 소장본 147.5 Theol. (14)는 A3r에서 약한 쉼표, A4r에서 kloisters와 schrfftlich를 가진다고 목록이 설명한다. 같은 항목의 일곱째 소장본 116.10 Theol. (11)은 강한 쉼표와 klosters·schrifftlich로 별도 기재되어 있다. 이 차이는 VD16 O91이라는 분류와 실제 인쇄 상태를 같은 뜻으로 취급하지 말아야 함을 보여 준다. 여기서 확인한 것은 도서관 목록의 소장본별 기술이다. 해당 책의 사진을 새로 읽은 결과가 아니다.

## 2. O90의 목록 기술과 빈본의 사진

1220항은 표제 오자형 O90으로 분류하며 대표 소장본 127.21 Theol. (15)에 강한 쉼표와 교정된 A4r 두 단어를 기록한다. 이는 V2.47의 빈 O90 사진에서 확인한 A4r 단어와 양립한다. 그러나 빈본 A3r은 결락 상태이므로 HAB 목록의 문장부호를 빈본의 직접 관찰값으로 옮겨 쓰지 않는다. 나머지 두 O90 소장본은 청구기호만 등록하고 개별 읽기는 비워 두었다.

## 3. 대표 기술을 다른 소장본에 자동 복제하지 않는다

O91 항목의 나머지 여섯 소장본에는 이번에 검색으로 확인한 텍스트 안에서 별도 읽기가 명시되지 않았다. 대표 기술이 이들 모두에 똑같이 적용된다고 단정하지 않는다. 데이터는 11개 소장 표기와 3개 명시적 읽기 프로필을 나누었다. 표제 역시 항목 수준의 기술인지 개별 사진 관찰인지 구분한다. 같은 청구기호의 재제본·합철 이력이나 물리적 완전성도 이번 목록만으로 확정하지 않는다.

## 4. WA 15의 Aa·Ab 문제에 주는 범위

HAB는 1220항을 Aa, 1221항을 Ab에 대응시키면서도 본문 읽기의 차이를 따로 기록한다. 따라서 표제와 본문 교정이 항상 하나의 묶음으로 움직인다고 전제할 수 없다. 다만 이 목록만으로 WA 15 인쇄81쪽의 충돌하는 Ab 표기를 어떻게 고쳐야 하는지는 결정할 수 없다. V2.47에서 보존한 인쇄상 불일치를 그대로 유지한다. 새 목록이 기존 편집자의 인쇄 순서 가설을 독립적으로 증명했다고 주장하지 않는다.

## 5. 뮌헨본과 HAB 소장본의 관계

뮌헨 O91의 교정된 A4r 두 단어는 HAB의 일곱째 O91 프로필과 유사하다. 유사한 읽기는 물리적으로 같은 책이라는 뜻이 아니다. 인쇄 상태의 동일성도 몇 단어만으로 확정할 수 없다. 향후에는 표제, A3r 문장부호, A4r 두 단어, B첩의 선택 이문을 각각 사진으로 확인해야 한다. 이번에는 추가 B첩 이문을 대조 완료로 계상하지 않았다.

## 6. 접근 기록과 재현의 한계

HAB 직접 HTTP 요청은 403이었다. 두 검색 엔진이 반환한 동일 공식 URL의 목록 텍스트를 대조했다. 전면 HTML이나 원판 사진을 내려받았다고 기록하지 않았다. 할레 링크는 HTTP 200이지만 실제 응답은 접근 확인 HTML이므로 원판 판독으로 세지 않는다. 접근 제약을 우회하지 않았다. 검색 색인의 최신성과 목록 원문의 완전성에는 한계가 있으므로 후속 검토에서 원 목록과 실제 인쇄면을 다시 확인해야 한다.

## 7. 다음 원판 대조의 우선순위

가장 중요한 대상은 HAB O91의 대표본과 일곱째 소장본이다. 같은 서지 번호 안에서 명시된 차이를 사진으로 검증하면 표제·본문 교정의 조합을 더 정확히 설명할 수 있다. O90의 완전한 A2·A3도 확보 대상이다. 소피아 편지의 숫자 최종 판독, 1526년 청원 원판 판독은 이번에 진척된 것으로 계산하지 않는다. 독립 증언의 추가와 같은 인쇄물의 상태 비교도 별도로 다룬다.
