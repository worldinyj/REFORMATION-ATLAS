# V3.31 — 1788년 콜록판과 1789년 로스판의 원본 인쇄면 접근 감사

> **MEDIUM · DRAFT · publication HOLD.** 본 연구는 1788·1789년 당대 원본 책의 특정 인쇄면 0면을 새로 직접 판독한 접근·서지 검증이다. 1898년 역사서, 1997년 학술 논문의 인쇄면 검토 이력은 후대 자료이며 초판 원본과 엄격히 구별한다.

## 1. 실질적 결론

1788년 엘리자베스타운 셰퍼드 콜록판은 표제에 다른 유용한 문헌의 부속을 명시한다. 1898년 타이거트와 프랭크 베이커는 별도 『일반 규칙』 제19판을 이 부속물 가운데 하나로 적었고, 베이커는 1789년 윌리엄 로스판 제5판에서 『일반 규칙』이 본문으로 편입되었다고 설명한다. **그러나 1788/1789 원래 인쇄면의 실제 장절·쪽수·글자 단위 이문 검증은 아직 완료되지 않았다.**

한편 19세기 역사가 네이선 뱅스는 1789년 제5판의 『일반 규칙』에서 술 취함과 증류주 매매·음용을 금하는 규정을 인용한다. 이것은 원문 직접 사진이 아닌 **역사가의 원전 인용**이다. V3.31에서는 판본의 물리적 위치 변화와 해당 조항의 내용 변화, 회원 심사기간 개정을 **세 개의 다른 연구 과제**로 구분한다.

## 4. 중간 수준 역사 해설 3편 · 9절

### 1. 1788년 표제에 적힌 부속 문헌과 1789년 본문을 읽는 방법

#### 표제지의 한 구절이 출판물 전체를 설명한다

1788년 엘리자베스타운 셰퍼드 콜록판의 서지는 다른 유용한 문헌을 부속했다고 명시한다. 타이거트는 1898년 역사서 106쪽에 이 책의 제목과 인쇄인을 상세하게 전사했고, 실제 도서관 희귀본 소장 기록도 존재한다. 표제지가 부속 문헌을 예고한 것은 분명한 서지 단서지만, 그 부속물 각각의 원래 페이지 경계와 문구를 완전히 확인했다는 뜻은 아니다.

#### 1788년 부속물에 있던 웨슬리의 규칙

타이거트와 프랭크 베이커의 역사 연구는 코크와 애즈베리의 이름이 붙은 『일반 규칙』 제19판이 1788년 미국 규정집에 별도 표제지로 포함되었다고 기록한다. 부속 문헌 자체의 1787년 5월 28일이라는 날짜는 인쇄본의 1788년 간행연도와 구별된다. 따라서 이 사건은 1784년 교회 조직이나 1785년 최초 규정집 간행과도 별개다.

#### 1789년에는 무엇이 바뀌었다고 보는가

베이커는 1789년 제5판에서 『일반 규칙』이 규정집의 일반 본문으로 이동했다고 설명한다. 이는 역사적 문헌 배열에 관한 학술적 판단이며, 조항의 모든 문장이 같은 형태로 옮겨졌다는 직접 대조 증명은 아니다. 이번 자료 접근에서는 1789년 로스판의 정확한 본문 시작 페이지를 확인하지 못했으므로 이를 다음 원문 대조 위치로 지정한다.

관련 개요: `OV-D-017`, `OV-E-027`

### 2. 제명과 성찬: 1788년 41쪽을 둘러싼 역사적 읽기

#### 신앙회 회원 자격과 성찬 참여는 같은 권리가 아니었다

레스터 루스의 1997년 학술 논문은 초창기 미국 감리교회가 회원 자격과 성찬 참여를 각각 규율했다고 설명한다. 1785년·1787년판과의 관계를 살핀 뒤 1788년 콜록판의 41쪽을 구체적으로 인용한다. 이 연구는 감리교회가 단순한 자격 명단을 넘어 예배와 공동체 생활을 연결해 규정했다는 점을 보여 준다.

#### 학술 논문 67쪽과 1788년 원본 41쪽은 다르다

루스가 해당 규정을 인용한 것은 1788년판의 1992년 복각본이다. 앞선 V3.30에서 화면으로 확인한 것은 루스의 1997년 학술지 인쇄면 66·67쪽이지, 1788년 콜록판 41쪽이나 복각본 41쪽의 사진이 아니다. 이 차이를 명시하지 않고 '1788년 실물 대조 완료'로 표시하면 자료의 검증 수준을 잘못 전달하게 된다.

#### 규정집과 『일반 규칙』을 같은 장으로 합치지 않는다

1788년 41쪽의 제명·성찬 규정은 규정집 본문의 특정 위치를 가리킨다. 그것이 책 뒤의 별도 『일반 규칙』 제19판 문구와 동일한 조항인지 확인하지 않았다. 문헌의 위치가 다르면 같은 개념을 다루더라도 별도 증거 카드로 관리하고, 원본을 확보한 다음에만 정확한 인용문을 연결한다.

관련 개요: `OV-D-017`

### 3. 1789년 금주 조항과 판본 대응의 한계

#### 뱅스가 인용한 1789년 규정집

19세기 감리교 역사가 네이선 뱅스는 1789년 제5판 『일반 규칙』의 술 취함과 주류 매매·음용 금지 문구를 인용했다. 그는 이를 웨슬리 규칙의 예외적 허용 표현과 비교해 해설한다. 1789년 원본의 해당 인쇄면을 직접 판독하지 않았기 때문에 지금은 '뱅스가 1789년판의 내용이라고 인용한 문구'라는 범위를 넘어서지 않는다.

#### 본문 편입과 규정의 강도 강화는 다른 변화일 수 있다

『일반 규칙』이 책의 부록에서 규정집 본문으로 옮겨졌다는 베이커의 설명과 금주 조항의 문구가 더 엄격해졌다는 뱅스의 역사적 설명은 서로 다른 유형이다. 어느 쪽이 실제 규정 변경의 원인이었는지, 내용 변경과 인쇄상 위치 이동이 같은 해 같은 회의에서 확정되었는지는 원본과 회의 자료를 보아야 한다.

#### 검증 대상은 위치·문구·효력일을 따로 가진다

다음 연구에서는 1788년 원본 부속 『일반 규칙』의 표제와 날짜, 1789년 원본 『일반 규칙』 본문 시작 위치, 뱅스가 인용한 금주 문구, 별도의 회원권 6개월 심사규정의 위치를 각각 독립된 단위로 판독해야 한다. 현대 1888년판이나 2016년 교단 문헌의 문구를 1788년 또는 1789년 원본의 글자와 같은 것으로 추정하는 일은 차단한다.

관련 개요: `OV-D-017`, `OV-E-027`

### 원본 접근 실패를 검증 결과로 기록하는 이유

이번에는 Google 전자책 안내에서 1788년 책이 117쪽인 것과 출판인을 확인했지만 41쪽·부속 표제지의 실제 사진은 열지 못했다. 반더빌트 희귀본 소장목록은 책의 실물 존재를 보증하지만 해당 표제지를 공개하지 않는다. Evans-TCP 공개 색인에는 **1787년 로스판**이 있지만 연결된 PhiloLogic 열람기는 JavaScript 실행을 요구하며 현재 연구 도구에서 직접 텍스트를 읽지 못한다. 이를 **1788년판 또는 1789년판 원본 확보 성공**으로 표시하면 안 된다.

특히 Google Books의 **1888년** 감리교 규정집 목차에 『일반 규칙』이 보이는데 이는 1788년 콜록판에서 **100년 뒤** 발행한 다른 책이다. 1888년 페이지 번호를 1788년 원본의 페이지 위치로 대체하면 역사적 오독이 발생한다.
