## 3. 기계적 연결망 구축 규칙

- **사건(EVENT) → 원고(READER):** 실제 V3.07 목록에 존재하는 ID만 허용한다.
- **사건(EVENT) → 개요(OVERVIEW):** 최신 연결 갱신과 V3.10 패치 후 실제로 해당 원고와 교차하는 개요 ID만 허용한다.

- **동일 지명·출판인 차단:** 스페인–네덜란드의 뮌스터 조약/제국–프랑스 IPM/제국–스웨덴 IPO는 서로 다른 \`work\` 값을 가진다. 본문 이문이 확정되기 전에는 다른 판본에 차이가 있다고 자동 표시하지 않는다.
- **검증 실패 정책:** 없는 독서 원고 참조, 초기 제외 규칙 위반, 연표의 날짜/정밀도 혼동, 배포 게이트 해제, 다른 조약을 동일 판본으로 취급하는 오류가 발생하면 빌더가 실패한다.
