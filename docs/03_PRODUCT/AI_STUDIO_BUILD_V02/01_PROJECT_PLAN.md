## 1. 목적
누구나 초기 교회사에서 한국 교회사까지 전체 흐름을 이해하고, 인물·사건·문헌·주제 사이를 자연스럽게 탐색하는 **미니멀 역사 아틀라스**. 처음에는 개요 수준의 잘 연결된 정보를 제공하고 이후 위클리프·얀 후스·루터 등의 깊은 연구를 **같은 URL의 상세 블록에 추가**한다.

첫 번째 성공 기준은 '8권 전체를 탐색할 수 있는 현대적 웹 프로토타입'이지 '모든 역사적 원전의 완전 교감'이 아니다.

## 2. 실행 플랫폼 — Google AI Studio Build
- 플랫폼: Google AI Studio **Build > Web app**. 2026년 공식 기본 구성이 **React 프런트엔드 + Node.js 서버 측 런타임**이므로 기존 Astro 우선 제안은 폐기하고 **React + TypeScript** 기준으로 모든 설계를 통일.
- 코드 스타일: React 함수 컴포넌트, TypeScript strict, React Router 또는 동등한 클라이언트 라우팅(실제 생성 결과에 맞게 고정), Tailwind CSS 또는 일관된 CSS 변수(비주얼 토큰 정의는 04 참조).
- 저장소: `worldinyj/REFORMATION-ATLAS`를 장기 정본으로 사용. Google AI Studio의 GitHub 가져오기/동기화는 **사용자가 직접 연결하는 절차**. 자동 푸시·`main` 덮어쓰기 금지.
- 데이터: Git 내 JSON/Markdown 개요 자료를 입력으로 사용. **MVP에서는 DB/Firebase/로그인/Gemini API 미필수**. 외부 API·Firebase·Cloud Run은 후속 요구에 따라 선택.
- 프리뷰: AI Studio 내부 미리보기 및 개인 로컬 프리뷰에서만 DRAFT 문서를 시험. 공유 링크/Cloud Run 배포는 **별도 승인**.

## 3. 디자인 미션: Quiet Editorial Atlas
**키워드:** 넓은 여백, 차분한 학술 신뢰감, 현대적 콘텐츠 발견, 절제된 모션, 읽기 중심.
- 2026년 트렌드의 장점을 선별: 큼직한 편집형 제목, 시선이 머무는 여백, 질서 있는 비대칭, 낮은 시각 소음, 충분히 큰 터치 영역, 은은한 인터랙션.
- 피해야 할 것: 앤티크 양피지·화려한 성화 복제, 무거운 스큐어모피즘, 글래스모피즘 남용, 대시보드형 KPI 카드, 보라색 AI 그라디언트, 카드/애니메이션 과잉.
- 컬러 후보: Warm off-white `#F7F8F5`, Ink `#1C2925`, Forest `#205F50`, Muted `#4B6058`, Border `#DDE5DF`, White `#FFFFFF`.
- 가로 여백: 모바일 20px, 태블릿 32px, 데스크톱 64px 이상; 본문 폭 680~760px, 전체 컨테이너 최대 1200px.
- 화면은 **가독성과 정보의 신뢰성 우선**, 이미지는 나중에 승인된 출처/역사 고증 자료만 선택적으로 추가.

## 4. 대상 사용자
**우선:** 일반 역사 독자/교회교육 입문자. **보조:** 소그룹 인도자·교육 담당자. **후속:** 원문 비교·번역/신학 논쟁을 다루는 연구 지향 사용자.

## 7. 외부 공개/역사적 책임
- 역사 주장 정확도·번역판본·출처 접근 수준·편집 검토·이미지 저작권·게시 권한은 독립 게이트.
- 옥스퍼드–프라하 지도상의 점선은 문헌 영향이지 실물 여행 경로가 아니며, 22개 장소는 지도 핀 좌표 고증 전까지 **목록으로만**.
- 미승인 제3권 인물화·사건화는 실제 생전 초상이 아니고 웹 번들에 넣지 않음.
- **GitHub 공개 저장소와 웹페이지 게시 상태는 별개다.** AI Studio 공유/Cloud Run Publish는 사용자가 접근 범위와 비용을 확인한 뒤 진행.

## 8. 의사결정 가정
- 1차 언어 한국어, 원어/영문명은 보조·검색 별칭.
- React+TS, 최소한의 컴포넌트와 클라이언트 검색, 데이터 추가 중심 확장.
- Google AI Studio Build 내부 미리보기를 개발 출발점으로 사용.
- 설계 내용은 사용자 요청대로 **하나의 일관된 초안으로 일괄 생성**. 사용자 검토 전에 승인 완료로 표시하지 않음.
