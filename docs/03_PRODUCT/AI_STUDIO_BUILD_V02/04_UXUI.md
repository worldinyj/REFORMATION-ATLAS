## 1. 미학적 컨셉
**“Modern museum meets reading journal”**. 박물관의 편집적 절제와 좋은 읽기 앱의 몰입감을 결합한다. 고급스럽되 호화롭게 꾸미지 않는다.

**지향:** 공간 비율, 글자 크기 대비, 선명한 정보 계층, 얇은 구분선, 4/8px 리듬, 손가락과 시선에 편한 패딩, 정돈된 비대칭, 은은한 hover/focus 피드백.

**금지:** 오래된 양피지 질감, 역사적 인물의 미검증 사진/AI 초상 자동생성, 거대한 색 그라디언트, 3D/글래스 카드 남발, 마구 배치한 아이콘, KPI형 대시보드, 과도한 반짝임, 끊임없는 스크롤 애니메이션.

## 4. 상세 페이지 공통 레이아웃
### 4.1 권별 상세
\`\`\`text
홈 / 04 16세기 종교개혁
────────────────────────────
04   16세기 종교개혁
     16세기 | 독일·스위스·영국·스코틀랜드...
     
     [4~6문장 개관 — 읽기 폭 720px]
     
     주요 인물             사건의 흐름
     [루터] [츠빙글리]      [1517] ─ [1521] ─ [1529] ─ [1530]
     [칼뱅] [멜란히톤]

     관련 문헌 / 사상 주제 / 출처
\`\`\`
- 제목과 메타정보 사이에 충분한 여백, 본문과 사이드 레일은 데스크톱에서만 분리.
- 권 상세에서 모든 항목을 한 화면에 빽빽이 보여주지 않는다. 각 섹션 최대 4~6개 미리보기 + “더 보기”.

### 4.2 인물 상세
\`\`\`text
[홈 / 04 / 인물]
마르틴 루터
Martin Luther                              1483—1546
─────────────
[핵심 설명 4~6문장]
주요 논점: 성경 권위 · 면벌부 논쟁 · 은총/칭의
[관련 사건] 1517 · 1521
[대표 문헌] 95개조 · 그리스도인의 자유
[자료·출처] · 현대 개요 / 학술연구
[심층 해설] 준비 중 또는 승인된 블록만
\`\`\`
- 역사적 인물 사진을 임의로 생성하지 않는다. 미디어 없는 초기 화면도 타이포그래피로 완결.
- “인물 배경 → 논점 → 연대 → 문헌 → 관련 인물 → 출처” 고정 구조를 유지.
- 심층 연구가 추가되면 **같은 페이지에서** 접힘 섹션/탭/앵커로 추가한다.

### 4.3 연대표
데스크톱은 가운데 세로선 또는 간결한 왼쪽 날짜 열, 모바일은 왼쪽 연대·오른쪽 본문으로 **한 줄기**. 모든 날짜는 원본 \`date_label\` 그대로 노출. “1420년 전후”를 “1420.01.01”로 만들지 않는다.

### 4.4 문헌
문헌의 짧은 해설을 먼저 보여주고, “원작 / 현대 편집본 / 번역 / 학술서평” 레이어는 표제로 분리한다. 유료 원전 전문을 임의로 삽입하지 않는다. 외부 원문은 링크와 접근 수준만.

### 4.5 제8권
VOL-08은 01~07과 디자인 스타일은 같되 카드에 **주제 분류 태그**를 배치한다. 8번째 연대 시대라고 쓰지 않는다. 성경 권위·성찬론·교회론·번역 등 주제 10개에서 시대를 가로질러 인물/문헌을 찾는다.

## 6. 반응형 규칙
| 화면 | 규칙 | 테스트 |
|---|---|---|
| 320~767px | 상단 메뉴 단일 버튼, 1열, 폭 100% 검색, 가로 패딩 20 | 320 / 375 |
| 768~1199px | 2열 카드, 보조 메타정보 우측 | 768 / 1024 |
| ≥1200px | 4열 권, 넓은 히어로, 읽기 컬럼과 우측 연관자료 | 1440 |

표는 모바일에서 무조건 축소하지 말고 카드/행 리스트로 재배열. 제목/긴 라틴어 문헌명은 줄바꿈 가능. 탭으로만 정보를 숨기지 않고 중요한 출처 문장은 본문에도 표시.

## 7. 상호작용
- Hover: 과하지 않은 테두리 색/텍스트 강조, 120~200ms. 움직임·색상만으로 상태 구별 금지.
- Focus: 명확한 아웃라인, 링크 영역 44px 이상 터치 권장.
- 검색: 200~300ms 입력 디바운스(초기 데이터에 따라 즉시 반영도 가능), 결과 유형·권 표시.
- 필터: 전체/인물/사건/문헌/주제, 선택을 쉽게 초기화.
- 연관 콘텐츠: 관계 유형 \`textual_influence\`는 “저술의 영향” 등 설명을 표시, “직접 사제 관계”라고 쓰지 않는다.
- 키보드 및 스크린리더: skip link, 랜드마크, H1 1개/페이지, 의미 있는 링크 텍스트, aria-expanded, 에러·결과 변화 안내.
- prefers-reduced-motion: hover/전환의 과도한 이동·시차 효과 제거.

## 8. 콘텐츠 배지·출처·검토 상태
내부 프리뷰에서는 모든 개요가 DRAFT임을 작고 명확한 텍스트로 표시. 외부 공개는 승인된 데이터만. 감수 등급·원전 접근 등급·이미지 권리 등급은 **서로 다른 필드**이므로 하나의 빨간/초록 배지로 합치지 않는다.

- 예: “개요 자료 · 출처 대조 중” / “라틴어 원전 전문 미열람” / “후대 편집본·자체 요약”.
- 현행 인물화는 초상 사진처럼 표기 금지. 이미지는 초기에 없어도 충분히 완성된 UI 제공.
- 장소는 현대 도시명/역사 맥락을 구분하여 표시하고 실제 지도 핀은 없음.

## 9. UX 수용 체크
1. 홈에서 8권과 사이트 목적 이해.
2. 인물 하나에 3번 이하 조작으로 도달.
3. 루터→1517 사건→95개조 문헌 이동.
4. 후스와 위클리프의 관계를 “문헌 영향”으로 이해.
5. 1436년의 상이한 행위를 날짜로 합치지 않음.
6. VOL-08의 주제별 탐색을 실제 시대 탐색과 구별.
7. 모바일 긴 이름·본문·문헌 검색 결과가 가로 넘치지 않음.
8. 현재 사용 가능한 콘텐츠와 준비 중 심층 자료 구별.
9. 키보드로 메뉴·검색·링크·필터 전부 사용.
10. 공개 빌드에 미승인 자료·이미지 0.
