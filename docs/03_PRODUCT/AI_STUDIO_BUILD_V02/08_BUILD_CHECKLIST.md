# 08 · AI Studio Build 실행 전 점검
> DRAFT / 작업 후 증빙해야 할 체크리스트. 현재 체크박스는 실제 작업을 수행했다는 기록이 아님.

## 원본 준비
- [ ] GitHub에 이 01~08 패키지와 개요 자료가 존재함 확인
- [ ] 현재 Google AI Studio Build > Web 에서 프로젝트를 열 수 있음
- [ ] AI Studio가 React/TS 빌드 구조를 실제 어떻게 생성했는지 확인
- [ ] GitHub 동기화 시 저장소/브랜치를 직접 확인, main 보호
- [ ] 디자인 토큰/마스터 프롬프트를 모델에 제공

## 첫 화면 검수(B1)
- [ ] 홈 H1, 큰 여백, 8권 카드 8장과 정확한 제목
- [ ] 8권 자료실은 별도 시대가 아님을 표시
- [ ] 메뉴·카드·직접 경로 및 모바일에서 정상 작동
- [ ] 단일 강조색, 과도한 그림자/이미지/효과 없음
- [ ] 콘텐츠가 DEMO인지 실제 원본인지 표시

## 데이터 및 사실성(B2/B3)
- [ ] 8/33/34/20/22/10/32/23 실제 JSON 개수 확인
- [ ] 출처 11건 확인 범위/나머지 미확인 구분
- [ ] 발도·위클리프·후스 3개 기존 인물과 ID 교차 검사
- [ ] 근사 연대·무날짜 원전 문서를 임의 일자로 변경하지 않음
- [ ] 지도 핀 0, 미승인 인물화 0
- [ ] 문헌 원작/후대 번역/편집본·서평 구분
- [ ] 동일 인물 상세에 향후 심층 블록 삽입 가능

## 품질(B4)
- [ ] 14개 경로, 6개 사용자 흐름 검수
- [ ] 모바일 320/375, 태블릿 768, 데스크톱 1024/1440 확인
- [ ] 키보드/포커스/접근성, 오류·빈 결과 상태
- [ ] 빌드/typecheck 실제 성공 로그 확인
- [ ] GitHub diff와 기능 브랜치 확인
- [ ] DRAFT 데이터가 외부 배포 번들에 포함되지 않았음을 검사
- [ ] API 키/비밀값 클라이언트 노출 없음
- [ ] 사용자 별도 승인 전 Publish/Share/Deploy 없음

## 개발 완료/배포의 구별
개발 단계 UI 미리보기 PASS → 코드 리뷰 PASS → 개요 콘텐츠 승인 → 저작권/고증 승인 → 배포 승인. 첫 번째 PASS만으로 다른 네 가지를 완료 처리하면 안 된다.
