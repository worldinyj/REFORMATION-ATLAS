# V3.06 검토 화면 및 자동검증 범위

새 V3.06 UI는 V3.04 원본 전달본, V3.05 신규 원고, V3.04 개요 연결표를 서로 독립된 체크섬으로 확인한 뒤 메모리에서 495편을 결합한다. V3.04 원본은 SHA256, 나머지 두 입력은 고정된 Git blob SHA1과 비교한다. 어느 입력이라도 다르면 화면은 자료 불러오기 실패로 중단하고 임의의 대체 원고를 넣지 않는다.

Chromium 화면 검사는 폭 320·375·1440px에서 검색, 키보드 이동, URL 유지, 원고 본문·질문, 20개 신규 해설 상세, 출처의 이전 확인 범위, 새 경로를 포함한 탐색을 실행한다. 검증 성공 여부는 해당 커밋의 CI 결과를 기준으로 판단하며, HTML 코드가 존재한다는 이유만으로 PASS 처리하지 않는다.

개요 연결 검증은 실제 AI Studio 앱의 라우트 대조가 아니라 저장소의 개요 97개 중 대응 상태를 확인하는 것이다. 미대응 18개, 일부 해설 14개의 제한을 그대로 유지한다. 495편이라는 수는 중간 깊이 집필 목록 수이며 역사 전문 감수 완료 수가 아니다.
