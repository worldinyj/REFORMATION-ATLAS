# V3.02 — 455편 통합 전달본과 개요 연결

상태: DRAFT · 중간 깊이 · 공개 보류

기존 435편과 V3.01의 20편을 하나의 전달본으로 통합했다. 새 집필은 0편이며 누적 455편·1,365절·455질문·출처 레코드 650건이다. URL 중복을 제거한 고유 자료 수나 검증 완료 수가 아니다. 기존 원고 435편과 새 20편의 본문·질문은 그대로 보존했다.

## 편집 검토

20편의 본문과 V3.01 출처 범위를 읽고 아래 경계를 확인했다. 본문 개정은 0건이다. 같은 내용을 다룬다는 이유로 인물·사건·문헌을 삭제하지 않고 읽는 역할을 나누었다. 원문 전수 대조나 외부 자료의 신규 확인은 수행하지 않았다.

신규 60개 본문 절을 기존 1,305절 및 신규 절과 문자열로 비교해 완전 일치 중복은 없었다. 의미 중복이 전혀 없다는 판정은 아니다. 특히 발도/리옹 빈자, 야코우베크/성배 실천, 프라하 강령 사건/문헌, 바젤 협상/협약, 첼치츠키/그물은 인물→사건→문헌 또는 사건→문헌 순서로 읽는다.

## 읽기 연결과 범위

새 읽기 경로 3개를 추가해 총 21개가 됐다. 3개 경로는 새 20편을 모두 포함하며 역사적 영향 관계나 자동 연대 데이터로 사용하지 않는다. 기존 18개 경로와 원고의 관련 읽기는 보존했다. 개요 연결 12개에는 새 원고를 PRIMARY로 두고 이전 연결은 FOLLOWUP 또는 BACKGROUND로 보존했다.

| 개요 연결 상태 | 이전 | 갱신 |
|---|---:|---:|
| 직접 대응 | 26 | 38 |
| 일부 범위 | 15 | 12 |
| 배경만 | 4 | 1 |
| 직접 원고 없음 | 52 | 46 |

97개 개요 중 기본 조회 가능한 항목은 41→50개다. 8권 전체 완성률이나 실제 앱 탑재율은 아니다. 원본 개요 레코드 97개와 잘못된 이름·판본 연결 배제 규칙 5개를 보존했다.

## 호출과 재현

```js
import {createMediumAtlas} from '../../integrations/medium-atlas-v302/adapter.mjs';
import {createOverviewReadingBridge} from '../../integrations/medium-atlas-v302/bridge.mjs';
const atlas = createMediumAtlas(delivery);
const bridge = createOverviewReadingBridge(crosswalk, atlas);
bridge.resolve('OV-E-014'); // 1433~1436년 바젤 협상
atlas.getReader('DOCUMENT-BASEL_COMPACTATA');
```

`delivery`: `data/deep/atlas_v302_integrated_455_medium_delivery.json`  / `crosswalk`: `data/contracts/atlas_v302_overview_medium_reading_crosswalk.json`. V2.98·V3.00 소비 코드는 동결하고 455편용 모듈을 별도 제공한다. 새 24개 출처는 `V301-Sxx`로 이름 공간을 분리한다. `priorInspection`은 V3.01의 과거 확인 일자·범위·메모이며 `access.status=NOT_CHECKED`는 V2.97 방식의 접근 재검증을 추가로 수행하지 않았다는 뜻이다. 과거 검색 발췌·초록 확인을 전편 확인이나 선택 주장 검증으로 승격하지 않는다. 기존 선택 주장 22건과 추가 확인 필요 1건도 그대로 유지한다.

```bash
python3 scripts/build_v302_integrated_delivery.py --check
node --test integrations/medium-atlas-v302/*.test.mjs
```

별도 검토 화면은 `integrations/medium-atlas-v302/index.html`에서 455편 전달본을 읽는다. 기존 V2.99 화면은 435편 스냅샷으로 보존한다. 실제 AI Studio 앱의 최신 소스·라우트와의 통합 및 그 앱의 모바일 검증은 미수행이다. 다음 작업은 남은 46개 직접 원고 없음 항목의 범위·우선순위를 정해 중간 깊이로 보강하는 것이다.
