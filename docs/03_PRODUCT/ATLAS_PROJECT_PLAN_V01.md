> 작성일: 2026-10-25
> 상태: **DRAFT — 사용자 검토용 설계 착수 계획서**
> 프로젝트: `worldinyj/REFORMATION-ATLAS`
> 상위 원칙: **역사 정보 개요 준비 → 프로젝트 설계문서 → 웹 뼈대 구축 → 심층 연구 및 콘텐츠 증분 업데이트**
> 주의: 본 문서는 PRD·TRD·UX/UI·TASKLIST가 아니며 코드 구현·운영 배포를 승인하지 않는다.

## 1. 비전과 우선순위
누구나 교회사를 **연대·인물·장소·사건·원전·주제**로 살펴볼 수 있고, 역사 지식이 확대될 때마다 같은 페이지에 새로운 검증 정보를 쌓아갈 수 있는 **장기 확장형 종교개혁 역사 아틀라스**를 만든다.

우선순위는 웹의 첫 화면부터 모든 문헌을 완전하게 고증하는 것이 아니다. 먼저 **시대별 개요와 잘 연결된 탐색 구조**로 웹 뼈대를 구축한다. 이후 위클리프·얀 후스·루터·츠빙글리·칼뱅 등 인물/사건의 연구를 이어 붙인다.

### 지켜야 할 편집 원칙
1. **정확한 것과 미검증을 구별**한다. 연구자 평가, 원전 본문, 후대 번역본, 단체가 설명한 역사, 일반 해설은 다른 출처 등급이다.
2. 인물 간의 `문헌 영향`, `후대 수용`, `공동 활동`, `직접 교류`와 `신학적 견해 일치`를 같은 관계로 묶지 않는다.
3. 가톨릭·정교회·개신교·재세례파 등 다양한 전통의 견해를 출처와 맥락을 밝히고 공정하게 보여준다. 한국·비유럽 신자의 능동적 역사도 반영한다.
4. AI 인물화는 **상상 재현임을 표시**하고 역사적 생전 초상으로 소개하지 않는다. 원본 이미지/저작권 불명 자료와 유료 문헌의 전문을 무단 수록하지 않는다. 필요한 지도·삽화는 별도 창작하고 검토·출처·권리 게이트를 적용한다.
5. 콘텐츠의 `DRAFT`·`REVIEWED`·`APPROVED` 등 편집 상태와 웹 공개 허가는 구별한다. **검증 통과는 출판 승인이 아니다.**

합계: **콘텐츠 객체 127건 + 연결 관계 32건**. 출처는 23개 등록 ID 중 2개가 다른 출처에 대한 중복 별칭이며, 본 회차에서 11개만 링크·제목·범위를 직접 확인했다. **22개 장소는 정확한 역사지도 점을 고증하지 않은 상태**다. 이 숫자를 완전하게 검증된 출판 항목 수로 설명하면 안 된다.

특히 제3권의 심층 자료(위클리프·후스·후스파 원전, 원본 지도·AI 삽화)는 기존 연구 브랜치에서 **독립적으로 보존**한다. 개요의 `OV-P` 임시 인물 ID 중 발도·위클리프·후스는 원래 제3권의 `PER`와 명시적 대응표로 연결하고, 후속 시스템의 단일 인물 ID 정책을 TRD에서 확정한다.

## 3. 정보구조(IA)의 설계 목표
### 권별 관문
- 1권: 초대교회·고대교회
- 2권: 중세교회와 개혁 배경
- 3권: 종교개혁의 선구자
- 4권: 16세기 종교개혁
- 5권: 가톨릭 개혁과 종교적 갈등
- 6권: 부흥과 세계선교
- 7권: 세계·한국 교회사
- 8권: 전 시대를 횡단하는 **사상·문헌 아카이브**(독립된 시간 순서의 8번째 시대로 취급하지 않음)

### 핵심 탐색 단위
- 권 → 시대 개요·핵심 질문·대표 항목
- 인물 → 기본 생애·활동·연관 사건·대표 문헌·관련 인물
- 연대표 → 시대·인물·주제 필터 → 사건 카드
- 장소 → 현대 지명·역사 배경·사건 연결. **미검증 좌표는 지도 핀으로 표시하지 않음**
- 문헌 → 제목·시기·문헌 구분(원저작/편집/번역/해설)·요약·링크
- 사상 → 관련 인물·논쟁·사료·교단별 해석의 차이
- 통합 검색 → 키워드/동의어로 위 항목을 찾는 구조(검색 알고리즘은 TRD에서 결정)

8권 화면은 동일한 디자인 시스템을 공유하되 VOL-08은 **자료실/주제 네비게이션**을 주로 사용한다.

## 4. 웹 MVP 1차 범위
**P0 — 첫 웹 뼈대에 포함**
1. 홈: 8권 개요와 주요 탐색 경로, 자료 검증 안내.
2. 권별 목록·권 상세: 해당 권의 인물/사건/문헌/장소/주제 연결.
3. 인물 목록과 상세 **개요 카드**(33명 초기 목록). 심층 내용은 선택적 추가 탭/섹션.
4. 연대표: 사건 34건과 정확/근사 연대의 표현 차이.
5. 문헌 목록/상세: 최소 요약·판본 수준·출처 링크·권리 고지.
6. 사상·주제 목록/상세: 주제 10건과 관련 권의 탐색.
7. 기본 검색/필터(최소 제목·인물·사건을 찾는 기능). 구체 UI 및 검색 기술은 PRD/TRD/UX에서 선택.
8. 반응형 모바일·데스크톱 읽기 및 접근성.

**P1 — 기반이 준비되면 열기**
- 지도를 통한 장소 탐색: 현 단계 장소 22건은 이름만 있고 **지도 좌표가 검증되지 않아 정밀 지도 구현은 고증 후 활성화**. P0는 장소 **목록**을 제공한다.
- 개인 간 관계 시각화: 관계 의미를 잘못 추론하지 않는 도식만 도입.
- 문헌 원문/번역 비교, 심층 주석, 여러 교단 관점 비교, 원전 각주, 심층 지도와 자체 제작 인물화.
- 교육용 읽기 경로/큐레이션·퀴즈 등은 별도 요구사항 검토.

**P0에서 제외**
- 모든 유료 원전의 전문 게재, 고증되지 않은 실제 역사 지도라고 주장하는 이미지, 로그인·사용자별 맞춤화·결제, 자동 AI 생성 공개, 외부 CMS 전체 구현. 미래 요구는 PRD에서 타당성을 재검토한다.

## 5. '개요에서 심층으로' 업데이트 구조
같은 인물(예: 마르틴 루터)의 식별자는 유지한다.
- 최초: 생몰년대·주요 활동·대표 사건·대표 문헌·출처 한눈에 보기.
- 후속: `DEEP_RESEARCH` 본문, 근거/이견, 문서 판본 설명, 사건별 주석, 검증된 추가 이미지.
- 공개 권한: **편집자 확인 + 사실/출처의 게이트 + 이미지 권리/고증 확인**이 충족된 항목만 노출.
- 관계: 하나의 인물이 여러 권에 등장해도 캐릭터 중복생성 없이 **글로벌 인물 ID** 사용. 원문 개정/번역/해석은 각각 고유 문서 객체.
- 기록: 변경한 이유, 근거, 판본, 승인자, 날짜, 롤백 방법을 남겨야 한다.

## 7. 데이터 및 품질 원칙
### 데이터 계약
각 카드 또는 상세 화면에는 식별자, 한국어 표제, 분류/권, 개요, 출처, 연구 상태, 공개 가능 여부가 필요하다. 사건은 `date_label`과 `date_precision`을 모두 가진다. 장소는 `modern_place`와 역사적 현장/좌표 인증을 분리한다.

### 기술 QA
- 데이터 참조 고아 0건/ID 충돌 0건.
- 권별 탐색과 검색의 필터 일관성, 날짜 근사 표기 유지.
- 사료 링크/출판 상태/이미지 캡션 추적.
- 모바일 화면의 핵심 흐름, 키보드 접근·스크린리더 alt, 기본 보안과 성능 예산은 PRD/TRD에서 구체화.
- 자동 검사 통과 ≠ 역사 내용 전면 승인.

### 콘텐츠 QA
- 개요에 대한 출처 1건 이상의 최소 링크와 `review_status`.
- 직접 원전·편집판·번역·현대 연구를 UI에서 구분.
- 다른 교단 해석에 관한 단정은 근거·기준 문맥과 함께 제시.
- 개요 콘텐츠에서도 오해 소지가 큰 이름·연대·국가/지역 해석을 우선 검증.

## 9. PRD 전에 정해야 할 선택 사항 (초안 결정 대기)
- 1차 이용자: 일반 독자/교회교육자/연구자 가운데 **일반 독자와 교육 입문자를 우선**으로 놓고, 연구층은 확장 대상으로 가정. 사용자 확정 필요.
- 서비스 언어: 1차 **한국어**. 영문 인물/문헌명은 원어·검색 별칭으로 유지.
- 데이터 편집 방식, 웹 프레임워크·호스팅·검색·지도 공급자는 **TRD에서 선택**, 현 단계에서 기술 스택 확정 금지.
- 운영 권한: 편집자/검수자/승인자/게시자 기능 필요성을 PRD에서 확정. 운영 관리화면은 P0 필수 아님.
- 시각 톤: 학술적 신뢰와 현대적인 인터랙션을 조화. 구체 컬러·폰트·시안은 UX/UI에서 선택.
