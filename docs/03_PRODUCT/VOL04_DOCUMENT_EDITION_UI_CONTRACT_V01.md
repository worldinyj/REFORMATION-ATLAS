# 제4권 문헌 상세·판본 비교 화면 계약 V0.1

> 설계 전용 / 웹앱 미적용 / 승인 전 공개 금지 · 2026-10-25

## 페이지 구조
1. **저작 상단**: 고정 저작 ID(현재 `OV-D-011`, `OV-D-012`), 제목, 시대와 저자. 연구용 `WORK-PROP`은 정식 문헌 경로를 발급하지 않는다.
2. **판본 연표**: 연도, 언어, 초판/개정/번역/사본의 객체 종류. 1530 제출 문서와 1531 인쇄본, 1540 Variata를 혼합하지 않는다.
3. **3개 비교 탭**: 구성 변화·본문 차이·삽화 차이. 관찰과 신학 해석을 분리한다.
4. **출처**: 서지 링크, 소장번호, 1차 자료/후대 전사/현대 번역의 등급.
5. **한계 표시**: 원문 미대조, 소장번호 미확인, 학술적 해석 이견을 독자에게 명시한다.

## 출판 게이트
- 승인된 **저작·판본·비교 사례·자료 근거·미디어 권리·사람 승인·릴리스 승인**이 모두 있어야 별도 공개 스냅샷에 포함.
- 누락·미승인·연구용 `*-PROP-*`/ `VOL04-CMP-*` 키는 기본 차단. 브라우저 숨김 처리만으로는 불충분하며 **빌드에서 배제**.
- 현재 연구용 3개 비교 사례는 모두 `public_visible=false`. 이 파일은 공개 페이로드가 아니다.
- 기존 `/documents/:documentId` 경로 및 권 공통 읽기 계약 `data/contracts/atlas_contract_v01.json`을 변경하지 않는다.

관련 파일: `data/contracts/vol04_document_edition_ui_v01.json`, `data/deep/vol04_edition_comparison_v01.json`.
