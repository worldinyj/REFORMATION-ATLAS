## 1. 제품 개요
종교개혁 아틀라스는 8권으로 구성된 교회사·종교개혁 탐색형 웹 아카이브다. 독자는 인물·사건·장소·문헌·사상의 관계를 **개요 카드로 쉽고 빠르게 살펴보고**, 심층 검증 자료가 준비될 때 같은 자리에서 더 깊게 읽게 된다.

**사용자에게 주는 가치:** 누구를 언제 어디에서 무엇 때문에 주목해야 하는지 짧게 이해한 뒤, 원문·학술 서평·해설 출처까지 따라갈 수 있다. 하나의 교단이나 근대화 서사를 전체 역사로 단정하지 않고 출처와 관점을 명시한다.

### 목표
1. **정보 발견:** 8권 간 관계 및 33명 초기 인물·34개 사건·20문헌·10주제를 쉽게 찾음.
2. **연구 확장:** 콘텐츠 깊이/판본이 늘어도 기존 ID·URL·기본 화면 형태를 보존.
3. **검증 투명성:** 대중적 개요/전문 심층/미검증·후대 번역/독립 원전을 이용자가 구별.
4. **낮은 구현 부담:** 검증된 최소 범위부터 출시하고 후속 연구 콘텐츠로 확장.

### 비목표
- 8권 모든 사료의 완전한 학술 교감 후에야 설계 착수.
- 가짜 역사 좌표로 지도 완성, 고증되지 않은 초상/AI 이미지 즉시 전시.
- 유료 원전 전문 제공, 자동 AI 출판, 로그인/결제/학습 성적 시스템 구축.
- 제3권 연구 브랜치의 182노드·365관계 원본을 새로운 개요 데이터로 덮어쓰는 행위.

## 2. 주이용자와 사용 시나리오
| 사용자 | 핵심 필요 | 1차 제공 |
|---|---|---|
| 일반 역사 독자(우선) | 시대의 큰 흐름과 인물을 빠르게 파악 | 8권·연대표·인물 카드 |
| 교회교육 입문자·소그룹 | 주제별 설명·수업 질문·출처 찾기 | 권 개관·사상 축·문헌 링크 |
| 교사/콘텐츠 작성자 | 자료의 신뢰도·한계를 확인하고 공유 | 원본 출처·정확도·연결 관계 |
| 연구 지향 사용자(후속) | 이문·번역/원문 및 논쟁 세부 추적 | P1 심층 연구·문헌 판본/비교 |

**U-01 처음 보는 독자:** 홈에서 8권을 살펴보고 VOL-04을 선택해 루터의 개요를 읽는다. 인물/문헌 링크로 1517 논쟁과 95개조 문헌을 오갈 수 있어야 한다.

**U-02 교육 준비자:** ‘성찬’을 검색하면 관련 주제와 위클리프·후스·루터·츠빙글리의 연관 정보를 찾되, 견해가 서로 같다는 단정은 보이지 않는다.

**U-03 한국사 관심자:** VOL-07에서 1784 천주교 초기 공동체, 1880년대 한국인 번역·전도와 해외 선교사 입국을 구분해 탐색한다.

**U-04 문헌 열람자:** ‘De Ecclesia’를 찾으면 1413년 저작과 후대 영어 번역의 구분, 출처 링크와 접근 범위를 확인한다.

**U-05 지도 관심자:** 프라하/옥스퍼드 등 장소의 현대 명칭은 읽되, 아직 검증되지 않은 지도 핀·실제 이동로·옛 건축물 좌표가 표시되지 않음을 이해한다.

**U-06 심층 콘텐츠 업데이트:** 역사 검수자가 후스의 새로운 심층 원고를 제출하더라도 기존 인물 상세 URL/기본 개요가 유지되고, 승인된 부분만 단계적으로 공개할 수 있어야 한다.

## 3. 현재 보유 자산과 범위
| 종류 | 준비된 개수 | 1차 처리 |
|---|---:|---|
| 시대·권 개요 | 8 | 8개 권별 페이지 데이터 |
| 인물 | 33 | 목록·상세 개요 |
| 사건 | 34 | 사건 카드·연대표 |
| 문헌 | 20 | 개요·서지/판본 |
| 장소 | 22 | 현대 지명 **텍스트** 목록 |
| 사상 주제 | 10 | 제8권/횡단 탐색 |
| 참조 관계 | 32 | 관련 항목·관계 의미 표시 |
| 참고 출처 ID | 23 | 11개 범위 직접 확인, 나머지 검토 대기 |

현재 자산은 **비공개 DRAFT**, 기술 검증 PASS는 사실관계·저작권 공개 승인을 뜻하지 않는다. 정확한 역사 현장 좌표 0건, 미승인 AI 이미지 공개 0건을 가정한다.

## 6. 콘텐츠 필드와 독자 표시 계약 (초안)
**공통 카드**: `id`, `title_ko`, `type`, `volume_ids`, `summary_ko`, `source_ids`, `review_status`, `public_visible`, `updated_at`(변경 이력 채택 시). 일부 원본 이름이 영어이면 검색 별칭으로 보존.

**사건**: `date_label`과 `date_precision`을 반드시 같이 제공한다. `year_start`는 **정렬용**일 뿐 실제 정확한 발생일로 노출하면 안 된다.

**인물**: 글로벌 인물 ID와 별칭, 활동 시기, 관련 사건/문헌/권. 제3권의 발도·위클리프·후스 `OV-P ↔ PER` 대응표는 필수 입력이며 어떤 ID를 최종 정본으로 삼을지는 TRD 결정.

**문헌**: 제목·원어 제목·저술 시대·원문/후대 인쇄본/번역/학술서평/기관 자료 구분, 간결한 독자용 설명, 출처 링크, 라이선스/접근 가능 범위.

**장소**: 현재 지명과 역사적 연관 설명은 보여주되 현재 22건의 미확인 좌표로 마커를 찍으면 안 된다. 권·역사 문헌의 위치 인식용이다.

**관계**: 관계 type 및 설명/출처를 표시. 영향/수용 ≠ 직접 여행·사제관계. 아직 연구 검증이 부족하면 직접적 관계 다이어그램은 P1으로 미룸.

**콘텐츠 상태**: `DRAFT`·`UNDER_REVIEW`·`APPROVED` 와 `public_visible`은 독립 축. 내부 프리뷰는 로그인 여부 등 기술 방식을 TRD에서 정하되, 공개 API에는 승인 데이터만 포함. 현재 개요 데이터는 모두 DRAFT이므로 **현 시점 공개 페이지에 127건을 제공한다고 주장하지 않는다**.

**심화 데이터 추가 방식**: 같은 ID 하위 `OVERVIEW`·`DEEP_RESEARCH`·`DOCUMENT_WITNESS`·`MAP` 등 블록의 가용성을 구분하고, 미승인 블록은 반환하지 않는다. 웹 컴포넌트는 빈/준비 중 상태를 지원한다.

## 7. UX/UI 요구사항 (다음 단계의 입력)
- 처음 방문한 사용자가 홈→권→인물 상세에 헤매지 않고 도달.
- 8권 모두가 보이고 VOL-08이 8번째 시간대가 아닌 **사상·문헌 자료실**로 설명.
- 모바일(320px 이상)에서 카드·검색·목록의 읽기 경험과 터치 대상을 점검.
- 사용자가 키보드만으로 검색/목록/상세/뒤로가기 이동 가능.
- 색상만으로 확실성 등급을 구별하지 않고 텍스트 설명도 제공.
- PDF/지도/AI 이미지가 추가될 때 대체텍스트·출처·제작/고증 고지가 있어야 함.
- 혼합 표기(루터/Martin Luther, 후스/Jan Hus)를 검색 별칭으로 처리.
- 외부 출처 링크는 사용자에게 다른 사이트로 이동한다는 점을 알림.
