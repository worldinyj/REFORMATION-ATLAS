# Google AI Studio 검토용 통합 지침 — V5.37

## 적용 경계
기존 앱을 복제한 검토용 환경에서만 작업할 계획이다. 현재 can_import_ai_studio=false이므로 실제 앱에 가져오거나 배포하지 않는다. 이 지침은 승인 이후 사용할 프롬프트 및 시험 계획이다.

## 패키지 생성
로컬에서 연구 브랜치를 동기화하고 다음 명령을 실행한다.

```sh
python3 research/v537/preview/build_preview_package.py --output /tmp/ATLAS_V537_REVIEW.zip
```

ZIP은 23개 SVG와 통합 JSON, 검색 색인, 계약, 검토 지침을 포함한다. 기존 파일을 덮어쓰지 않으며 해시 불일치나 누락은 즉시 실패한다. 이 단계의 스크립트 실행은 아직 확인하지 않았다.

## 승인 이후 AI Studio용 프롬프트
기존 화면, 라우팅, 인증, 데이터와 기능을 보존한다. 별도 미리보기 경로에서만 atlas_preview.json과 asset_manifest.json을 사용한다. 콘텐츠 ID를 기존 데이터의 키와 충돌 없이 연결하고, 8권/24장 목록과 개요/중간/심층 읽기, 지도, 사례, 인물, 신학 해설을 탐색할 수 있게 한다. 기존 데이터베이스를 변경하거나 대체하지 않는다. 검색은 search_index.json을 사용하며 결과에서 해당 장으로 이동한다. 시각 자료는 asset ID로 해석한 preview_path를 사용한다. 이미지 누락 시 상징 카드 또는 명시적 텍스트 안내를 제공한다. null 좌표는 지도에 표시하지 않는다. 연구 미승인 상태와 출처·한계 문구를 유지한다. 자동 배포 금지.

## 실제 검토 시험
| ID | 시험 | 합격 조건 |
|---|---|---|
| A01 | 권/장 탐색 | 8권 24장, 중복/빈 페이지 없음 |
| A02 | 깊이 선택 | L1/L2/L3 정상 전환, 기존 본문 유지 |
| A03 | 사례·지도 | 52 사례, 36 좌표; null 위치는 텍스트 |
| A04 | 인물 | 10명, 누락 WebP 요청 없음 |
| A05 | 문헌 | 연표 및 4개 비교도 정상 표시 |
| A06 | 검색 | 제목·지역·인물·신학 검색 후 장 이동 |
| A07 | 모바일 | 360/768/1440px에서 잘림·겹침·가로 스크롤 검사 |
| A08 | 접근성 | 키보드 탐색, 초점, 대체텍스트, 대비 검사 |
| A09 | 안전한 렌더링 | 외부 스크립트 실행 및 신뢰되지 않은 HTML 차단 |
| A10 | 기존 앱 회귀 | 기존 경로와 기능 유지, 운영 DB 미변경 |
| A11 | 배포 차단 | can_ship/can_import_ai_studio=false 유지 |

현재 A01~A11은 실제 앱에서 시험하지 않았다. 전문가 검토와 출처·좌표 검증, SVG 시각 QA, 앱 스키마 적합성을 별도 승인받은 뒤 진행한다.
