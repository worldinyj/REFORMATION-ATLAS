## 1700년 마드리드판과 1701년판의 인쇄지 대응

| 원래 인쇄지 서명 | 1700년판 | 1701년판 | 증거 분류 |
|---|---|---|---|
| ¶ before main preliminary gatherings | # i–viii | not printed as separate corresponding leaf series | 서지학자 가상 페이지 번호 |
| ¶×2 through ¶×4 | # 1–24 | # 1–24 | 서지학자 가상 페이지 번호 |
| ¶×5 through ¶×6 | # 25–40 | # 25–40 | 서지학자 가상 페이지 번호 |
| a, b, c | # 41–64 | # 81–104 | 서지학자 가상 페이지 번호 |
| ¶×7 through ¶×10 | # 65–96 | # 41–72 | 서지학자 가상 페이지 번호 |
| * | # 97–104 | # 73–80 | 서지학자 가상 페이지 번호 |
| ** through *** 1–2 | # 105–116 | # 117–128 | 서지학자 가상 페이지 번호 |
| *** 3–4 and **** | # 117–128 | # 105–116 | 서지학자 가상 페이지 번호 |
| A–Z | pp. 1–184 | pp. 1–184 | 인쇄 본문 페이지 번호 |
| Aa–Dd | pp. 185–[216] | pp. 185–[216] | 인쇄 본문 페이지 번호 |

**표 읽기에서 중요한 구분:** 위 표에서 `#`는 알라토레가 자체 부여한 무쪽수 권두부의 **가상 페이지 번호**이고, `pp.`는 원래 책의 **본문 인쇄 쪽수**다. 전자는 인쇄물에서 같은 페이지 번호가 찍힌 사실이 아니다. 1700/1701판의 본문은 모두 **pp. 1–184, pp. 185–[216]** 구조로 표에 나타나지만, **같은 쪽수를 쓴다는 사실만으로 각 문장이 글자 하나까지 동일하다고 증명하지 않는다.**

**편집 구조의 실제 차이:** 알라토레의 표에서 인쇄지 `a,b,c`는 1700년판 권두부의 가상 41–64쪽에 대응하지만 1701년판에서는 81–104쪽으로 옮겨 배치된다. 반대로 `¶×7`부터 `¶×10`의 자리는 1700년판 65–96쪽에서 1701년판 41–72쪽으로 이동한다. 따라서 사후 저작집의 헌정·찬시·서문의 배치가 바뀌었다는 서지학적 설명을 **인쇄지 번호와 위치**로 구체화할 수 있다.

**1701년 판본 구별:** 원 논문은 리스본과 바르셀로나의 1701년 출판을 모두 다루면서 표에는 `1701`을 한 열로 표기한다. 본 연구는 표의 모든 대응 위치가 리스본·바르셀로나 양쪽의 모든 소장본에서 개별적으로 확인됐다고 확장해 주장하지 않는다.

## 출판 가능한 진술과 보류 진술

**서지학자가 검토한 근거에 따라 말할 수 있음:** 두 저작집의 본문 인쇄쪽수 구간이 같고 권두부 일부 인쇄지가 서로 다른 위치에 있다는 것. **새로 주장할 수 없음:** 소르 후아나의 1691년 원고를 1701년에 저자가 수정했다는 설, 1700·1701년 『답장』 본문에 몇 개의 특정 이문이 있다는 설, 소르 후아나의 논쟁이 현대 특정 운동의 직접 원인이었다는 설.
