## 직접 확인한 핵심 근거

Antonio Alatorre의 *NRFH* XXIX권 449–450쪽을 **스캔 이미지로 직접 판독**하여 1700·1701년 저작집 인쇄지 대응표 10행을 작성했다. 권두부의 가상 페이지 위치 차이와 본문의 인쇄 페이지 범위가 표에서 보이는 방식으로 서로 다르다는 점을 증명하는 서지학 연구의 재확인이다.

**당대 원판 자체의 동일 문장 활자를 비교한 것은 아니다.** JCB 1700년 372쪽 PDF, BYU 1701년 352쪽 PDF는 공개돼 있지만 이 웹 열람 과정에서 59.0MB/37.6MB 파일의 직접 열람이 용량 제한으로 막혔다. 이 제한을 숨기지 않고 자료 접근 등급에 기록했다.
