## 학술적 게이트 — 엄격하게 구분

**직접 대조한 것:** GHDI의 현대 영어 편집 번역문, 그루버 희귀본 소장 설명, WLB 선교 성경 PDF 2쪽(화면 직접 확인), BSI 기관 설명, 한국민족문화대백과사전의 서지 해설, 학술 논문 발췌·각주·권호.

**대조하지 않은 것:** 위클리프·후스의 라틴어 원고 본문, 1529년 조항의 WA 원본 페이지, 아우크스부르크 각 인쇄본 전권, 1555/1648 당대 독일어·라틴어 문서 전권, 타밀어 신약 표제지와 권말·완질 여부, 1900년 서울·요코하마 두 인쇄본의 본문 차이.

V4.82 원고 복구, 역사학자 검토, 실제 독자 평가, 이미지 권리 심사, 앱 E2E 역시 미완료다. **인용문 위치를 특정했다는 것은 원전 전체를 직접 교감했다는 뜻이 아니다.**
