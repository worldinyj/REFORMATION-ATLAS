# 종교개혁 ATLAS V5.06 — 독자 평가 진행 지침과 본문 개정 판단

> 2026-11-23 · **평가 진행자용** · 실제 응답·독자 평가·전문가 승인 **0건** · `can_ship=false`

## 1. 무엇을 개선했으며, 이번에 검증할 질문은 무엇인가

V5.05의 여섯 주제 원고는 역사 문헌의 관계를 신중하게 설명하지만, 일반 독자가 처음 읽기에는 **한 문단에 16세기 유럽 신학, 17세기 남미 여성 저술, 19세기 태평양의 사본 문제까지 등장**한다. 실제로 어렵다는 독자 응답을 수집한 것은 아니며, 이것은 편집자의 사전 진단이다.

이번 V5.06에서는 각 주제의 시작에 다음을 새로 썼다.

- **쉬운 출발 질문** — 전문 용어를 모르더라도 처음 생각해 볼 질문
- **핵심 장면 대비** — 서로 다른 자료가 무엇을 말하는지 짧은 문장으로 구분
- **증거의 한계** — 직접 쓴 원고와 제삼자의 기록·서지 목록은 다른 자료임을 표시
- **원래 역사 장으로 돌아갈 경로** — 실제 ID를 명시하되 웹앱 경로로 주장하지 않음

문서 끝에는 공의회·칭의·성찬·신민·필사본·초판·이문·교감·전사·메타데이터 등 **16개 핵심 용어의 쉬운 풀이**를 추가했다. 기존 V5.05 본문을 없애지 않은 이유는 쉬운 안내와 문헌의 정확성을 동시에 읽을 수 있어야 하기 때문이다.

**이것만으로 독자의 이해가 개선됐다고 확정하지 않는다.** 실제 사람이 읽고 자신의 말로 설명할 때 오해가 줄었는지 확인하는 절차가 필요하다.

## 2. 실제 조사를 시작하기 전의 문서 고정

진행자는 아래 세 자료가 동일한 V5.06 연구 브랜치를 가리키는지 확인한다.

1. [V5.06 일반 독자 개정본](../../docs/01_CONTENT/L1/V506_SIX_THEME_PLAIN_LANGUAGE_READER_EDITION_KO.md)
2. [12문항 + 3개 탐색 과제 참가자 질문지](./participant_reader_comprehension_questionnaire_ko.md)
3. [채점 기준·실제 역사 장 ID 데이터](./reader_pilot_scoring_contract.json)

원고 중간에 해설을 수정하면 같은 문항의 답이 다른 문서에서 달라질 수 있다. 그러므로 **실제 테스트가 시작되면 원고와 문항을 고정해 버전·blob SHA를 남기고**, 수정 후보는 별도 편집 파일로 관리해야 한다.

### 예상 독자 범주 — 계획, 모집 결과가 아님

| 범주 | 목적 | 확인하고 싶은 차이 |
|---|---|---|
| 일반 독자 | 전문 용어 설명 없이도 사건·근거를 구별하는가 | 어려운 낱말, 출처 수준, 시간표 이해 |
| 교회사·성경 공부 경험이 있는 독자 | 익숙한 교리 용어 때문에 자료를 과도하게 추론하지 않는가 | 구원론과 사회비판, 성찬과 고해 구분 |
| 역사·신학 분야의 전문 독자 | 문헌의 출처 수준과 지역별 과잉 일반화를 찾아내는가 | 1차 자료 접근, 본문의 학술적 경계, 서지 정확성 |

각 범주 **3~5명 안팎을 편의표집하는 소규모 예비평가를 제안**할 수 있지만, 이것은 표본을 확보했다는 주장이 아니다. 표본 크기가 작고 무작위 표집이 아니므로 통계적 대표성이나 교단·지역 전체의 일반적 결과를 주장할 수 없다.

### 개인정보 보호

참가자는 원하는 질문을 건너뛰고 언제든 중단할 수 있어야 한다. 조사 목적과 익명 처리, 응답의 사용 범위를 미리 알린다. 이름·연락처·종교 소속·정치 신념·건강 등 신원 식별 또는 민감 정보는 **채점에 필요하지 않으므로 수집하지 않는다**. 참여 범주만 선택한 뒤 이름이 아닌 임의 참가코드로 표기한다. 실제 수집이 시작될 때 기관의 연구윤리·보관 정책을 별도로 확인한다.

## 3. 진행자 행동 — 힌트를 주지 말고 어디에서 막히는지 기록

**가. 안내:** 이 문헌은 역사 해설의 가독성을 점검하는 초안이며, 참가자의 신학 지식이나 신앙을 평가하지 않는다고 설명한다. 정답을 맞히도록 돕는 과정이 아님을 안내한다.

**나. 읽기:** 참가자는 V5.06 원고를 자유롭게 살펴보고 뒤의 16개 용어 풀이를 사용할 수 있다. 진행자가 먼저 '1555년은 이렇게 해석해야 한다'고 설명하지 않는다.

**다. 답변:** Q01~Q12의 답을 자기 말로 쓰게 한다. 근거를 찾았다면 장 ID나 문장 단서를 적는다. 문장 길이나 표현의 유창성보다 **역사 사실과 자료 범위를 정확히 구분하는지**를 본다.

**라. 탐색:** N01~N03은 문서 안에서 사례 ID와 장 ID를 찾는 과제다. 실제 앱이 아직 검증되지 않았으므로 **화면 전환 속도, 앱에서의 클릭 성공률 또는 검색 성능으로 기록하지 않는다**. 이 부분의 평가는 원고에서 '어디로 가야 하는지 알 수 있는가'에 한정한다.

**마. 자유 의견:** F01~F04는 수정할 문장·용어·경로의 구체 지점을 발견하기 위한 질문이다. "좋았다/어려웠다" 같은 막연한 의견만 적기보다 관련 장 ID와 문단 일부를 기록하도록 요청한다.

## 4. 채점 — 답을 미리 정하지 않은 것이 아니라 관찰과 기준을 분리

모든 문항에 대한 **판정 기준은 별도의 JSON에 기록**했다. 참가자에게 정답표를 먼저 보여 주지 않는다.

| 점수 | 판정 |
|---|---|
| **2점** | 문항별로 지정된 두 핵심 요소를 모두 자신의 말로 정확히 설명 |
| **1점** | 한 요소만 정확하거나 핵심 근거 범위 설명이 부족 |
| **0점** | 핵심 역사 사실을 반대로 해석하거나 출처의 한계를 명백히 잘못 이해 |
| **NA** | 응답하지 않음 또는 자발적으로 건너뜀 — 자동으로 0점으로 기록하지 않음 |

12문항의 점수 범위는 **최대 24점**, 3개 원고 탐색 과제는 **최대 6점**으로 설계했다. 총 30점은 계산 가능하지만 **이 점수의 신뢰도·타당도·합격선은 아직 검증되지 않았다**. 특정 점수 이상을 '이해도 통과'로 판단하지 않는다. 서로 다른 채점자가 독립적으로 채점할 수 있다면 판단 차이를 기록하고, 판단이 다른 이유를 원고 수정에 활용하는 것이 좋다.

*예시 문항별 정답 요소는 답안 데이터로 생성돼 있으나 실제 참가자 응답은 한 건도 없다.* 연구 데이터의 `real_responses: []`, `scores: []`, `metrics: null`은 그대로 유지한다.

이 표의 '오해 위험'은 **편집자가 미리 식별한 가설**이다. 실제 응답에서 관찰된 빈도나 출현 확률이 아니다.

## 6. 연구자가 원고를 어떻게 고칠 것인가 — 판단 기준

### P0: 즉시 검토할 역사적 오류 또는 증거 수준의 착오

누군가 원고를 근거로 고해 장면을 성찬론의 직접 원전으로 이해하거나, CELAM 문헌 메타데이터를 실제 회의 조항으로 인용한다면, 우선 **원고 표현 자체가 그런 오해를 유발하는지** 확인한다. 한 사람의 해석만으로 내용을 즉시 삭제하지 않되, 출처의 직접성에 관한 역사적 위험은 반드시 검토한다. 전문 검토가 필요하면 별도 보류 이슈를 만든다.

### P1: 반복해서 혼동하는 시간표나 역사 연결

서로 다른 참가자가 1691/1700/1701 또는 1823/1830/1889의 기능을 같은 방식으로 혼동하면, 설명이 충분하지 않을 가능성이 있다. 원고에 시간표를 삽입하거나 문장 순서를 바꾸고, 그 변경은 **다른 편집 후보로 명확히 기록**한다. 아직 나타나지 않은 응답 빈도를 만들어내지는 않는다.

### P2: 낱말·문장 길이·탐색 경험

칭의·이문·교감처럼 정확하지만 어려운 용어는 삭제하기보다 **짧은 설명과 구체 사례**로 재서술한다. 찾아가야 할 장 ID와 돌아올 허브가 반복해서 보이지 않는다면 배치 구조나 제목을 바꾼다. 다만 실제 앱 UI의 성능 문제와 원고 탐색 문제는 따로 구분한다.

## 7. 실제 응답 수집 시 기록 양식

최소 기록은 다음 단위를 권장한다. 이것은 **행·열 이름의 제안**이며 실제 사람이 제출한 결과가 아니다.

| 필드 | 용도 |
|---|---|
| `participant_code` | 익명 참가자 코드 |
| `reader_cohort` | 독자 경험 범주 3개 중 하나, 세부 신앙 소속 기록 금지 |
| `reader_version_sha` | 실제 읽은 원고 파일의 Git blob SHA |
| `question_id` | Q01~Q12 / N01~N03 |
| `answer_text` | 참가자가 자발적으로 제출한 응답, 가능한 한 개인 정보 제거 |
| `score_0_1_2_or_NA` | 코드북에 근거한 판정 |
| `misconception_code` | 원문과 증거를 혼동한 유형 |
| `evidence_anchor_id` | 실제 원고 장 ID 또는 사례 ID |
| `editorial_priority` | P0/P1/P2 또는 수정 불필요 |
| `revision_proposal` | 수정하려는 문장과 근거, 진행자 메모 |
| `reviewer_disagreement` | 가능하다면 독립 채점자 사이의 판단 차이 |

응답은 설명된 목적에서 벗어난 공개 분석이나 개인정보 추정에 사용하지 않는다. 데이터 보관·삭제 정책은 실제 조사 개시 전에 정한다. 추후 파일 저장 시 익명화와 접근 권한을 확인해야 한다.

## 8. 완성 상태

이번 V5.06은 **실제 원고 수정 + 참가자용 평가 문항 + 채점 코드북 + 진행 지침**까지 작성한 단계다. 3개 범주의 사람을 실제 모집하거나 질문지에 답하게 한 것은 아니다. 그러므로 시험 점수, 전문가 승인, 이해도 개선율, 서비스 이용 지표를 생성하지 않는다.
