## 실제 성과

**8권·24장 증거 지도:** P0 5장, P1 9장, P2 7장, P3 3장.

**제4권 에티오피아 인쇄사 1편을 실제 삽입:** 테스파 시온(1548~1549), 총 본문 49,242자에서 50,166자(+924자).

**판본 위험 식별:** 1599 디암페르 시노드는 서로 다른 원문 전승을 확인한 뒤에도 조문 교감이 끝나지 않아 미삽입. 기존 V5.08의 다섯 지역 사례와 V5.09의 세 기록 주체 사례 유지.

**자료 점검:** 1376년 카타리나 Harley MS 3480 목록 및 영어 번역, 1523년 아르굴라 인쇄본 별도 서지, 1543년 하비에르 편지의 후대 번역과 선교사 관점 차이 확인. 자료 링크 개수는 직접 원전 교감 완료의 증거가 아님.
