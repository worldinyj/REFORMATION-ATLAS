## 이번 단계의 편집 판단

**8권·24장 역사 본문은 그대로 유지하고, 실제 독자용 '여섯 질문' 사이에서 다섯 지역 역사 사례를 읽을 수 있게 통합했다.** 연구 문헌을 더 늘리는 데 치중하지 않고, 기존 자산이 서로 어떻게 보완되는지 해설하는 콘텐츠를 완성했다.

V4.93부터 존재하던 여섯 주제 경로(T01~T06)는 수정하지 않았다. V5.01~V5.04에서 집필·검토한 과만 포마·소르 후아나·파페이하와 타웅아·태평양 여성·메데인의 사례는 각각 기존 제5·6·7권에 둔 **하나의 우선 L1 장 ID**를 기준으로 연결했다. 같은 사례를 여섯 주제마다 복사해 정본을 늘리지 않고, **주제에 따라 직접적인 역사적 비교인지, 단순한 맥락 비교인지, 메타데이터 수준인지를 구분**한다.

### 실제 독자 코스 3개

1. **누가 신앙을 가르치고 글을 남길 권한을 가졌는가?** — 공의회 → 교회생활 → 소르 후아나 → 과만 포마 → 제7권
2. **유럽만이 복음을 전한 것이었는가?** — 경교비 → 남인도 타밀어 → 제6권 선교 → 파페이하/타웅아 → 한국어 성경
3. **교회가 가르친 것과 사람들이 경험한 것은 같았는가?** — 제국법 → 교회규율 → 과만 포마 → 태평양 여성 → 메데인

화살표는 교육용 독서 순서이며 역사적 인과·사상적 전승의 확정을 뜻하지 않는다.
