1. **제3권 — 선행 개혁:** 왈도파의 1532년 모임과 후대 '찬포란 시노드' 명칭, 위클리프의 성찬·은총론과 후스의 구별, 후스파 1420/1433/1436년의 요구·교섭·공포를 분리해 집필

3. **제5권 — 가톨릭 쇄신·공존:** 트리엔트 공의회의 세 기간과 25회기, 1555년과 1648년의 법적 보호 및 1624년 기준연도, 지역 교회회의를 통해 볼 수 있는 여성·평신도의 일상

## 통합 후 확인한 사실과 한계

- **24/24장** 원고를 정확한 ID 위치에서 대조했고, 제8권 3개 장은 V4.50 그대로 유지했다.
- 21개 확장 원고의 장 ID가 모두 실제 V4.50에 존재했다.
- 새 확장 연구본에 기록한 문헌 링크는 중복을 제외해 **71개 URL**(합계 78건 참조). 이것이 71개 문헌의 원문 판독이 모두 완료됐다는 뜻은 아니다.
- 완전히 같은 장 본문 문단의 중복은 검사상 0건이며, 의미가 비슷한 문장의 편집 중복은 사람이 후속 검토해야 한다.
- 실제 독자 평가 0회, 역사학자 승인 0회, 운영 앱 E2E 0회이며, 심화 연구 후보를 자동 공개하지 않았다.
