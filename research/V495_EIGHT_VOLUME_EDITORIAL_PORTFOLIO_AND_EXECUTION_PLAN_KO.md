## 1. 작업 방향: 버전 수보다 실제 역사 원고의 밀도를 올린다

이번 검토는 V4.94의 8권 24장 합본을 기준으로 한다. V4.50의 24장 `bodyMarkdown`을 합산하면 약 **15,031자**, 한 장 평균 약 **626자**다. 제8권에서 파생된 여섯 주제 독서 해설은 별도의 연결 원고다. **약 4.9만 자의 통합 합본이 곧 4.9만 자의 독립 역사 본문을 의미하지 않는다.** 합본에는 각 장의 출처 목록·주의사항·반복 소개·통합 주제 해설도 포함된다.

실질적인 심화가 필요한 시점이다. 원고의 분량 자체가 품질을 증명하지는 않지만, 지금의 L1 각 장은 큰 역사적 결론을 제한된 문단에 압축한 상태다. 앞으로는 형식적 검증만 반복하지 않고 **원인과 배경 → 지역별 인물과 선택 → 구체 문헌 → 다른 해석 → 독자의 이해**가 한 장 안에서 연결되도록 한다.

## 2. 이번 V4.95에 실제로 개선한 내용

### 제3권 × 은총과 구원

- 기존 판단: 주제와 연결할 수 있는 제3권의 **직접적인 구원론 앵커 미확보**.
- 신규 연구: 위클리프의 구원론을 독립적으로 다룬 2005년 및 2025년 학술 논문 확인.
- 실제 집필: 위클리프의 은총·예정·인간 자유·공로 문제를 16세기 신앙고백과 혼합하지 않는 **추가 절 원고 후보** 작성.
- 검증 수준: **학술 2차 근거 후보 있음 / 중세 라틴어 특정 문단 직접 대조 미완료**. 최종 정본으로 자동 승격하지 않음.

### 제7권 × 은총과 구원

- 기존 판단: 세계 기독교의 지역적 다양성만으로 구원론을 설명하는 것은 근거가 부족함.

- 실제 집필: 사회적 차별·고통·해방과 구원 이해가 어떻게 연결되는지 설명하면서, 한국·인도 전체에 동일한 신학을 귀속하지 않는 **추가 절 원고 후보** 작성.
- 검증 수준: **학술 종합 개관 근거 있음 / 각 지역의 신학자 원저·교단 문헌 직접 대조 미완료**. 최종 정본으로 자동 승격하지 않음.

## 3. 시대권과 주제권의 역할을 명확히 나눈다

원고를 무조건 합치면 같은 인물·사건이 반복해서 독자에게 등장한다. 반대로 모든 중복을 삭제하면 주제 간 비교가 불가능하다. 따라서 연구 데이터는 다음 세 계층으로 분리한다.

**계층 A — 시대·지역 정본 L1:** 24장 각각의 독립적인 역사 본문·일정·증거 목록·검증 상태. 사실·연대·판본·인물·직접 역사 서술의 주된 저장 위치.

**계층 B — 제8권 여섯 주제 탐색:** 권별 장의 원문을 복제하지 않고, T01~T06에서 해당 장을 어떤 질문으로 읽는지 안내한다. 같은 장을 2개 이상의 경로에서 연결하더라도 실제 본문 데이터는 한 군데만 둔다.

**계층 C — 미승인 심화 원고 후보:** 부족한 학술 근거와 새로 쓴 추가 절을 정본 바깥에서 관리한다. '참고 문헌 확보'와 '기존 원고에 대한 출판 승인'은 완전히 다른 단계다. 신규 2건은 이 계층에 속한다.

GitHub 연구용 JSON: `research/data/V495_EIGHT_VOLUME_CONTENT_STAGING_CONTRACT.json`. 이 파일의 파일 경로·식별자·출처 해시·검증 상태가 모두 연결되어야 향후 앱 탑재에 대비할 수 있다. **앱 URL이나 실제 라우트는 아직 추정하지 않는다.**

## 4. 상위 수준의 부족한 영역과 우선순위

### A급 — 역사적 오해·원문 불확실성이 큰 부분

1. **타밀어 신약 1715/1719 서지 문제:** 인쇄 시기·소장본·전권 간행 설명을 섞지 말고 기관 회신 및 표제지·권말 대조 전 확정하지 않는다.
2. **위클리프·후스 성찬·은총:** 각 인물의 문헌·시대·교리 차이를 확인한다. 후대 루터파 견해를 중세인에게 소급하지 않는다.
3. **아우크스부르크 1530/1531/1540:** 제시 시점·인쇄 판본·개정 본문, 1540년 Variata와 같은 해의 비-Variata 소장본을 구별한다.
4. **종교법 1555/1648:** 보호 범위와 적용 대상 및 1624년 기준연도를 명시한다. 보편적 개인 종교자유의 즉각적 성립이라고 말하지 않는다.
5. **V4.82 본문 복구:** 이전 대화에서 보고된 번역·수용 연구 원전의 정확한 파일과 SHA를 회수하기 전에는 정본에 병합하지 않는다. 이번에는 GitHub의 `V4.82` 관련 커밋 검색 및 `v482` 브랜치 검색에서 결과를 찾지 못했다. 이것이 존재하지 않았다는 증거는 아니다.

### B급 — 지역·성별·교파별 역사적 균형

1. **VOL-01/02:** 고대~중세 역사를 서유럽→나머지 세계의 일방 전파로 그리지 않는다. 실제 지역 교회·언어·공동체별 근거를 확보한다.
2. **VOL-06:** 경건주의, 모라비아, 웨일스·영국과 북아메리카의 여러 부흥, 선교와 현지인의 교육·번역을 분리한다.
3. **VOL-07:** 아프리카의 고대 지역 교회와 근현대 자생 교회, 인도 달리트 신학, 라틴아메리카의 다양한 해방신학, 한국 천주교·개신교·민중신학의 출발점을 독립적으로 설명한다.
4. **교파간 비교:** 가톨릭·동방정교·오리엔트 정교·개신교·자생교회를 하나의 조직이나 하나의 신학으로 합치지 않는다.
5. **현지 행위자:** 여성, 평신도, 번역가, 원주민·피식민 공동체의 선택과 반응을 구체적 사람·지역·문헌으로 복원한다.

### C급 — 독자 경험과 실제 앱 연결

- 24장 전체를 8권 목차에서 바로 찾도록 하는 표준 ID.
- 여섯 주제의 핵심 연결과 맥락·선택형 연결을 UI에서 시각적으로 구분.
- 원문 전문을 복제해 여러 경로에 저장하지 않고 재사용.
- 새로 발견된 학술자료는 신뢰 수준과 미검증 사유를 표시.
- 지도·초상·원전 이미지의 저작권과 출처를 개별적으로 확인. 실제 배포 앱의 링크와 화면은 해당 시스템에서 확인하기 전 확정하지 않는다.
