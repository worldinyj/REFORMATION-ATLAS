# 종교개혁 ATLAS V4.39 — 8권 역사 서술과 독자 경로 통합 검증

> 2026-11-18 · **실질적 편집/데이터 교정 완료 · 사람의 역사학적 승인 아님 · 실제 앱에 미반영** · `can_ship=false`

## 1. 편집상 발견과 실제 수정

V4.38의 8권 확장본은 역사적 인과를 설명하는 장점이 있지만, 제1~7권마다 **새 연결 설명 + 기존 「다음 권으로」 설명이 겹치는 두 마무리 절**이 있었다. 제8권에는 비교 후 결론과 '독자가 선택하는 경로' 안내의 순서가 뒤섞여 있었다.

V4.39에서는 7권의 마무리를 각 **하나의 다음 권 연결 절**로 통합하고, 제8권은 **비교 원리 → 두 가지 독서 경로 → 본래 역사로 돌아가는 마무리** 순으로 정리했다. 역사적 사례를 설명하는 기존 본문은 새 마무리 이전까지 문자 단위로 보존했다.

| 지표 | V4.38 | V4.39 |
| --- | ---: | ---: |
| 권 수 | 8 | 8 |
| 8권 본문 문자열 길이 | 19,406 | **17,951** |
| 제1~7권 마무리 절 | 권별 2개 | **권별 1개** |
| 제8권의 역사시대 분류 | 시대가 아닌 비교 색인 | 유지 |
| 앱 본문 변경 | 0 | **0** |

**단순한 압축이 아니라, 역사적 논증의 핵심과 주의할 구별을 남기며 반복만 줄이는 편집이다.**

## 2. 검증 가능한 독서 경로 두 종류

**시간순:** VOL-01 → VOL-02 → VOL-03 → VOL-04 → VOL-05 → VOL-06 → VOL-07 → VOL-08(비교색인). 권의 연대가 일부 겹치는 것은 잘못된 분류가 아니라 **다른 지역·운동을 설명하기 위한 편집상 중첩**이다. 7권을 독립적·배타적인 연대 구간으로 오해해서는 안 된다.

**주제별:** V4.29 기존 6개의 주제 ID 각각에 대해 시대권 **4개씩 총 24개 방문 지점**을 설계했다. V4.29 원본의 6×7=42개 비교 연결 모두 보존되며, 새 경로에서 사용한 24개 지점도 각각 실제 원본 연결을 가진다.

| 경로 | 방문 지점 | 구별할 질문 |
| --- | --- | --- |
| 성경과 권위 | 01→03→04→07 | 누가 무엇을 근거로 가르치고 조직했나 |
| 은총과 구원 | 01→04→05→06 | 신앙고백과 생활의 차이를 볼 수 있는가 |
| 성찬과 예배 | 02→03→04→05 | 후스·위클리프와 마르부르크, 트리엔트의 논쟁을 합치지 않는가 |
| 교회조직과 생활 | 02→04→06→07 | 수도원·도시교회·근대 선교공동체를 일직선 발전으로 그리지 않는가 |
| 국가·갈등·공존 | 01→03→05→07 | 황실의 수용과 주민 개종, 1555년 합의와 보편 종교 자유를 구별하는가 |
| 번역과 지역 수용 | 02→03→06→07 | 경교비의 두 연도, 타밀어 인쇄, 한글 성경 판본과 지역의 역할을 구별하는가 |

**주의:** 연결은 `CORE_CASE`(핵심 사례), `CONTEXT_BRIDGE`(맥락 연결), `LIMITED_CONTEXT_NOT_DOCTRINE`(제한된 배경)처럼 증거·관계의 역할이 다르다. 모두 같은 직접 증거라고 표시하지 않는다. 이번 결과는 **오프라인 콘텐츠 링크 그래프 검증**이며, 실제 AI Studio 앱 내 클릭 이동과 이용자 행동에 대한 실험은 **0건**이다.

## 3. 숨은 결함 수정: 기존 주장 앵커 7개

V4.33은 확장 원고에 29개 주장 문자열을 연결했다. 그런데 V4.34부터 역사적으로 중요한 문장을 바꾸면서 **7개 과거 앵커가 현행 원고에서 일치하지 않았다.**

V4.39에서 이 7건의 원고 위치를 정확하게 다시 확인했다.

| 주장 ID | 재연결 대상 |
| --- | --- |
| CL433-08 / 09 | 위클리프의 실체존속설과 후스의 실체변화 |
| CL433-13 | 1530년 비공식 인쇄와 1531년 멜란히톤 관여 판본 구별 |
| CL433-20 / 21 | 1714년 타밀어 부분 인쇄, 1715년 전체 수록 소장본 |
| CL433-24 | 1779년 전후의 강학 모임과 1784년 세례·공동체 형성 |
| CL433-25 | 1882년 누가복음 등 개별 복음서와 1887·1911년 전권 범위 |

**검증 결과:** 기존 위치 그대로 **22개**, 갱신 **7개**, 누락 **0개**, 중복 **0개**. 모든 새 앵커가 해당 권의 본문에서 **정확히 한 번** 나타나며 문자 인덱스도 일치한다.

과거의 `CL433-21=SOURCE_SUPPORTED`는 그대로 역사 기록으로 보존하되, 이번 판정에서는 **1715년 실물 소장 근거는 강함 / 1719년 기록의 서지적 관계는 미해결**로 명시하여 `CONFLICT_HOLD_COMPLETION_YEAR_1719_UNRECONCILED`로 관리한다. 기존의 29개 판정서를 과거가 달라진 것처럼 덮어쓰지 않았다.

그 결과 **현재 연구용 유효 판정의 분포**는 `SOURCE_SUPPORTED=12`, `REVIEW_REQUIRED=10`, `HOLD=3`, `CONFLICT_HOLD=1`, `STRUCTURE=3`이다. 이는 출판 가능 문장 12개가 승인됐다는 뜻이 아니다.
