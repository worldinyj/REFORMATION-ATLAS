# 종교개혁 ATLAS V4.08 — 유럽 11개 지역 동시대 탐색 UI 연결 규약 (개발 참고용)

> **외부 AI Studio 웹앱을 직접 수정하지 않는 검토용 데이터 계약.** 기존 앱 구조와 API 명칭은 현재 확정하지 않는다. 본 파일은 데이터를 연결할 때 우선적으로 지켜야 할 사용자 경험 및 역사적 정확성 규칙이다.

## 목표

**한 지역·한 인물·한 사건으로 들어온 독자가 같은 시기의 다른 지역을 읽을 수 있도록 한다.** 유럽 종교개혁을 루터 한 사람에서 주변 도시로 퍼지는 단일 화살표가 아니라, 신학적 대화·정치적 경쟁·지역별 병행 변화로 보여 준다.

입력 데이터: `research/data/V4_08_EUROPE_SYNCHRONOUS_EVENTS_PEOPLE_RELATIONSHIPS_L0_DRAFT.json` (V4.07 11지역과 V4.06 8권 데이터에 대한 확장 레이어, 정본 대체 아님). 독자용 산문: `docs/01_CONTENT/OVERVIEW/V408_EUROPE_SYNCHRONOUS_HISTORY_COMPARATIVE_GUIDE_KO.md`.

## 사용자의 네 가지 진입점

### A. 연도·시대에서 시작하기

기본은 1415~1648년 범위의 6단계 시대 구간이다. 역사에서 변화가 집중되는 1517~1598년을 확대해서 볼 수 있게 하되, 전체 시야의 1415년 선행 개혁과 1618~1648년 전쟁·조약 맥락을 숨기지 않는다. 단일 연도를 탭하면 해당 연도의 사건과 그 시기에 걸쳐 이어지는 기간형 사건을 구분해 보여 준다.

단일 사건(year_start ＝ year_end 없음)은 **연도 점**, 종교전쟁이나 장기적 시행 같은 기간형 사건(year_end 있음)은 **기간 띠**로 표현한다. 숫자에 해당하는 정확한 월일이나 위치는 데이터가 검증하지 않았다. 기간형 사건을 시작해의 단일 점으로 축약하면 역사적 오해가 생긴다.

### B. 지역에서 시작하기

V4.07의 `ER-01`부터 `ER-11`까지 **11개 지역 레인**을 사용한다. 레인당 사건·인물·비교 관계를 함께 불러온다. 처음부터 11개 지역을 나란히 길게 늘어놓기보다, 모바일에서는 한 지역을 선택한 뒤 **‘다른 지역과 비교’** 하나를 추가하도록 설계한다. 화면에 동시 표시하는 지역은 2~3개를 우선한다.

현대 국가명은 검색과 길 찾기의 **안내 표기**일 뿐 16세기 영토의 엄밀한 법적 경계가 아니다. 국가 전체를 단일 신앙 색상으로 칠하지 않는다. 지도 배경이 반드시 필요하다면 해당 연도 또는 시대의 역사적 경계·소수 공동체를 다룰 수 있는 사용권 검토 자료만 사용한다.

### C. 인물에서 시작하기

`people` 24명의 목록과 `people_event_relationships`의 연결만 사용한다. 인물 카드에는 **역할 요약 / 활동 지역 / 관련 연표 사건**을 보여 준다. 자신과 무관한 모든 사건을 자동 연결하지 않는다. 두 인물이 같은 시기에 살았다는 이유만으로 만남·서신·영향을 가정하지 않는다.

### D. 역사적 질문에서 시작하기

6개의 주요 주제를 활용한다: `T01` 성경·권위 / `T02` 은총·구원 / `T03` 성례·예배 / `T04` 교회 조직 / `T05` 국가·전쟁·공존 / `T06` 번역·교육·전파. 필터에 따라 같은 주제의 다른 지역 사건이 드러나도록 한다. 사용자는 **같은 질문에 대한 지역별 다른 답**을 비교할 수 있다.

## 가장 중요한 핵심 화면: 동시대 비교 장면 8개

`comparative_scenes`의 `spotlight_event_ids`는 역사적 구체 사례 4~5건을 보여 주는 기본 화면이며, `all_synchronized_event_ids`는 시기와 지역을 더 넓게 탐색할 때 쓰인다. 장면에서 강조된 사례가 전체 사건의 유일한 목록은 아니다.

| 비교 장면 | 사용자에게 전달할 메시지 |
|---|---|
| SC408-01 독일과 스위스 | 교리·도시정치·제후정치는 처음부터 같지 않았다 |
| SC408-02 1530년대 | 잉글랜드·덴마크·독일·제네바가 같은 시대의 다른 선택을 했다 |
| SC408-03 가톨릭 개혁 병행 | 서로 경쟁하는 제도개혁들이 함께 진행됐다 |
| SC408-04 전쟁과 공존 | 프랑스·저지대의 전쟁과 토르다·바르샤바의 정치적 협상을 비교한다 |
| SC408-05 세 왕국 | 잉글랜드·스코틀랜드·아일랜드의 수용 결과는 달랐다 |
| SC408-06 북유럽 | 개혁 결의와 실제 제도화는 수십 년 차이가 날 수 있다 |
| SC408-07 평화·전쟁·조약 | 낭트·보헤미아·1648년은 서로 다른 정치적 결과다 |
| SC408-08 국가교회 밖의 신자 | 재세례파·가톨릭 소수파·정교회 등도 역사적 행위자다 |

장면 하나에 설명문 전체를 한 화면에 밀어 넣지 않는다. **140~200자 핵심 이야기 → 관련 사건 4~5건 → 더 읽기**의 세 단계로 펼친다. 독자의 핵심 질문을 바꾸지 않은 채 지역 필터만 갱신할 수 있어야 한다.

## 관계망 그래프의 선의 종류 — 오해하지 않기

데이터의 `region_relationships`에는 `relation_type`과 `narrative`, `causation_claim`이 있다. 모든 선을 이동 화살표나 직접 전파라고 표현하지 않는다. 관계는 `THEOLOGICAL_DIALOGUE`, `PERSON_NETWORK`, `HABSBURG_RULE_AND_CONFLICT`처럼 역사적 교류·통치 갈등을 뜻할 수도 있고, `STRUCTURAL_CONTRAST`, `PLURALISM_CONTRAST`, `LIMITED_TOLERATION_COMPARISON`처럼 후대 연구자가 **비교를 위해 연결하는 선**일 수도 있다.

권장: 역사적으로 연결된 교류 관계는 일반 연결선으로, 연구자가 나란히 비교하는 관계는 점선으로 구분하고, 양쪽 화살표·일방 화살표는 직접 문헌으로 전파의 방향성이 확증된 경우에만 사용한다. 인물·사건·지역 모두 클릭 시 자세히 볼 수 있는 연결 정보를 갖되, 현재 파일에 없는 정확한 이동 경로는 그리지 않는다.

## 6개 시대 구간과 이벤트 데이터의 연결

원본 `events`에는 정확한 기간 범위(`year_start`, `year_end`), 사건과 관련된 지역(`region_ids`), 주제(`theme_ids`), 인물(`actor_ids`), 출처(`source_ids`)가 있다. `layers[].event_ids`, `regional_lanes[].event_ids`는 실제 존재하는 사건 ID를 참조한다.

데이터가 가진 `date_label`은 독자에게 보이는 역사적 시간의 표현이다. 연도 표기와 기간 표기는 구별하며, 1530년대처럼 장기간의 흐름을 말하는 사건을 **1530년 1월 1일**처럼 정밀한 단일 날짜로 바꾸지 않는다.

실제 지도 좌표, 당시 왕국·교구의 경계 폴리곤, 주민 종교 인구 비율은 이 파일에 없다. 시각화 과정에서 AI가 국가별 비율이나 GPS를 만들어 넣는 것을 차단한다.

## 이 데이터만으로 가능한 것과 아직 불가능한 것

**가능:** 유럽 11개 권역을 비교하고 45개 사건을 하나의 연표에 배치, 24명 인물의 관련 사건 탐색, 6개 주제로 필터, 8개 동시대 장면의 역사적 비교, V4.07 지역별 해설과 V4.06 8권 개요 링크 연결.

**아직 불가능:** 역사적 현장의 좌표 기반 여행경로, 16세기 모든 영토의 정확한 정교한 GIS 지도, 인구·교단별 비율의 연도별 차트, 종교개혁 인물 전체의 완전한 서신·만남 네트워크, 513편의 자동 갱신. 이런 기능을 현재 구현했다고 말하지 않는다.

## 출처 등급과 저작권

제시된 14개 참고 자료는 웹에서 확인한 공개 연대표·학술 서지·박물관·대학 자료의 경로다. 일부 학술 장은 **초록·목차만 조회**했으며 전문을 읽은 것으로 표시하지 않는다. 인용문·원본 지도 이미지를 저장소에 복사하지 않는다.

오래된 지도나 현대 비교 지도 중 어느 것도 **허가·연도·지역 축척**을 검토하지 않고 웹앱에 붙이지 않는다. 참고 지도: https://germanhistorydocs.org/en/from-the-reformations-to-the-thirty-years-war-1500-1648/confessional-divisions-before-and-during-the-reformations

## 제품 통합 전 검수 기준

1. V4.07의 11개 지역 ID와 충돌하지 않으며, 최소 2건의 사건이 모든 지역에 있다.
2. 비교 장면 8개의 주요 사건 ID와 전체 동시대 사건 ID가 실제 데이터에 존재한다.
3. 모든 사건은 검증 가능한 참고 자료 ID를 갖고, 역사적 날짜와 시기를 임의의 월일로 바꾸지 않는다.
4. 서로 다른 성격의 연결선은 직접 영향·비교 관계를 구별한다.
5. 1555년 아우크스부르크, 1568년 토르다, 1573년 바르샤바, 1598년 낭트, 1648년 베스트팔렌을 현대적 보편 종교 자유라고 단정하지 않는다.
6. 원본 편집 자료·기존 513편·`main`·AI Studio는 수정하지 않으며 Human 승인 전 `can_ship=false`이다.
