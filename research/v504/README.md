## 이번 연구의 실제 성과

지난 V5.03의 **'1700년과 1701년에 인쇄본이 존재한다'**는 설명을 넘어, **그 인쇄본들의 내용 배치·인쇄 상태·철자 차이가 실제로 어떻게 기록돼 있는지** 확인했다.

1. **1700 마드리드 초판 자체의 불균일성:** 초상판화의 소장 유무, 인쇄 도중 추가된 a·b·c 접지의 편철 위치, 시 표제의 변화와 끝부분의 페이지·저자 표기 차이가 전문가 연구에서 확인됨.
2. **1701 두 도시의 별도 인쇄:** 리스본의 Miguel Deslandes 인쇄본과 바르셀로나의 Rafael Figueró 인쇄본은 **표지만 바꾼 동일 인쇄판의 책이 아니며**, 활자·판면·판화에 차이가 있음.
3. **여성의 글을 소개하는 순서:** 익명 여성의 아크로스틱 십행시와 편집자 Castorena의 안내문이 1700년판에서는 서두 뒤쪽에 있다가 1701년 두 인쇄본에서는 **표제지 직후로 이동**.
4. **45개 실제 비교 사례:** Georgina Sabat de Rivers의 1700 Madrid–1701 Lisboa–1701 Barcelona **표기 샘플 45건**을 검토. Barcelona와 Madrid의 서로 다른 읽기 **41건**, Lisboa와 Madrid의 같은 읽기 **20건**이라는 **원 연구의 비교 분류**를 확인하고, 학자들이 제안한 **Madrid→Lisboa→Barcelona**의 인쇄 계보를 연구용 가설로 기록.
5. **출처의 매우 중요한 구분:** 이 45개는 시·추도문·서문·경건문헌·색인 등 **저작집 전체의 표본**이다. 그 숫자는 **1691년 『답장』에 발생한 45개 의미 있는 신학적 이문 수가 아니다.**

이 작업은 기존 V5.03의 다섯 사례 중 **소르 후아나 한 편만 실질적으로 보강**했고 나머지 네 사례는 본문 그대로 유지했다. 기존 V5.00의 **8권·24장** 원고를 변경하지 않았다.

## 실제 원판 접근의 제한

Madrid 원본: 일부 소장 웹 열람 오류. Lisboa 원본: Valladolid의 복제 자료로 직접 연결하는 호스트 접근 제한. Barcelona 원본: 공개된 원본 스캔 **352쪽, 약 35.82MB**의 파일이 존재하지만 웹의 파일 용량 제한으로 페이지 단위 내용 검토 실패. **따라서 없는 본문 이문을 만들어내거나 초판 이미지 교감이 성공했다고 기록하지 않는다.**

본 연구는 역사 교사의 독자용 설명을 강화하기 위한 검토 초안이다. 실제 원어 인쇄물의 표제지·인쇄면과 사료학적 검토, 역사학자 서명, 독자 평가, 저작권/이미지 심사 및 AI Studio 앱 시험을 완료하지 않았다.
