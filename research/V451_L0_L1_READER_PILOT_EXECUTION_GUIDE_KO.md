- L0 최신 연구 개요 8권과 V4.50 L1 중급 역사 해설 24개 장의 **원문 전체**가 한 파일에 포함되어 있다. 파일을 내려받아 브라우저에서 로컬로 열 수 있도록 HTML·CSS·JavaScript를 같은 파일에 넣었다.
- 제1~7권은 역사·지역 설명, 제8권은 주제 비교라는 기존 구조를 유지한다. 왼쪽에서 권 선택·본문 검색, 가운데서 L0/L1 전환·장 읽기·다른 권으로 이동, 오른쪽에서 이해도 및 독해 질문 2개를 기록한다.

- 본문 읽기는 인터넷 연결이 필요 없지만, 각 장의 **외부 문헌 링크를 열 때는 해당 외부 웹사이트에 접속**한다. 검토 시에는 인터넷 사용을 통제하거나 자료를 미리 제공한다.

## 2. 파일 실행과 실측 방식

1. GitHub 연구 브랜치에서 HTML 파일의 **Raw/Download**를 선택해 `.html` 확장자로 컴퓨터에 저장한다. GitHub 자체의 코드 보기 화면은 대화형 페이지가 아니므로 로컬 브라우저로 직접 열어야 한다.
2. HTML을 열면 기본값 제1권 L0 개요가 표시된다. 사이드 메뉴에서 다른 권을 고를 수 있고, 본문 검색으로 해당 내용을 포함한 권을 찾을 수 있다.
3. **L1 · 심화 장 읽기**를 누르면 해당 권의 세 장이 보인다. 한 장을 열어 본문, 근거자료, '사료 검토 유의'를 살펴본다.
4. 평가 실험에서는 연구 책임자가 아래 권별 실제 탐색 과제 중 하나를 참가자에게 배정한다. 참여자는 책의 논지를 본인 언어로 다시 설명해 본다. 신학적 동의 여부를 조사하지 않는다.
5. 오른쪽 질문 2개, 이해 정도, 어려운 용어 등을 기록한다. 실명·소속·교파·전화번호 등의 개인정보를 넣지 않았음을 확인한 뒤 필요한 경우에만 로컬 JSON 파일을 내려받는다.
6. 연구 책임자는 실제 응답을 분석하기 전에 참가자의 자유로운 동의와 데이터 보관 방식·열람 권한·삭제 정책을 정해야 한다. 응답 원문은 **GitHub 공개 브랜치에 올리지 않는다**.

## 4. 점수보다 중요한 관찰 항목

파일의 독해 질문은 V4.42에서 준비한 8권 × 2문항을 그대로 사용한다. 실제 평가자는 용어를 이해했는지, **L0에서 L1을 찾을 수 있는지**, 역사적 사건의 날짜나 교파를 혼동했는지, 참고자료가 어디에 있는지 알 수 있었는지를 구별해 기록한다.

연구자가 임의로 1~5점을 생성하거나 시범 데이터를 실제 응답으로 간주하지 않는다. 참가자 수, 과제 수행률, 소요 시간, 독자 오류와 같은 숫자는 **실제 관찰 결과가 있을 때**만 작성한다. 원한다면 도착한 익명 JSON 답변을 사전에 정한 평가 기준에 맞춰 요약할 수 있지만, 원고를 읽지 않은 채 자동 승인을 내리면 안 된다.

- 실제 Safari/Chrome/모바일 화면에서의 **수동 브라우저 조작·접근성 QA는 아직 수행하지 않았다.** 따라서 페이지가 모든 환경에서 완벽히 작동한다고 주장하지 않는다.
- 고위험 역사 보류 `C417-11`, `C417-12`, `C417-18`, `TAMIL-1719` 유지. 원고의 역사적 승인을 의미하지 않는다.
- 기존 L0 53개 주장 이력과 V4.29 운영 앱 원본은 변경하지 않았다. 운영 데이터 도입·공개 배포를 금지한다.
