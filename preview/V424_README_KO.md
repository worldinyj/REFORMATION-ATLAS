**01 여덟 권**에서 8개 카드를 고르고 원고 전문을 읽는다. 각 역사권에서 여섯 개 질문 중 해당 권을 가리키는 앵커로 이동할 수 있다. **02 여섯 주제**에서는 하나의 주제를 고른 후 일곱 시대권을 연결한 7개 버튼을 눌러 실제 권별 서술로 갈 수 있다. **03 입문 원고**에서는 6장면을 순서대로 읽고 앞뒤로 이동한다. 우측 상단 검색창에서 ‘후스’, ‘타밀어’, ‘성찬’ 등의 단어를 검색하면 8권·6주제·6장면 본문에서 찾아준다. **04 점검**에서는 내장된 수량 및 연결 무결성 확인 결과가 표시된다.

## 실행·검증한 범위와 미실시 범위

V4.24에서 GitHub에 저장된 **실제 HTML과 그 안의 JavaScript**를 추출해 모의 DOM 환경에서 실행했다. 8권 목록과 상세 8개, 주제 목록과 상세 6개, 입문 장면 6개, 후스 검색, 정적 연결 점검을 시험했다. 발견된 참조 오류는 0건이다. HTML 안에는 외부 스크립트, 외부 이미지, 네트워크 호출이 없다.

**미실시:** 실제 Chrome/Safari에서의 시각 확인과 클릭 자동화, VoiceOver·화면낭독, 모바일의 텍스트 넘침과 접근성, 전문 역사 교열, 독자 5명 테스트, 사진·현대 번역 이용 허가, Google AI Studio 배포. HTML의 정적 무결성 테스트와 실제 브라우저 사용성 테스트를 같은 결과로 기록하지 않는다.
